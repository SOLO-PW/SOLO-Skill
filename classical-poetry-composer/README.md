# 古典诗词创作 Skill（唐诗宋词）

一个专业的 AI 诗词创作工具，赋能生成符合传统格律标准的唐诗宋词作品。

## 简介

本 Skill 提供从需求分析到质量自评的完整诗词创作流程。每次创作均遵循 **分析→研究→创作→校验→复盘** 的标准化工作流，确保作品在格律、意境、语言等方面达到专业水准。

## 适用场景

- 创作唐诗（五/七言绝句、律诗、排律）
- 创作宋词（浣溪沙、蝶恋花、念奴娇等常见词牌）
- 已有诗词的格律校验与修改润色
- 诗词格律知识教学（平仄、押韵、对仗）

## 核心能力

### 完整的创作工作流

1. **需求分析** — 提取主题、情感基调，推荐合适体式，确认韵书标准
2. **主动学习** — 搜索真实经典作品作为参照，分析用韵、意象和结构
3. **格律参考** — 读取专业格律文档，获取体式规则详情
4. **构思创作** — 定韵、布局意象、打磨关键句、逐句创作
5. **格律校验** — 六步人工核查（平仄标注→孤平→三平调→押韵→结构→对仗）
6. **质量自评** — 五维加权评分体系（格律/语言/意境/思想/原创性）
7. **输出交付** — 结构化交付（正文+创作说明+逐句解析+质量自评）
8. **迭代修订** — 支持不超过三轮的免费修订

### 专业校验体系

- **500+ 入声字表** — 按韵部和拼音双索引，解决 AI 平仄判断最大痛点
- **完整平水韵韵部表** — 上平/下平/上声/去声/入声全量覆盖
- **六步核查流程** — 严谨的手动校验操作指南，可配合自动化初检脚本使用
- **五维评分体系** — 0-10 分量化评分，对标专业诗词圈学术标准

## 使用方式

直接向 AI 提出创作请求即可，例如：

```
写一首关于秋思的七言绝句
以"怀古"为主题，用《念奴娇》词牌写一首宋词
帮我看看这首诗的格律有没有问题：白日依山尽，黄河入海流……
```

AI 会自动：
1. 确认韵书标准（平水韵 / 中华新韵）
2. 向你复述创作方案
3. 完成创作后交付完整结构（含质量自评）

## 韵书说明

| 韵书 | 特点 | 推荐场景 |
|------|------|----------|
| **平水韵** | 106韵，含入声，传统正统标准 | 追求古典韵味的创作 |
| **中华新韵** | 14韵，按普通话拼音划分 | 现代人入门，更易懂 |

## 评分等级

作品完成后会按五维加权体系评分：

| 总分 | 等级 | 含义 |
|:----:|:----:|------|
| 9.0-10.0 | ⭐⭐⭐⭐⭐ | 上上品（传世级） |
| 7.5-8.9 | ⭐⭐⭐⭐ | 上品（优秀） |
| 6.0-7.4 | ⭐⭐⭐ | 中品（合格） |
| 4.0-5.9 | ⭐⭐ | 下品（需修改） |
| 0-3.9 | ⭐ | 劣品（根本性问题） |

> 评分对标专业诗词圈标准，7.5分以上已是相当出色的水平。

## 核心原则

- **先研究、再创作** — 每次创作都主动搜索真实作品，禁止凭空编造
- **格律不容妥协** — 平仄、押韵、对仗严格遵循，出律必指出
- **意境优先于技巧** — 形式为内容服务，不为合律牺牲诗意
- **诚实告知水平** — 如实评分，不虚高
- **尊重用户选择** — 用户可选择不接受格律建议，但会告知格律风险
