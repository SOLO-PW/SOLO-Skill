# 唐诗格律规则参考

## 一、唐诗基本分类

| 类型 | 句数 | 每句字数 | 平仄要求 | 对仗要求 | 押韵要求 |
|------|------|----------|----------|----------|----------|
| 五言绝句 | 4句 | 5字 | 严格 | 不强制 | 一、二、四句或二、四句 |
| 七言绝句 | 4句 | 7字 | 严格 | 不强制 | 一、二、四句或二、四句 |
| 五言律诗 | 8句 | 5字 | 严格 | 颔联颈联需对仗 | 二、四、六、八句 |
| 七言律诗 | 8句 | 7字 | 严格 | 颔联颈联需对仗 | 二、四、六、八句 |
| 排律 | >8句 | 5或7字 | 严格 | 除首尾外均需对仗 | 偶句押韵 |

## 二、平仄规则

### 基本平仄格式

平：阴平（一声）、阳平（二声）
仄：上声（三声）、去声（四声）
入声：属仄声（现代汉语已消失，分散在一二三四声中，需特别记忆）

### 五言基本句式（四种）

1. **仄仄平平仄**（仄起仄收）
2. **平平仄仄平**（平起平收）
3. **平平平仄仄**（平起仄收）
4. **仄仄仄平平**（仄起平收）

### 七言基本句式（四种）

1. **平平仄仄平平仄**（平起仄收）
2. **仄仄平平仄仄平**（仄起平收）
3. **仄仄平平平仄仄**（仄起仄收）
4. **平平仄仄仄平平**（平起平收）

### 重要规则

**一三五不论，二四六分明**：五言诗第二、第四字，七言诗第二、第四、第六字的平仄必须严格遵循格式，其余位置可适当放宽（但需避免"孤平"和"三平调"）。

**孤平禁忌**：在"平平仄仄平"句式中，若第一字用了仄声（变成"仄平仄仄平"），则全句除韵脚外只有一个平声字，称为"孤平"，需避免。补救方法：将第三字改为平声（"仄平平仄平"）。

**三平调禁忌**：句末连续三个平声字（如"仄仄平平平"），这是律诗大忌。

**拗救**：当某字该平却仄（拗）时，可在本句或对句的适当位置补偿一个平声字（救）。

## 三、押韵规则

### 韵书依据

- **《平水韵》**：唐宋诗词押韵的标准韵书，共106韵（上平声15韵、下平声15韵、上声29韵、去声30韵、入声17韵）
- **《中华新韵》**：现代汉语拼音为基础的韵书，适合现代人创作，分十四韵

### 押韵要求

1. **律诗**：偶句（二、四、六、八句）押韵，首句可押可不押
2. **绝句**：第二、四句押韵，首句可押可不押
3. **一韵到底**：同一首诗不换韵
4. **避重韵**：同一韵字不在诗中重复使用（除非特别需要）
5. **平仄韵分明**：律诗绝句一般押平声韵

### 《平水韵》常用韵部（平声）

| 韵部 | 代表字 | 说明 |
|------|--------|------|
| 一东 | 风、中、空、红、同 | 宽韵，字多 |
| 二冬 | 冬、钟、龙、松、峰 | 可与一东通押 |
| 四支 | 支、时、知、诗、思 | 极宽韵 |
| 五微 | 微、归、飞、衣、稀 | 窄韵 |
| 七阳 | 阳、香、光、长、方 | 极宽韵 |
| 八庚 | 庚、声、明、城、情 | 宽韵 |
| 十一尤 | 秋、流、舟、愁、游 | 宽韵 |
| 十三元 | 元、言、门、昏、村 | 适中 |
| 十五删 | 删、关、山、还、间 | 窄韵 |

## 四、对仗规则

### 对仗要求

- **律诗**：颔联（三、四句）和颈联（五、六句）必须对仗
- **绝句**：不强制要求对仗
- **排律**：除首联和尾联外，均需对仗

### 对仗要素

1. **词性相对**：名词对名词、动词对动词、形容词对形容词、副词对副词
2. **结构相应**：主谓对主谓、动宾对动宾、偏正对偏正
3. **平仄相反**：出句和对句对应位置平仄相反
4. **意义相关**：两句内容相关但避免合掌（意义重复）

### 常见的对仗类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 工对 | 同一小类名词相对 | "两个黄鹂鸣翠柳，一行白鹭上青天" |
| 宽对 | 相邻类别名词相对 | "感时花溅泪，恨别鸟惊心" |
| 流水对 | 两句语意连贯如流水 | "欲穷千里目，更上一层楼" |
| 借对 | 借字音或字义相对 | "沧海月明珠有泪，蓝田日暖玉生烟" |

## 五、唐诗经典格律示例

### 五言绝句

**仄起首句不入韵**（最常见）

```
仄仄平平仄，平平仄仄平。
平平平仄仄，仄仄仄平平。
```

示例：王之涣《登鹳雀楼》
```
白日依山尽，黄河入海流。
欲穷千里目，更上一层楼。
```

### 七言律诗

**平起首句入韵**

```
平平仄仄仄平平，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
平平仄仄平平仄，仄仄平平仄仄平。
仄仄平平平仄仄，平平仄仄仄平平。
```

示例：杜甫《春望》
```
国破山河在，城春草木深。
感时花溅泪，恨别鸟惊心。
烽火连三月，家书抵万金。
白头搔更短，浑欲不胜簪。
```

## 六、创作检查清单

创作完成后逐项检查：
- [ ] 句数是否正确（绝句4句，律诗8句）
- [ ] 每句字数是否一致
- [ ] 平仄是否符合基本格式（重点关注"二四六"位置）
- [ ] 是否有孤平（"平平仄仄平"句式第一字为仄时需救）
- [ ] 是否有三平调（句末连续三平声）
- [ ] 押韵是否正确（韵部一致，一韵到底）
- [ ] 律诗颔联颈联是否对仗
- [ ] 整体意境是否连贯统一
