```
① 逐句平仄标注 → ② 孤平检测 → ③ 三平调检测 → ④ 押韵检测 → ⑤ 结构检测 → ⑥ 对仗检测
```

**每个步骤都包含：操作说明 + 核查要点 + 入声字/韵部查表方法。**

## 二、入声字完整字表（核查平仄的核心工具）

### 2.1 什么是入声字

入声字是古汉语四声之一，属**仄声**。在现代汉语普通话中，入声已消失，分散到一（阴平）、二（阳平）、三（上声）、四（去声）声中。**今读一二声（平声）的入声字**是最容易出错的地方——AI 用拼音判断会误判为"平"，实际应为"仄"。

**核查原则**：使用前先查入声字表。若某个字在表中，无论现代拼音读几声，一律判为**仄**。

## 四、手动核查操作流程

### 核查步骤 ①：逐字平仄标注

**操作**：
1. 取一句诗，逐字判断平仄
2. 判断优先级：**先查入声字表 → 再按拼音读法判断 → 标记不明字**

**判断规则**（按优先级）：
| 优先级 | 条件 | 结果 |
|:------:|------|:----:|
| 最高 | 字在入声字表中 | **仄**（无论现代读几声） |
| 次高 | 现代拼音一二声（非入声） | **平** |
| 次高 | 现代拼音三四声 | **仄** |
| 最低 | 轻声或无法判断 | 标注 ? 待确认 |

**核查要点**：
- 五言诗重点检查**第2、4字**，七言诗重点检查**第2、4、6字**
- 这些位置平仄必须严格符合格式，出错即为"出律"
- 第一、三、五位置可适当放宽，但需避免孤平、三平调

**格式对照**（最常用）：
```
五绝仄起首句不入韵：仄仄平平仄，平平仄仄平。平平平仄仄，仄仄仄平平。
七律仄起首句入韵：仄仄平平仄仄平，平平仄仄仄平平。平平仄仄平平仄，仄仄平平仄仄平。仄仄平平平仄仄，平平仄仄仄平平。平平仄仄平平仄，仄仄平平仄仄平。
```

---

### 核查步骤 ②：孤平检测

**孤平定义**：在"**平平仄仄平**"句式中，第一字用了仄声 → 变成"**仄平仄仄平**"→ 全句除韵脚外只有一个平声字。

**检测方法**：
1. 找到句式结构为"平平仄仄平"的句子
2. 检查第一个字是否为仄声
3. 如果是仄声，检查第三个字是否改为平声做了**拗救**
   - 有救 → 变成"**仄平平仄平**"→ 不算孤平（合格）
   - 未救 → 算孤平（不合格）

**示例对比**：

| 诗句 | 平仄 | 判定 |
|------|:----:|:----:|
| 黄河入海流 | 平平仄仄平 | ✅ 正常，无孤平 |
| 一从归白社 | 仄平平仄仄 | ✅ 不是平平仄仄平句式 |
| 客心悲未央 | 仄平平仄平 | ✅ 首字仄，第三字救（未央→平），合格 |
| 晓镜但愁云鬓改 | 仄仄仄平平仄仄 | ✅ 七言，不是此句式 |

**七言简化为五言判断**：七言"**仄仄平平仄仄平**"句式，只看后五字"平平仄仄平"，方法同上。

---

### 核查步骤 ③：三平调检测

**三平调定义**：句末连续**三个平声字**。

**检测方法**：
1. 查看每句的最后三个字
2. 现代拼音判断，排除入声字（入声即使今读平声也按仄算）
3. 如果三个字都是平声 → 三平调（不合格）

**示例**：
| 句末三字 | 判定 |
|:--------:|:----:|
| 入海流 → 仄仄平 | ✅ 安全 |
| 光秃秃 → 平入入 | ✅ 秃是入声，不算三平调 |
| 花如雪 → 平平仄 | ✅ 安全 |
| 春天来 → 平平平 | ❌ 三平调 |
| 秋风清 → 平平平 | ❌ 三平调 |

---

### 核查步骤 ④：押韵检测

**检测方法**：
1. 确定韵脚行（律诗偶句押韵，绝句2、4句押韵，首句可押可不押）
2. 提取每个韵脚字
3. 在对面的平水韵韵部表中逐一查找每个韵脚字
4. 检查是否所有韵脚字属于**同一韵部**

**操作示例**（以《如梦令·听雨》为例）：
```
窗外雨声如诉 → 诉 → 查平水韵韵部表 → 去声七遇 ✅
独倚空庭谁顾 → 顾 → 查平水韵韵部表 → 去声七遇 ✅
散入漫天寒雾 → 雾 → 查平水韵韵部表 → 去声七遇 ✅
伫望晚庭烟树 → 树 → 查平水韵韵部表 → 去声七遇 ✅
```
判定：共同韵部"去声七遇"→ **押韵一致 ✅**

> **注意事项**：
> - 如果某个字在多个韵部中出现，取交集判断
> - 如果某个字在所有韵部中查不到，需标记为"待确认"
> - **绝句**第3句不押韵，不要误判
> - 词牌按各自韵脚位置判断（参见 song-ci-rules.md）

---

### 核查步骤 ⑤：结构检测

#### 唐诗结构检查

| 体式 | 句数 | 字数 | 检查方法 |
|:----:|:----:|:----:|----------|
| 五绝 | 4 | 每句5字 | 逐一数每句汉字数 |
| 七绝 | 4 | 每句7字 | 逐一数每句汉字数 |
| 五律 | 8 | 每句5字 | 逐一数每句汉字数 |
| 七律 | 8 | 每句7字 | 逐一数每句汉字数 |

句数字数任何一处不符 → 出律。

#### 词牌结构检查

参见 `references/song-ci-rules.md` 中各词牌的 `chars_per_line` 信息。核查时：

2. 逐句统计汉字字数
3. 与词牌谱式逐句比对

### 核查步骤 ⑥：对仗检测（仅律诗）

**律诗对仗位置**：
- **颔联**（第3、4句）→ 必须对仗
- **颈联**（第5、6句）→ 必须对仗
- 首联和尾联可对可不对

**对仗核查清单**：

| 核查项 | 说明 | 校验方法 |
|--------|------|----------|
| 词性相对 | 名词对名词，动词对动词，形容词对形容词 | 逐词判断词性是否匹配 |
| 结构相应 | 主谓对主谓，动宾对动宾 | 判断短语结构类型 |
| 平仄相反 | 对应位置平仄相反 | 逐字比对已标注的平仄 |
| 避免合掌 | 两句意思不能重复 | 理解句意，不重复 |

**对仗评分速查**：

| 对仗情况 | 评分 | 说明 |
|----------|:----:|------|
| 完全工对，词性结构平仄皆准 | 9-10 | 优秀 |
| 基本对仗，偶有词性偏差但不影响 | 6-8 | 良好 |
| 仅结构相似但词性多处不对 | 3-5 | 勉强 |
| 完全不对仗或只字面相对 | 0-2 | 不合格 |

## 七、常见问题快速诊断

| 现象 | 最可能原因 | 解决方法 |
|------|-----------|----------|
| 读起来拗口 | 平仄不交替 | 检查"二四六"位置是否平仄交错 |
| 某句意思凑合 | 凑韵 | 换用同韵部更自然的字 |
| 两句意思重复 | 合掌 | 一句写景、一句抒情，或换角度 |
| 感觉太像古人 | 意象套用 | 加个人独特的观察或感受 |
| 不知道某个字平仄 | 可能是入声 | 查入声字速查索引 |
| 韵脚感觉不对 | 韵部混用 | 用平水韵表核对各韵脚是否同一韵部 |
