# 宋词格律规则参考

## 一、词的基本概念

**词**：又称"长短句""诗余""曲子词"，是配合燕乐而创作的歌词。词有固定的曲调（词牌），每个词牌规定了特定的句式、字数、平仄和押韵位置。

**词牌**：词的曲调名称，如《浣溪沙》《念奴娇》《水调歌头》等。同一词牌可能有多种"体"（变体）。

**词谱**：记录词牌格律的谱式，标明每句的字数、平仄和韵脚位置。

**阕**：词的一段。单片词称"单调"，双片词上段称"上阕/上片"，下段称"下阕/下片"。

## 二、常见词牌格律速查

### 小令（58字以内）

#### 《浣溪沙》（42字）
双调，上片三平韵，下片两平韵，下片前两句需对仗。

```
仄仄平平仄仄平（韵），平平仄仄仄平平（韵），平平仄仄仄平平（韵）。
仄仄平平平仄仄，平平仄仄仄平平（韵）。平平仄仄仄平平（韵）。
```

```

仄平平仄仄（换仄韵），仄仄平平仄（仄韵）。
```

```
西北望长安，可怜无数山。
```

示例：苏轼《水调歌头》

#### 《沁园春》（114字）
双调，上片四平韵，下片五平韵。上片四言句多为扇面对。

示例：毛泽东《沁园春·雪》
```
北国风光，千里冰封，万里雪飘。
望长城内外，惟余莽莽；大河上下，顿失滔滔。
山舞银蛇，原驰蜡象，欲与天公试比高。
须晴日，看红装素裹，分外妖娆。
江山如此多娇，引无数英雄竞折腰。
惜秦皇汉武，略输文采；唐宗宋祖，稍逊风骚。
一代天骄，成吉思汗，只识弯弓射大雕。
俱往矣，数风流人物，还看今朝。
```

## 三、词的结构特征

### 句式特点

1. **长短句交错**：词的核心特征是句式长短不一，不像诗那样整齐划一
2. **领字**：词中特有现象，一字或数字引领全句，如"望""看""念""更""且"等
3. **扇面对**：在《沁园春》等词牌中，四言句两两相对形成扇面

### 词的章法

| 结构要素 | 说明 |
|----------|------|
| **起句** | 开篇定调，可写景起、抒情起、叙事起、议论起 |
| **过片/换头** | 下片首句，是词意转折的关键位置，需承上启下 |
| **结句** | 收束全篇，"结句须要放开，有余不尽之意" |
| **情景关系** | 上片写景下片抒情，或情景交融 |

### 常见的词牌类型

| 类型 | 风格特征 | 代表词牌 |
|------|----------|----------|
| 婉约派 | 含蓄蕴藉、婉转细腻 | 《浣溪沙》《蝶恋花》《声声慢》《如梦令》 |
| 豪放派 | 气势恢宏、意象壮阔 | 《念奴娇》《水调歌头》《满江红》《沁园春》 |
| 闲适派 | 清新自然、平淡恬静 | 《鹧鸪天》《采桑子》《西江月》 |

## 四、词的押韵特点

1. **韵位疏密不定**：不同词牌韵位密度不同，小令较密，长调较疏
2. **可平仄换韵**：部分词牌允许平仄韵转换（如《菩萨蛮》），部分一韵到底
3. **入声独立**：入声字自成一类，不与平上去通押（需严格遵守）

## 五、创作检查清单

完成创作后逐项检查：
- [ ] 字数是否符合词牌要求
- [ ] 句数是否正确（上下片各几句）
- [ ] 每句的字数是否与词谱一致（特别注意长短句位置）
- [ ] 平仄是否符合词谱（关注可平可仄的位置）
- [ ] 押韵位置和韵部是否正确
- [ ] 是否使用了领字（如需的话）
- [ ] 过片是否自然流畅
- [ ] 上片下片内容是否有层次
- [ ] 整体意境是否符合所选词牌的风格特征
