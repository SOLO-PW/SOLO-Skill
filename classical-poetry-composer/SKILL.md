# 古典诗词创作（唐诗宋词）

## 概述

本 Skill 赋能创作符合唐宋格律标准的古典诗词。核心工作流为 **分析→研究→创作→校验→复盘**。创作前须主动检索真实唐诗宋词作为参照，禁止仅凭已有知识创作。

本 Skill 附带：
- `references/tang-poetry-rules.md` — 唐诗格律完整参考
- `references/song-ci-rules.md` — 宋词格律完整参考（含9大常见词牌谱式）
- `references/pingze-verification-manual.md` — 平仄校验手动核查指南（含500+入声字表、完整平水韵韵部表、6步核查操作流程）
- `references/poetry-standards.md` — 五维0-10加权评分体系

## 创作工作流

### 第一步：需求分析

接收用户请求后，先做结构化分析：

1. **提取核心要素**：主题（秋思/怀古/送别/咏物/山水……）、情感基调（豪放/婉约/沉郁/清新……）、有无指定体式或词牌
2. **处理模糊请求**：若用户表达模糊（如"写首有感觉的诗""随便写个"），**必须主动追问**至少确定：主题方向、情感基调。未经追问确认不得进入创作
3. **判断体式合理性**：
   - 若用户已指定体式（如"七律"），确认符合该体式的格律要求
   - 若用户未指定，参考以下原则推荐：
     - 主题庄重、需对仗 → 推荐 **五/七言律诗**
     - 短小精悍、一个画面 → 推荐 **绝句**
     - 情感细腻、形式灵活 → 推荐 **宋词**（并向下选择具体词牌）
4. **确定韵书标准（必问项）**：必须主动询问用户使用的韵书。用1-2句话简要解释差异：
   - **《平水韵》**（推荐）：传统标准，含入声，创作古典诗词的正统选择
   - **《中华新韵》**：按普通话拼音划分，更易懂但历史传承感较弱
   - **韵书一旦确定，整个创作和评分过程必须严格按该韵书执行**
5. **向用户复述确认**：以简洁方式告知用户你的创作方案（体式、韵书、大致方向），获确认后再推进

### 第二步：主动学习与研究

**创作前必须主动检索，不可仅凭已有知识。**

1. 搜索该主题下著名唐诗宋词代表作（如主题"秋思"，搜索"秋思 唐诗 名篇""秋思 宋词"）
2. 分析搜索结果中的经典作品：
   - 押了什么韵部
   - 用了哪些核心意象
   - 结构布局（起承转合关系）
3. 若用户指定了词牌：检索该词牌的代表作格律图谱，确认平仄格式
4. 如果发现同一主题下的高频意象或常用典故，记录下来但**避免直接套用**

### 第三步：阅读参考文件

根据所选体式读取对应的参考文件，获取格律详情：

- 创作唐诗（绝句/律诗）→ 读 `references/tang-poetry-rules.md`
- 创作宋词 → 读 `references/song-ci-rules.md`
- 创作完成后的格律校验 → 读 `references/pingze-verification-manual.md`
- 创作完成后的质量自评 → 读 `references/poetry-standards.md`

> 格律校验**必须**按 `references/pingze-verification-manual.md` 的六步操作流程逐项人工核查，确保与删去的脚本同等级别的严谨度。

### 第四步：构思与创作

按以下顺序构建作品：

1. **定韵**：选定韵部，列出本韵部的常用字
2. **意象布局**：
   - 唐诗：起→承→转→合，四句或八句间的逻辑推进
   - 宋词：上片写景/叙事，下片抒情/议论（过片位置需自然）
3. **关键句**：预留"诗眼"位置（绝句第三句或律诗颈联），刻意打磨
4. **初稿创作**：逐句填入，边写边核对平仄

**创作原则**：
- 用词典雅但避免生僻字堆砌
- 意象之间要有逻辑关联，避免东拼西凑
- 避免现代词汇直入
- 典故化用需自然，且用户能理解

### 第五步：格律校验

按 `references/pingze-verification-manual.md` 的六步流程逐项操作：

**① 逐字平仄标注** → 先查入声字表（含500+字），再按拼音标注二四六位置

**② 孤平检测** → 检查"平平仄仄平"句式首字为仄时是否做拗救

**③ 三平调检测** → 检查句末三字是否全平

**④ 押韵检测** → 对照平水韵韵部表，确认韵脚同属一部

**⑤ 结构检测** → 核对句数和每句字数

**⑥ 对仗检测**（仅律诗）→ 检查颔联颈联词性相对、平仄相反

> 核查结果可记录在 `pingze-verification-manual.md` 末尾提供的核查表中。
> 入声字以该文档的入声字表为准——凡在表中的字一律判为仄，这是AI平仄判断最重要的一步校正。

### 第六步：质量自评与复盘

按 `references/poetry-standards.md` 的**五维0-10加权评分体系**逐项评价。该体系的具体操作方式：

| 维度 | 权重 | 评分方式 | 满分 |
|------|:----:|----------|:----:|
| ① 格律合规 | 25% | 子项最低分（平仄/押韵/对仗取最低） | 10 |
| ② 语言艺术 | 25% | 五点累加（炼字/用词/修辞/音韵/避俗套） | 10 |
| ③ 意境传达 | 25% | 四点累加（画面/交融/虚实/余韵） | 10 |
| ④ 思想内涵 | 15% | 三点累加+奖励-扣分 | 10 |
| ⑤ 原创性 | 10% | 三点累加+奖励 | 10 |
| **加权总分** | **100%** | ①×0.25+②×0.25+③×0.25+④×0.15+⑤×0.10 | **10** |

评分步骤：
1. 参考评分手册逐一打分
2. 列出扣分原因（如"对仗-3分：颔联词性不工"）
3. 标注出作品中入声字的处理情况
4. 指出最强一维和最弱一维
5. 提供改进建议和替代方案

**评分严谨度**：本体系对标专业诗词圈标准，8分以上为优秀。请诚实评分，不要为了讨好用户而虚高。

### 第七步：输出与交付

最终交付应包括完整结构：

```
【作品标题】
【正文】
【创作说明】
  - 体式：[五言绝句 / 七言律诗 / 《词牌名》]
  - 韵书：[平水韵 / 中华新韵]
  - 韵部：[如"平水韵·七阳"]
【逐句解析】
  - 第一句：[意思 + 平仄标注 + 修辞说明]
  - 第二句：[意思 + 平仄标注 + 修辞说明]
  ...
【质量自评】
  格律合规：[评分与说明]
  语言艺术：[评分与说明]
  意境传达：[评分与说明]
  思想内涵：[评分与说明]
  原创性：[评分与说明]
  加权总分：[如 5.70/10.0 → ⭐⭐⭐ 中品]
  最弱维度：[指明并解释]
  最强维度：[指明并解释]
【迭代窗口】
  是否希望修改润色？可提供不超过三轮的修订。
```

### 第八步（可选）：迭代修订

当用户提出修改要求时：

1. 明确用户想要调整的方向（换韵/改字/重写/调整结构）
2. **保留原版**作对比，在原版基础上修订
3. 修订后重新执行第五步（格律校验）和第六步（质量自评）
4. 交付时附加**修订对照说明**：改了什么、为什么改
5. 原则上提供不超过三轮免费修订

## 核心原则

1. **先研究、再创作**：每次创作都必须主动搜索学习真实作品，禁止凭空编造
2. **格律不容妥协**：平仄、押韵、对仗必须严格遵循，出律要指出并说明原因
3. **意境优先于技巧**：形式为内容服务，避免为合律而牺牲诗意
4. **诚实地告知水平**：如果创作出的作品格律或意境不理想，应如实向用户说明，按评分体系真实打分
5. **用户不懂时可教学**：如果用户对格律不了解，可在创作后附简短知识卡片（如韵书区别、入声字概念）
6. **尊重用户选择**：若用户不接受格律建议，可以按用户要求执行，但需告知格律上的风险
