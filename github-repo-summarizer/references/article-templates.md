# 文章模板库

## 概述

本文档提供面向普通群众的开源项目推荐文章模板，用通俗易懂的语言介绍项目。

## 通用推荐模板

### 轻松推荐风格

```markdown
# [项目名称]：[一句话吸引人的描述]

![项目截图](图片URL)

## 🌟 这是什么？

[用2-3句话介绍项目是什么，能做什么，解决什么问题]

想象一下，[用一个生活化的场景让用户理解项目价值]。

## ✨ 有什么亮点？

- **[亮点1名称]**：[用通俗语言描述，突出用户能感受到的好处]
- **[亮点2名称]**：[用通俗语言描述，突出用户能感受到的好处]
- **[亮点3名称]**：[用通俗语言描述，突出用户能感受到的好处]
- **[亮点4名称]**：[用通俗语言描述，突出用户能感受到的好处]

## 🎯 能用来做什么？

- **[场景1]**：[具体的使用场景，让用户能想象到]
- **[场景2]**：[具体的使用场景，让用户能想象到]
- **[场景3]**：[具体的使用场景，让用户能想象到]

## 📊 大家都在用吗？

- ⭐ **受欢迎程度**：[Star数量 + 通俗解读]
- 🔥 **活跃程度**：[最后更新时间 + 通俗解读]
- 👥 **社区氛围**：[贡献者数量 + 通俗解读]
- 📜 **使用许可**：[许可证 + 通俗解读]

## 🚀 怎么体验？

[提供最简单的体验方式]

## 🔗 想了解更多？

- 📂 [项目主页](URL)
- 📖 [使用说明](URL)
- 💬 [交流社区](URL)

## 💝 推荐理由

[用1-2句话总结推荐理由，像朋友推荐一样真诚]
```

## 通俗描述转化示例

### 技术特性 → 用户价值

| 技术特性 | 通俗描述 |
|----------|----------|
| 响应式设计 | 手机电脑都能用，自动适应屏幕 |
| 实时同步 | 数据实时更新，不用手动刷新 |
| 离线支持 | 没网也能用，有网自动同步 |
| 多语言支持 | 支持中文、英文等多种语言 |
| 暗黑模式 | 有深色主题，晚上用不刺眼 |
| 快捷键支持 | 键盘快捷键，操作更快 |
| 导出功能 | 可以导出文件，方便分享 |
| 搜索功能 | 强大的搜索，快速找到想要的 |
| 拖拽操作 | 拖拖拽拽就能完成操作 |
| 自动保存 | 自动保存，不怕丢失 |

### 性能指标 → 使用感受

| 性能指标 | 使用感受 |
|----------|----------|
| 加载速度快 | 打开就用，不用等待 |
| 内存占用低 | 不卡顿，老电脑也能用 |
| 体积小 | 下载快，不占空间 |
| 启动速度快 | 秒开，立即使用 |
| 响应时间短 | 操作即响应，很跟手 |

## 标题生成示例

### 好标题示例
- ✅ `QuantumOS：在浏览器里体验《流浪地球》的MOSS系统`
- ✅ `这个开源工具让你的照片秒变艺术画`
- ✅ `有了它，再也不怕忘记密码了`
- ✅ `想做个炫酷的个人网站？这个工具帮你搞定`
- ✅ `程序员必备：这个代码编辑器太好用了`
- ✅ `免费！开源！这个记事本应用比付费的还好用`

### 坏标题示例
- ❌ `基于React和TypeScript的高性能Web框架`（太技术化）
- ❌ `一个开源项目`（太笼统）
- ❌ `GitHub上的一个仓库`（没有吸引力）
- ❌ `使用Next.js开发的Web应用`（用户不关心技术）

## 场景描述示例

### 好场景示例
- ✅ `想做个炫酷的个人网站？用它就对了！`
- ✅ `需要管理一堆文件？它帮你整理得井井有条`
- ✅ `想体验科幻电影里的AI系统？这个能满足你`
- ✅ `每次开会都要记笔记？这个工具帮你自动生成`
- ✅ `想学编程但不知道从哪开始？这个项目是你的入门好帮手`

### 坏场景示例
- ❌ `适用于Web开发`（太笼统）
- ❌ `可用于前端项目构建`（太技术化）
- ❌ `适合各种场景`（没有具体信息）
- ❌ `可以用来做很多事情`（没有价值）
