# 沟通技巧练习手册

## 使用说明

本文档提供系统化的沟通技巧练习，帮助你从"知道"到"做到"。沟通是一项技能，需要通过练习来掌握。建议每周练习2-3次，持续一个月会有明显改善。

---

## 一、基础练习

### 练习1：情绪识别

**目标**：提高识别和命名情绪的能力

**练习方式**：
每天花5分钟，写下你今天感受到的3种情绪，并尝试精确描述。

**示例**：
| 时间 | 情绪 | 精确描述 |
|------|------|---------|
| 早上 | 不开心 | 因为昨晚和女友吵架，感到有点委屈和担心 |
| 中午 | 开心 | 收到女友的消息，感到被关心和温暖 |
| 晚上 | 疲惫 | 工作一天很累，但想到女友又觉得有动力 |

**进阶练习**：
尝试识别女友的情绪，从她的文字、语气、行为中判断。

**记录表**：

| 日期 | 她的表现 | 我判断的情绪 | 准确度 |
|------|---------|-------------|--------|
| | | | |
| | | | |
| | | | |

### 练习2：积极倾听

**目标**：提高倾听能力，让对方感到被理解

**练习方式**：
找一个朋友或伴侣，进行10分钟的对话练习。

**规则**：
1. 一方说话时，另一方只能听
2. 不打断、不评判、不给建议
3. 用身体语言表示在听（点头、眼神接触）
4. 说完后，听的人复述："你的意思是......"
5. 说的人确认或纠正

**检查清单**：
- [ ] 放下了手机
- [ ] 看着对方的眼睛
- [ ] 没有打断
- [ ] 复述了对方的话
- [ ] 表达了理解

---

### 练习3：非暴力沟通

**目标**：学会用"我"表达感受，而不是用"你"指责

**练习方式**：
把以下指责性表达转换为非暴力沟通：

**练习题**：

| 指责性表达 | 非暴力沟通 |
|-----------|-----------|
| "你总是不理我！" | |
| "你根本不在乎我！" | |
| "你怎么又忘了！" | |
| "你能不能别玩手机了！" | |
| "你从来不关心我！" | |

**参考答案**：

| 指责性表达 | 非暴力沟通 |
|-----------|-----------|
| "你总是不理我！" | "我发了消息但没收到回复，我感到有点担心和失落。我希望你能在我发消息后回复我，哪怕只是一个表情" |
| "你根本不在乎我！" | "我感到自己不被重视，这让我很难过。我需要感受到你在乎我。你能告诉我，你最近是不是有什么事？" |
| "你怎么又忘了！" | "这件事你没有做到，我感到有点失望。我希望我们能一起想办法，确保下次不会再忘" |
| "你能不能别玩手机了！" | "你玩手机的时候，我感到被冷落了。我希望我们在一起的时候能多一些互动" |
| "你从来不关心我！" | "我感到自己没有被关心，这让我很孤单。我需要你的关心和陪伴。你能每天问问我今天怎么样吗？" |

## 二、进阶练习

### 练习4：温和启动

**目标**：学会在冲突开始时用温和的方式表达

**练习方式**：
把以下"硬启动"转换为"温和启动"：

**练习题**：

| 硬启动 | 温和启动 |
|--------|---------|
| "你为什么又加班！" | |
| "你能不能靠谱一点！" | |
| "你到底想怎样！" | |
| "你每次都这样！" | |
| "你是不是有别人了！" | |

**参考答案**：

| 硬启动 | 温和启动 |
|--------|---------|
| "你为什么又加班！" | "我知道你工作很忙，但我有点想你了。今天能早点回来吗？" |
| "你能不能靠谱一点！" | "这件事让我有点失望，我希望我们能一起想办法解决" |
| "你到底想怎样！" | "我感觉到你有些不满，能告诉我你的真实想法吗？" |
| "你每次都这样！" | "这件事发生过几次了，我感到有点累。我们能好好谈谈吗？" |
| "你是不是有别人了！" | "我最近有点不安，可能是我太敏感了。你能给我一些安全感吗？" |

### 练习5：共情回应

**目标**：学会回应对方的情绪，而不是只回应内容

**练习方式**：
对于以下情境，先识别她的情绪，再给出共情回应：

**练习题**：

| 情境 | 她的情绪 | 共情回应 |
|------|---------|---------|
| 她说："今天工作好累啊" | | |
| 她说："我闺蜜又和她男朋友吵架了" | | |
| 她说："我妈又催我结婚了" | | |
| 她说："我今天被领导骂了" | | |
| 她说："我胖了好多" | | |

**参考答案**：

| 情境 | 她的情绪 | 共情回应 |
|------|---------|---------|
| 她说："今天工作好累啊" | 疲惫、需要安慰 | "辛苦了宝贝，抱抱你。今天发生什么了？和我说说" |
| 她说："我闺蜜又和她男朋友吵架了" | 担心、八卦、可能联想到自己 | "怎么回事？她还好吗？（如果她继续说，认真听）" |
| 她说："我妈又催我结婚了" | 压力、可能有点焦虑 | "你是不是感到有压力？你怎么想的？" |
| 她说："我今天被领导骂了" | 委屈、难过 | "抱抱你，被骂肯定很难受。发生了什么？" |
| 她说："我胖了好多" | 自我怀疑、需要肯定 | "在我眼里你一直很好看。不过如果你想去运动，我陪你～" |

### 练习6：道歉的艺术

**目标**：学会真诚有效的道歉

**道歉的四个步骤**：
1. **承认错误**：明确说出你做错了什么
2. **表达理解**：说明你理解对方的感受
3. **承担责任**：不找借口
4. **承诺改进**：给出具体的改进方案

**练习题**：

| 情境 | 道歉练习 |
|------|---------|
| 你忘记了一周年纪念日 | |
| 你回消息太慢了 | |
| 你说了伤人的话 | |
| 你没有兑现承诺 | |
| 你在外人面前让她没面子 | |

**参考答案**：

**忘记纪念日**：
"我忘记了一周年纪念日，这是我的错。我知道这让你很失望，觉得我不重视你。没有任何借口，我应该记住的。我现在就去准备补救，以后我会设置提醒，确保不会再忘"

**回消息慢**：
"我回消息太慢了，让你等了很久。我知道等待的感觉很不好，可能让你担心了。以后如果我忙，我会先告诉你一声"

**说伤人的话**：
"我刚才说的话太伤人了，对不起。我知道那些话让你很难过。我不应该那样说，以后我会注意自己的言辞"

**没有兑现承诺**：
"我没有做到答应你的事，我知道这让你失望了。我说到没有做到，是我的问题。我会重新承诺，并且这次一定做到"

**在外人面前让她没面子**：
"我刚才在外人面前那样说你，让你没面子了。我知道这很伤人，我应该维护你而不是让你难堪。以后我会注意，有什么问题我们私下说"

## 三、高级练习

### 练习7：情绪调节

**目标**：学会在情绪激动时保持冷静

**练习方式**：
当你感到情绪激动时，使用以下步骤：

1. **暂停**：深呼吸3次
2. **识别**：我现在感到什么情绪？
3. **评估**：这个情绪的强度是1-10分？
4. **选择**：我现在应该怎么做？
   - 继续冷静沟通
   - 告诉对方我需要冷静一下
   - 暂时离开，稍后再谈

### 练习8：需求表达

**目标**：学会清晰地表达自己的需求

**练习方式**：
用以下句式表达你的需求：

"当......（情境）的时候，我感到......（情绪），因为我需要......（需求）。你能不能......（具体请求）？"

**练习题**：

| 情境 | 需求表达练习 |
|------|-------------|
| 她总是迟到 | |
| 她不回消息 | |
| 她和异性朋友走得太近 | |
| 她不做家务 | |
| 她总是抱怨 | |

**参考答案**：

**她总是迟到**：
"我们约好时间但你迟到了，我感到有点失落，因为我很期待和你见面，也希望我们的时间能被尊重。你能不能以后如果会晚到，提前告诉我一声？"

**她不回消息**：
"我发了消息但没收到回复，我感到有点担心和不安，因为我很在乎我们的联系。你能不能忙的时候先告诉我一声，这样我就不用担心了？"

**她和异性朋友走得太近**：
"你和XX走得很近，我感到有点不安和吃醋，因为我需要安全感。你能不能告诉我，你们是什么关系？这样我就能安心了"

**她不做家务**：
"我做了大部分家务，感到有点累和不公平，因为我希望我们能一起分担。你能不能每周负责......？"

**她总是抱怨**：
"你经常抱怨，我感到有点压力，因为我希望我们在一起是开心的。你能不能告诉我，是什么让你这么不满？我们一起想办法解决"

### 练习9：冲突修复

**目标**：学会在冲突后修复关系

**冲突修复的五个步骤**：

1. **冷静下来**：给双方时间冷静
2. **主动破冰**：打破沉默
3. **承认责任**：承认自己的问题
4. **表达理解**：理解对方的感受
5. **提出改进**：给出解决方案

**练习题**：
回忆一次你们的冲突，用以上五个步骤写出你会怎么做。

## 七、常见问题

### Q: 练习时总是忘记怎么办？

**A**: 设置提醒，或者把练习和日常行为绑定（比如每天睡前写情绪日记）。

### Q: 练习了但伴侣没有注意到怎么办？

**A**: 坚持练习，改变需要时间。也可以和伴侣分享你在学习沟通，邀请她一起练习。

### Q: 练习时感觉很刻意怎么办？

**A**: 刚开始学习任何技能都会感觉刻意，坚持练习就会变得自然。

### Q: 练习了但还是会吵架怎么办？

**A**: 练习是为了减少冲突，不是消除冲突。吵架后用学到的技巧修复关系，也是进步。

## 八、重要提醒

1. **坚持练习**：沟通是技能，需要练习才能掌握
2. **不要放弃**：改变需要时间，给自己和伴侣耐心
3. **实践为主**：看再多技巧，不如实际练习一次
4. **共同成长**：邀请伴侣一起学习，效果更好
5. **接受不完美**：没有人能做到完美，重要的是持续改进

---

> 💡 **核心洞察**：沟通不是天赋，而是技能。通过系统化的练习，每个人都可以成为更好的沟通者。开始练习吧，你会发现关系变得不一样。
