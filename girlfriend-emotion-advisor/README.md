# 女友话术分析与情绪解读

一个温暖、专业、贴心的情感沟通助手，帮你读懂女朋友的真实想法，提供有温度又有实操性的应对建议。本 Skill 不仅提供话术，更提供心理学理论支撑和系统化的沟通能力提升方案。

> 说明：这是目录「说明文档」。具体的执行规范、工作流程与规则见 [SKILL.md](SKILL.md)。

## 功能简介

当你在恋爱沟通中遇到困惑时，这个 Skill 可以帮你：

- **情绪判断**：分析女友消息背后的真实情绪状态
- **话术解读**：解读表面文字下的深层含义和需求
- **关系阶段分析**：根据对话判断你们所处的关系阶段
- **应对建议**：提供多种风格的回复方案和后续跟进建议
- **心理学解读**：用依恋理论、爱的五种语言等解释行为模式
- **沟通模式分析**：识别和改善不良沟通模式
- **冲突预防**：提供关系维护和冲突预防建议
- **案例参考**：学习成功和失败的真实案例
- **技能提升**：系统化的沟通技巧练习

## 学习路径

- **基础话术（1-2 周）**：阅读 [SKILL.md](SKILL.md) 了解流程，学习 [情绪解读指南](references/emotion-guide.md)，使用 [应对策略库](references/response-strategies.md) 应对具体场景。
- **心理学理解（2-3 周）**：学习 [心理学理论基础](references/psychology-foundation.md) 与 [沟通模式分析](references/communication-patterns.md)，阅读 [真实案例库](references/case-studies.md)。
- **预防与提升（3-4 周）**：学习 [冲突预防指南](references/conflict-prevention.md)，使用 [沟通技巧练习](references/communication-exercises.md)，建立每日情感存款和关系检查习惯。

## 注意事项

- 本 Skill 提供的是沟通建议，不能替代专业的心理咨询。
- 每对情侣都有自己的相处模式，建议根据实际情况调整。
- 最重要的永远是真诚和直接沟通。
- 所有分析基于用户提供的信息，可能存在偏差。

## 核心理念

> 💡 **理解比话术更重要**：理解她行为背后的心理需求，比记住一百个话术更有用。本 Skill 的目标不仅是帮你解决眼前的问题，更是帮你成为更好的沟通者。
