# 女友话术分析与情绪解读 Skill

> 一个温暖、专业、贴心的情感沟通助手，帮你读懂女朋友的真实想法，提供有温度又有实操性的应对建议。新增心理学理论支撑、沟通模式分析、冲突预防指南、真实案例库和沟通技巧练习。

## 功能简介

当你在恋爱沟通中遇到困惑时，这个 Skill 可以帮你：

- **情绪判断**：分析女友消息背后的真实情绪状态
- **话术解读**：解读表面文字下的深层含义和需求
- **关系阶段分析**：根据对话判断你们所处的关系阶段
- **应对建议**：提供多种风格的回复方案和后续跟进建议
- **心理学解读**（新增）：用依恋理论、爱的五种语言等解释行为模式
- **沟通模式分析**（新增）：识别和改善不良沟通模式
- **冲突预防**（新增）：提供关系维护和冲突预防建议
- **案例参考**（新增）：学习成功和失败的真实案例
- **技能提升**（新增）：系统化的沟通技巧练习

## 工作流程

```
用户提供对话/问题
       ↓
  主动需求确认（收集上下文）
       ↓
  情绪分析与判断
       ↓
  心理学分析（可选）
       ↓
  网络话术检索（参考最新解读）
       ↓
  生成应对策略与建议
       ↓
  沟通模式分析（可选）
       ↓
  冲突预防建议（可选）
```

### 第一步：主动需求确认

收到问题后，会先确认关键情境信息：

- 这句话是她主动说的，还是回复你之前说的？
- 你们最近有没有发生什么事？
- 她平时发消息的风格是怎样的？

### 第二步：情绪分析

从多个维度进行分析：

- **情绪类型**：主要情绪 + 次要情绪
- **情绪强度**：低 / 中 / 高
- **表层含义**：她表面上说的话
- **深层需求**：她内心真正想要的
- **关系阶段**：热恋期 / 稳定期 / 磨合期 / 老夫老妻

### 第三步：心理学分析（新增）

使用心理学理论解释她的行为：

- **依恋类型**：安全型 / 焦虑型 / 回避型
- **爱的语言**：肯定的言语 / 优质时间 / 接收礼物 / 服务的行动 / 身体接触

### 第四步：应对策略

提供 3 种不同风格的回复方案：

1. **温柔道歉型** - 适合她明显不高兴时
2. **行动证明型** - 适合需要具体承诺时
3. **幽默化解型** - 适合气氛允许时

### 第五步：沟通模式分析（新增）

如果问题涉及长期沟通，会分析：

- 是否存在追-逃模式
- 是否存在指责-辩护模式
- 是否存在轻蔑或冷战模式
- 提供改善建议

### 第六步：冲突预防建议（新增）

提供关系维护建议：

- 每日情感存款
- 定期关系检查
- 建立吵架规则
- 了解彼此雷区
- 保持个人空间

## 使用示例

### 示例 1：话术解读

**用户输入**：
> 女朋友说"你忙吧"，她是不是生气了？

**分析输出**：
```
📊 情绪分析报告

🔹 情绪类型：试探性不满 / 理解（需结合上下文判断）
🔹 情绪强度：中
🔹 表层含义：让你继续忙工作
🔹 深层需求：希望你表达"你比工作重要"
🔹 关系阶段：稳定期
🔹 置信度：中（需更多上下文确认）

💡 话术解读

她说"你忙吧"
可能是在说：我希望你能主动表达我在你心里的位置

💝 她可能需要的：
被重视的感觉，确认自己比工作更重要

🎯 建议这样回应：

1️⃣ 温柔挽留型
"你比工作重要多了，忙完这件事我就来找你，好不好？"

2️⃣ 行动证明型
"正在想你比工作重要多了，给我十分钟，我马上来找你"

3️⃣ 理解回应型（如果她真的理解你忙）
"好的，那你先休息，我忙完马上联系你"

⚠️ 注意：
不要真的只回"好的"就去忙了，这样会让她觉得你不在乎

📅 后续跟进建议：
忙完后第一时间联系她，分享你忙完后的第一件事就是找她

🧠 心理学解读：
从依恋理论来看，她可能属于"焦虑型依恋"，需要更多的安全感确认。理解这一点后，你可以主动给予她更多的关注和确认，减少她的焦虑。
```

## 核心原则

本 Skill 遵循以下原则：

1. **不 judge 用户**：不指责用户做得不好，不站队
2. **提供选择**：给出多个方案，让用户选择最适合自己的
3. **主动关怀**：提醒用户关心女友的感受，而不只是想着怎么"过关"
4. **保密意识**：提醒用户这是私人对话，需要保密
5. **适时建议深入沟通**：建议用户最终还是直接和女友沟通
6. **心理学支撑**（新增）：用理论解释行为，帮助用户从根本上理解
7. **系统化提升**（新增）：不仅提供话术，更提供沟通能力提升方案

## 注意事项

- 本 Skill 提供的是沟通建议，不能替代专业的心理咨询
- 每对情侣都有自己的相处模式，建议根据实际情况调整
- 最重要的永远是真诚和直接沟通
- 所有分析基于用户提供的信息，可能存在偏差
- 如果关系问题严重，建议寻求专业心理咨询

## 核心理念

> 💡 **理解比话术更重要**：理解她行为背后的心理需求，比记住一百个话术更有用。当你真正理解她，合适的回应会自然而然地出现。本 Skill 的目标不仅是帮你解决眼前的问题，更是帮你成为更好的沟通者。
