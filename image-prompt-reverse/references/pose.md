| 姿态 | 特征 | 氛围 | 提示词 |

## 姿态提示词模板

### 单人姿态

```
[身体姿态] + [手臂位置] + [腿部姿势] + [头部方向] + [表情] + [氛围]

示例:
Standing with weight shifted to one leg, arms crossed, looking at camera with confident smile, powerful and assertive
```

### 双人姿态

```
[互动方式] + [相对位置] + [身体接触] + [视线关系] + [氛围]

示例:
Couple facing each other, holding hands, gazing into each other's eyes, romantic and intimate atmosphere
```

### 动态姿态

```
[动作类型] + [运动方向] + [肢体状态] + [动感效果] + [情绪]

示例:
Dancing with arms raised, twirling motion, flowing dress, joyful and energetic expression
```

### 静态姿态

```
[基础姿态] + [细节描述] + [支撑物] + [放松程度] + [氛围]

示例:
Sitting in armchair, legs crossed, one hand resting on armrest, relaxed and thoughtful mood
```

## 姿态分析检查清单

分析人物姿态时检查：

- [ ] 身体整体姿态（站/坐/躺/动态）
- [ ] 头部方向和倾斜
- [ ] 眼神方向和注视点
- [ ] 手臂和手部位置
- [ ] 腿部和脚部位置
- [ ] 身体重心和平衡
- [ ] 与环境的互动
- [ ] 姿态传达的情绪
