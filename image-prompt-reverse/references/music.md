## 音乐提示词模板

### 演奏场景

```
[乐手] + [乐器] + [演奏姿态] + [环境] + [光线] + [氛围]

示例:
Musician playing electric guitar on stage, dynamic pose, concert lighting, dramatic spotlights, energetic rock atmosphere
```

### 乐器特写

```
[乐器类型] + [材质] + [细节] + [角度] + [光线] + [背景]

示例:
Classical guitar with rosewood body, detailed wood grain, close-up, warm side lighting, dark background
```

### 音乐会场景

```
[演出类型] + [舞台] + [灯光] + [观众] + [氛围]

示例:
Rock concert stage with dramatic lighting, crowd silhouettes, neon lights, energetic and loud atmosphere
```

### 录音室场景

```
[设备] + [环境] + [人物] + [动作] + [氛围]

示例:
Recording studio with mixing console, musician singing into microphone, professional equipment, creative atmosphere
```

## 音乐分析检查清单

分析音乐图片时检查：

- [ ] 乐器类型识别
- [ ] 演奏姿态和手法
- [ ] 乐手表情和情绪
- [ ] 演出环境（舞台/录音室/户外）
- [ ] 灯光效果
- [ ] 观众反应（如有）
- [ ] 整体氛围和情绪
