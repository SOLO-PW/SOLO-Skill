## 功能概述

### 什么是交互式精调

交互式精调是指在初始提示词生成后，用户可以：
- 指定图片中的特定区域进行重点分析
- 调整某些元素的描述方式
- 修改权重分配
- 改变输出风格
- 添加或删除某些描述

### 适用场景

| 场景 | 说明 |
|------|------|
| 细节遗漏 | 初始分析遗漏了某些重要细节 |
| 重点偏移 | 用户希望强调某个特定元素 |
| 风格调整 | 需要调整整体风格方向 |
| 权重优化 | 某些元素权重需要调整 |
| 格式适配 | 需要针对特定模型优化 |

---

## 交互式精调流程

### 标准流程

```
Step 1: 初始分析完成
  └─ 输出初始提示词

Step 2: 用户反馈
  ├─ 指定需要精调的区域/元素
  ├─ 说明期望的调整方向
  └─ 提供额外信息或偏好

Step 3: 精调分析
  ├─ 针对指定区域重新分析
  ├─ 调整描述方式
  └─ 优化权重分配

Step 4: 输出精调结果
  ├─ 展示修改对比
  └─ 说明调整原因

Step 5: 确认或继续
  ├─ 用户满意 → 完成
  └─ 需要继续 → 返回Step 2
```

### 交互式对话示例

```
用户: 帮我反推这张图片的提示词

AI: [初始分析和提示词输出]

用户: 请重点分析一下背景的光线效果，我想要更强调那种逆光的感觉

AI: [针对背景光线的精调分析]
已将"soft lighting"调整为"dramatic backlit silhouette with golden rim light"
权重从1.0提升至1.3

用户: 很好，另外服装的描述能更详细一些吗？

AI: [针对服装的精调分析]
已扩展服装描述：
原: "wearing black dress"
新: "wearing elegant black velvet dress with lace trim and pearl buttons, fitted silhouette"

用户: 完美，谢谢！

AI: [输出最终精调后的提示词]
```

## 精调选项

### 精调类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 区域精调 | 指定图片区域重点分析 | "重点分析左上角的光线" |
| 元素精调 | 调整特定元素描述 | "服装描述更详细" |
| 风格精调 | 调整整体风格方向 | "更偏动漫风格" |
| 权重精调 | 调整元素权重 | "提高主体权重" |
| 格式精调 | 针对特定模型优化 | "针对Midjourney优化" |

### 精调指令

用户可以使用以下指令进行精调：

| 指令 | 说明 | 示例 |
|------|------|------|
| 重点分析 | 对某区域/元素重点分析 | "重点分析眼睛的细节" |
| 更详细 | 要求更详细的描述 | "服装描述更详细" |
| 更简洁 | 要求更简洁的描述 | "背景描述更简洁" |
| 强调 | 强调某个元素 | "强调光影对比" |
| 弱化 | 弱化某个元素 | "弱化背景描述" |
| 改变风格 | 调整描述风格 | "改为动漫风格描述" |
| 添加 | 添加缺失元素 | "添加配饰描述" |
| 删除 | 删除不需要的元素 | "删除文字描述" |

## 区域指定分析

### 区域划分

将图片划分为9个区域：

```
┌─────┬─────┬─────┐
│ 左上 │ 中上 │ 右上 │
├─────┼─────┼─────┤
│ 左中 │ 中央 │ 右中 │
├─────┼─────┼─────┤
│ 左下 │ 中下 │ 右下 │
└─────┴─────┴─────┘
```

### 区域指定方式

用户可以通过以下方式指定区域：

| 方式 | 示例 |
|------|------|
| 方位词 | "左上角"、"右侧"、"中央" |
| 相对位置 | "人物后面"、"画面边缘" |
| 具体元素 | "眼睛部分"、"背景建筑" |

### 区域分析示例

```
用户: 重点分析一下图片右侧的光线效果

AI: 右侧光线分析：
- 光源类型：自然光，从右侧窗户射入
- 光线强度：中等强度，柔和扩散
- 光线颜色：暖色调，略带金色
- 阴影效果：在左侧形成柔和阴影
- 高光位置：人物右侧面部和肩膀

提示词调整：
原: "natural lighting"
新: "soft diffused window light from right side, warm golden tones, gentle shadows on left"
权重：1.1 → 1.3
```

## 风格微调

### 风格调整选项

| 调整方向 | 说明 | 关键词变化 |
|----------|------|------------|
| 更写实 | 增加写实感 | 添加 photorealistic, realistic |
| 更动漫 | 增加动漫感 | 添加 anime style, illustration |
| 更艺术 | 增加艺术感 | 添加 artistic, painterly |
| 更商业 | 增加商业感 | 添加 commercial, professional |
| 更复古 | 增加复古感 | 添加 vintage, retro |
| 更现代 | 增加现代感 | 添加 modern, contemporary |

### 风格微调示例

```
用户: 我想要更偏动漫风格的提示词

AI: 风格调整：
原风格: photorealistic, professional photography
新风格: anime illustration style, cel shading, vibrant colors, detailed character design

调整说明：
- 移除了摄影相关描述
- 添加了动漫风格关键词
- 调整了色彩描述为动漫常用色调
- 添加了动漫特有的技法描述
```

## 权重调整

### 权重调整方式

| 调整类型 | SD语法 | MJ语法 | 说明 |
|----------|--------|--------|------|
| 提高权重 | (word:1.3) | word::3 | 增加元素重要性 |
| 降低权重 | (word:0.8) | word::0.5 | 降低元素重要性 |
| 最高权重 | (word:1.5) | word::5 | 核心元素 |
| 普通权重 | word | word | 默认权重 |

### 权重调整建议

| 元素类型 | 建议权重范围 | 说明 |
|----------|--------------|------|
| 核心主体 | 1.3-1.5 | 最重要的识别特征 |
| 关键特征 | 1.2-1.3 | 重要的外貌/特征 |
| 风格词 | 1.1-1.2 | 艺术风格修饰 |
| 环境词 | 0.9-1.1 | 背景环境描述 |
| 质量词 | 1.1-1.3 | 质量增强词 |

### 权重调整示例

```
用户: 我希望更强调人物的服装

AI: 权重调整：
原: wearing black dress (权重: 1.0)
新: (wearing elegant black velvet dress:1.3) with (intricate lace details:1.2)

调整说明：
- 服装描述权重从1.0提升至1.3
- 添加了服装细节描述，权重1.2
- 保持其他元素权重不变
```

## 输出格式优化

### 格式优化选项

| 优化类型 | 说明 | 示例 |
|----------|------|------|
| 长度优化 | 调整提示词长度 | "更简洁"或"更详细" |
| 结构优化 | 调整描述顺序 | "先描述风格再描述主体" |
| 语法优化 | 调整语法结构 | "改为自然语言描述" |
| 模型适配 | 针对特定模型优化 | "针对SD优化" |

### 模型适配优化

```
用户: 请针对Midjourney优化这个提示词

AI: Midjourney优化：

原SD格式:
(beautiful woman:1.3), (long silver hair:1.2), (wearing white dress:1.1), (forest background:1.0), (cinematic lighting:1.2), 8k, highly detailed

优化后MJ格式:
beautiful woman with long flowing silver hair, wearing elegant white dress, enchanted forest background, cinematic lighting, ethereal atmosphere, fantasy art --ar 2:3 --v 6 --s 250

优化说明：
- 移除了权重语法
- 添加了自然语言连接词
- 补充了氛围描述
- 添加了MJ专用参数
```

## 精调对话模板

### 精调请求模板

用户可以使用以下模板进行精调请求：

```
[精调指令] + [精调对象] + [期望效果]

示例：
- "重点分析背景光线，我想要更梦幻的效果"
- "服装描述更详细，添加材质描述"
- "提高主体权重，弱化背景"
- "针对NijiJourney优化，更偏可爱风格"
```

### 精调响应模板

AI响应精调请求时使用：

```
精调内容：
[精调对象] - [调整说明]

调整详情：
原: [原描述]
新: [新描述]
权重: [原权重] → [新权重]

调整原因：
[说明为什么这样调整]

精调后提示词：
[完整的精调后提示词]
```

## 精调检查清单

完成精调后检查：

- [ ] 精调是否符合用户需求
- [ ] 权重分配是否合理
- [ ] 描述是否保持一致性
- [ ] 是否引入了矛盾
- [ ] 整体风格是否协调
- [ ] 长度是否合适
- [ ] 格式是否适配目标模型
- [ ] 是否保留了核心特征

---

## 精调最佳实践

### 1. 保持核心不变

精调时保持核心主体和关键特征不变，只调整修饰和细节。

### 2. 渐进式调整

每次精调只调整1-2个方面，避免大幅改动。

### 3. 记录变更

清晰记录每次精调的变更，方便用户理解。

### 4. 提供选项

当有多种精调方向时，提供选项让用户选择。

### 5. 验证一致性

精调后检查描述是否一致，避免矛盾。
