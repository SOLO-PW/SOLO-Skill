## 艺术提示词模板

### 古典艺术风格

```
[艺术时期] style, [技法特征], [主题], [色彩], [氛围]

示例:
Baroque style, chiaroscuro lighting, dramatic religious scene, rich golden tones, emotional and intense
```

### 现代艺术风格

```
[艺术运动] inspired, [技法], [形式], [色彩], [情感]

示例:
Impressionist inspired, visible brushstrokes, garden scene, vibrant colors, light and airy atmosphere
```

### 数字艺术风格

```
[数字技法], [风格], [细节], [渲染], [质量]

示例:
Digital painting, fantasy concept art, highly detailed character, dramatic lighting, 8k, masterpiece
```

### 插画风格

```
[插画类型], [技法], [色彩], [线条], [用途]

示例:
Children's book illustration, watercolor technique, soft pastel colors, gentle lines, whimsical and magical
```

## 艺术风格检查清单

分析艺术风格时检查：

- [ ] 艺术时期/运动识别
- [ ] 技法特征（笔触/线条/色彩）
- [ ] 构图方式
- [ ] 色彩运用
- [ ] 光影处理
- [ ] 主题内容
- [ ] 情感表达
- [ ] 整体氛围
