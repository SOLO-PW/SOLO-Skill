## 时尚提示词模板

### 整体穿搭描述

```
[风格] outfit, [上装], [下装], [鞋履], [配饰], [色彩], [场合]

示例:
Casual streetwear outfit, oversized graphic hoodie, slim-fit jeans, white sneakers, baseball cap, neutral tones, everyday look
```

### 单品详细描述

```
[品牌感] [类型], [材质], [颜色], [设计细节], [搭配方式]

示例:
Luxurious silk blouse, ivory white, delicate ruffle collar, tucked into high-waisted trousers
```

### 风格氛围描述

```
[风格] aesthetic, [色彩情绪], [材质组合], [整体气质]

示例:
Minimalist Scandinavian aesthetic, muted earth tones, mix of wool and leather, clean and sophisticated
```

### 季节穿搭描述

```
[季节] [场景] outfit, [层次], [材质], [色彩], [氛围]

示例:
Autumn city walk outfit, layered knit sweater over collared shirt, warm earth tones, cozy and stylish
```

- [ ] 整体风格（经典/现代/复古/特殊）

- [ ] 下装类型和款式
- [ ] 鞋履类型和风格
- [ ] 包袋类型和搭配
- [ ] 首饰和配饰
- [ ] 色彩搭配方案
- [ ] 面料和质感
- [ ] 妆容和发型
- [ ] 整体气质和场合
