## 天气提示词模板

### 基础天气描述

```
[天气类型] + [光线效果] + [氛围情绪] + [视觉特征]

示例:
Overcast sky with soft diffused light, moody atmosphere, gray clouds covering the sun
```

### 雨天场景描述

```
[雨量] + [效果] + [氛围] + [环境]

示例:
Heavy rain with water droplets on window, dramatic atmosphere, city lights reflecting on wet streets
```

### 雪景描述

```
[雪量] + [覆盖效果] + [氛围] + [季节感]

示例:
Gentle snowfall with white ground cover, peaceful winter wonderland, serene and magical atmosphere
```

### 特殊天气描述

```
[天气现象] + [视觉效果] + [情绪氛围] + [环境影响]

示例:
Dense morning fog with low visibility, mysterious and ethereal atmosphere, trees fading into mist
```

## 天气分析检查清单

分析图片天气时检查：

- [ ] 天气类型（晴/阴/雨/雪/特殊）
- [ ] 云量和云层厚度
- [ ] 光线质量（直射/散射/反射）
- [ ] 能见度（清晰/朦胧/模糊）
- [ ] 地面状态（干燥/湿润/积雪）
- [ ] 色彩倾向（暖/冷/灰暗/明亮）
- [ ] 氛围情绪（欢快/忧郁/神秘/宁静）
- [ ] 特殊现象（彩虹/雾凇/闪电等）
