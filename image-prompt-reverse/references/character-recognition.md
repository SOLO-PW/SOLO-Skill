## 识别原则

### 核心原则

1. **特征组合匹配** - 不依赖单一特征，通过发型+发色+眼睛+服装+配饰的组合判断
2. **作品风格关联** - 识别画风后缩小角色范围
3. **标志性元素优先** - 优先匹配最具辨识度的特征（如独特配饰、发型）
4. **不确定时描述特征** - 无法确定具体角色时，详细描述可见特征而非猜测

### 识别置信度

| 置信度 | 判断标准 | 输出方式 |
|--------|----------|----------|
| 高 | 3个以上标志性特征匹配 | 直接说出角色名和作品 |
| 中 | 2个特征匹配，风格吻合 | "疑似为XX作品中的XX角色" |
| 低 | 仅有1个特征匹配 | 不猜测角色名，详细描述特征 |

## 角色识别流程

```
Step 1: 识别作品风格
  ├─ 日式动漫 → 进入Step 2
  ├─ 美式卡通 → 进入Step 2
  ├─ 国漫/韩漫 → 进入Step 2
  └─ 无法判断风格 → 直接描述特征

Step 2: 提取角色特征
  ├─ 发型（长度、颜色、形状、标志性造型）
  ├─ 眼睛（颜色、形状、特殊效果）
  ├─ 服装（校服、制服、战甲、日常装）
  ├─ 配饰（发饰、武器、道具、耳环等）
  └─ 其他（动物伙伴、纹身、特殊标记）

Step 3: 特征匹配
  ├─ 高置信度匹配 → 输出角色名+作品
  ├─ 中置信度匹配 → 输出疑似角色+特征描述
  └─ 低置信度/无匹配 → 详细描述所有可见特征

Step 4: 生成角色描述
  └─ 按角色描述框架组织输出
```

## 特征匹配方法

### 高辨识度特征（权重最高）

以下特征最具辨识度，优先匹配：

| 特征类型 | 说明 | 示例 |
|----------|------|------|
| 独特发型 | 非常规造型、标志性发色 | 刺猬头、双马尾、渐变发色 |
| 标志性配饰 | 角色专属物品 | 护额、面具、特定武器 |
| 独特服装 | 角色标志性穿着 | 校服款式、战斗服 |
| 特殊标记 | 身体上的独特标记 | 纹身、伤疤、特殊瞳色 |
| 动物伙伴 | 角色常伴的动物 | 小龙、猫、精灵 |

### 中辨识度特征

| 特征类型 | 说明 |
|----------|------|
| 发色 | 常见色（黑/棕/金）辨识度低，罕见色（粉/蓝/紫/红）辨识度高 |
| 瞳色 | 特殊瞳色（异色瞳、金色、红色）辨识度高 |
| 体型 | 特殊体型（极高、极矮、特殊比例） |
| 表情习惯 | 角色标志性表情 |

### 低辨识度特征

| 特征类型 | 说明 |
|----------|------|
| 常规服装 | 普通校服、日常装 |
| 常规发型 | 常见短发、长发 |
| 常规发色 | 黑色、棕色 |

## 角色描述框架

### 识别成功时

```
角色名 (作品名)
├─ 基本信息: 性别、年龄外观、身高体型
├─ 外貌特征: 发型发色、眼睛颜色、面部特征
├─ 服装造型: 标志性服装、配饰、武器
├─ 表情姿态: 角色标志性表情或姿态
└─ 风格参考: 作品画风、官方设定图风格
```

### 识别失败时

```
未知角色
├─ 基本信息: 性别、年龄外观、身高体型
├─ 外貌特征: 发型发色（详细）、眼睛颜色（详细）、面部特征
├─ 服装造型: 服装类型、颜色、配饰、武器（详细描述）
├─ 标志性元素: 最独特的1-2个视觉特征
├─ 画风推测: 可能的作品风格或地区风格
└─ 参考建议: 可参考的类似角色或风格
```

## 角色提示词模板

### 已识别角色模板

**Stable Diffusion:**
```
(角色名:1.3), (作品名 style:1.2), [角色标志性特征描述], [服装描述], [表情姿态], [背景], [画风描述], masterpiece, best quality, highly detailed

示例:
(Anya Forger:1.3), (Spy x Family style:1.2), (pink short hair:1.2), (green eyes:1.1), (hair ornaments:1.1), wearing school uniform, surprised expression, holding stuffed penguin, classroom background, anime illustration style, masterpiece, best quality
```

**Midjourney:**
```
角色名 from 作品名, [标志性特征], [服装], [表情姿态], [背景], [画风] --ar 比例 --niji 版本 --style 风格

示例:
Anya Forger from Spy x Family, pink short hair with hair ornaments, green eyes, school uniform, surprised expression, classroom background, anime illustration --ar 2:3 --niji 6 --style cute
```

**DALL-E 3:**
```
Anya Forager from the anime Spy x Family. A young girl with short pink hair and green eyes, wearing hair horn ornaments. She is wearing a school uniform and has a surprised expression. Anime illustration style with soft colors.
```

### 未识别角色模板

当无法识别具体角色时，使用详细特征描述：

```
[性别] anime character with [详细发型描述], [详细眼睛描述], wearing [详细服装描述], [配饰描述], [表情姿态], [背景], [画风推测], highly detailed, masterpiece

示例:
Male anime character with spiky silver hair and black mask covering lower face, wearing dark blue outfit with metal forehead protector tilted to cover one eye, holding a kunai, serious expression, forest background, ninja anime style, highly detailed, masterpiece
```

### 角色Cosplay/真人风格模板

当图片是真人cosplay或3D写实风格的角色时：

```
cosplay photography of [角色名] from [作品名], [角色特征描述], realistic portrayal, [服装材质描述], [摄影风格], [质量词]
```

## 角色识别注意事项

### 同一角色不同形态

许多角色有多种形态，需要识别当前形态：

| 形态类型 | 示例 | 处理方式 |
|----------|------|----------|
| 变身形态 | 超级赛亚人、九尾模式 | 描述当前形态 |
| 年龄变化 | 小时候vs长大后 | 描述当前年龄外观 |
| 服装变化 | 日常装vs战斗装 | 描述当前服装 |
| 状态变化 | 觉醒后、黑化后 | 描述当前状态 |

### 原创角色处理

当图片是原创角色（非已知作品角色）时：

1. **不要强行匹配**已知角色
2. 详细描述所有可见特征
3. 说明"疑似原创角色"
4. 提供风格参考建议

### AI生成角色处理

当图片是AI生成的角色时：

1. 识别画风（哪个AI模型或哪种风格）
2. 描述角色的设计特征
3. 说明"AI生成角色"
4. 提供风格关键词以便复现

## 性别识别精准指南（并入自 gender-identification.md）

> 人物/角色识别包含性别识别，故合并至此文档。本节提供系统化的性别识别方法，帮助准确判断图片中人物的性别特征，避免误认。

### 性别识别原则

#### 核心原则

1. **多重验证原则** - 不要依赖单一特征，需要至少2-3个特征交叉验证
2. **服装优先原则** - 服装款式通常是最明显的性别指示器
3. **发型辅助原则** - 发型是重要但非决定性特征
4. **面部特征谨慎原则** - 动漫/插画风格中面部特征可能中性化，需谨慎判断
5. **不确定性标注** - 当无法确定时，使用中性描述或明确标注不确定性

#### 识别优先级

```
高优先级 (决定性特征):
- 服装款式 (裙子/西装等)
- 身体轮廓 (明显性别特征)
- 配饰 (领带/项链等)

中优先级 (辅助特征):
- 发型长度和款式
- 面部轮廓
- 姿态和肢体语言

低优先级 (参考特征):
- 色彩偏好
- 装饰元素
- 背景暗示
```

### 男性特征识别

#### 服装特征

| 类别 | 关键词 | 确定性 |

### 模糊/中性特征处理

#### 中性服装

以下服装**不能**作为性别判断依据：

- T-shirt, hoodie, sweater (基础款)
- jeans, pants (基础款)
- jacket, coat (无明显性别特征)
- sneakers, boots (基础款)

#### 中性发型

以下发型**不能**单独作为性别判断依据：

- medium length hair
- straight hair (无明显造型)
- simple ponytail (无装饰)
- bangs/fringe (单独存在时)

#### 动漫/插画风格的特殊性

在动漫风格中，以下特征可能高度中性化：

- 大眼睛 (男女通用)
- 光滑皮肤 (男女通用)
- 纤细身材 (男女通用)
- 柔和面部轮廓 (男女通用)

**处理策略**:
1. 优先依赖服装判断
2. 结合发型长度和款式
3. 查看是否有明确的性别化配饰
4. 若仍不确定，使用中性描述

#### 不确定性处理

当无法确定性别时，使用以下策略：

1. **使用中性描述词**:
   - "a person" 代替 "a man/woman"
   - "androgynous appearance"
   - "gender-neutral style"

2. **描述可见特征而非推断性别**:
   - 描述服装而非说"穿着女装"
   - 描述发型而非说"女性发型"

3. **明确标注不确定性**:
   - "性别特征不明显，可能为..."
   - "中性风格，难以确定性别"

### 常见误认场景

#### 场景1: 动漫少年/少女

**问题**: 动漫风格中少年和少女特征相似

**解决方案**:
- 查看服装是否有明显性别特征
- 注意发型长度 (极短=男性概率高，极长=女性概率高)
- 查看是否有面部毛发
- 查看配饰 (领带vs蝴蝶结等)

#### 场景2: 中性风格角色

**问题**: 刻意的中性化设计

**解决方案**:
- 优先描述可见特征
- 避免强行指定性别
- 使用"androgynous"等中性描述词

#### 场景3: 背影/侧影

**问题**: 无法看到面部和正面服装

**解决方案**:
- 依赖发型轮廓
- 依赖身体轮廓
- 依赖可见的服装部分
- 不确定时标注"从背影看..."

#### 场景4: 非二元性别/跨性别表达

**问题**: 性别表达与生理性别可能不一致

**解决方案**:
- 描述可见的性别表达特征
- 避免假设生理性别
- 尊重图片呈现的性别表达
