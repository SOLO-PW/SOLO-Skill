## 游戏提示词模板

### 游戏角色

```
[角色类型] + [装备] + [姿态] + [环境] + [风格] + [氛围]

示例:
Fantasy knight in shining armor, holding sword and shield, standing heroically, medieval castle background, RPG style, epic and heroic
```

### 游戏场景

```
[场景类型] + [环境元素] + [光线] + [氛围] + [风格]

示例:
Enchanted forest with glowing mushrooms, magical particles, moonlight filtering through trees, mystical atmosphere, fantasy RPG style
```

### 游戏战斗

```
[角色] + [敌人] + [动作] + [特效] + [环境] + [氛围]

示例:
Warrior fighting dragon, dynamic combat pose, fire breathing, medieval arena, epic battle, intense action
```

### 游戏概念图

```
[场景/角色] + [设计元素] + [色彩] + [构图] + [风格]

示例:
Sci-fi space station concept art, metallic structures, blue and orange color scheme, wide angle view, detailed environment design
```
