## 建筑提示词模板

### 古典建筑

```
[建筑风格], [主要元素], [材料], [装饰], [氛围]

示例:
Gothic cathedral with pointed arches and flying buttresses, stone masonry, stained glass windows, dramatic and sacred atmosphere
```

### 现代建筑

```
[建筑类型], [设计风格], [材料], [特征], [环境]

示例:
Modern skyscraper with glass curtain wall, steel and glass, sleek and minimalist, urban skyline setting
```

### 室内空间

```
[空间类型], [风格], [材料], [光线], [氛围]

示例:
Grand lobby with marble floors, classical style, natural light from skylight, luxurious and elegant atmosphere
```

### 建筑细节

```
[元素类型], [风格], [材料], [装饰], [效果]

示例:
Ornate Baroque ceiling with gold leaf decoration, intricate plasterwork, dramatic lighting, opulent and grand
```

## 建筑分析检查清单

分析建筑图片时检查：

- [ ] 建筑风格识别（古典/现代/地域）
- [ ] 建筑类型（住宅/商业/宗教/公共）
- [ ] 主要材料（石材/砖/玻璃/金属/木材）
- [ ] 屋顶形式（平顶/坡顶/穹顶/尖顶）
- [ ] 门窗特征（拱门/落地窗/天窗）
- [ ] 装饰元素（雕刻/图案/色彩）
- [ ] 结构特征（柱子/拱券/悬挑）
- [ ] 环境关系（城市/自然/景观）
