## 运动提示词模板

### 动态运动瞬间

```
[运动员] + [动作] + [运动项目] + [环境] + [动感效果]

示例:
Athlete sprinting on track, explosive running motion, 100m dash, stadium background, motion blur
```

### 运动环境描述

```
[运动场地] + [天气条件] + [氛围] + [观众/环境]

示例:
Football stadium on sunny day, exciting match atmosphere, cheering crowd, green pitch
```

### 运动装备描述

```
[运动类型] + [装备细节] + [动作姿态] + [专业感]

示例:
Tennis player with racket, athletic pose, professional sportswear, competitive spirit
```

### 极限运动描述

```
[运动类型] + [极限环境] + [动作技巧] + [肾上腺素感]

示例:
Rock climber on steep cliff, gripping handhold, extreme altitude, adrenaline rush
```

## 运动分析检查清单

分析运动图片时检查：

- [ ] 运动类型识别
- [ ] 运动员姿态和动作
- [ ] 运动装备细节
- [ ] 场地环境特征
- [ ] 比赛状态（进行中/暂停/庆祝）
- [ ] 光线和氛围
- [ ] 动态效果（冻结/模糊）
- [ ] 观众和环境元素
