## 车辆提示词模板

### 汽车外观

```
[品牌] [车型], [颜色], [角度], [环境], [光线], [氛围]

示例:
Red Ferrari 488 GTB, glossy Rosso Corsa, three-quarter front view, mountain road, golden hour light, dynamic and powerful
```

### 汽车内饰

```
[品牌] [车型] interior, [材质], [色彩], [配置], [氛围]

示例:
Mercedes-Benz S-Class interior, leather seats, dark wood trim, ambient lighting, luxurious and modern
```

### 摩托车

```
[类型] motorcycle, [品牌], [颜色], [姿态], [环境], [风格]

示例:
Sportbike motorcycle, Ducati Panigale, red and black, leaning into corner, mountain road, aggressive and fast
```

### 交通场景

```
[场景类型], [车辆元素], [时间], [天气], [氛围]

示例:
Busy city intersection at night, multiple cars with light trails, rainy weather, neon reflections, urban cyberpunk atmosphere
```

## 车辆分析检查清单

分析车辆图片时检查：

- [ ] 车辆类型（轿车/SUV/跑车等）
- [ ] 品牌识别（如可识别）
- [ ] 车身颜色和涂装
- [ ] 拍摄角度（正面/侧面/后面）
- [ ] 环境场景（城市/公路/赛道）
- [ ] 光线条件（自然光/人造光）
- [ ] 动态状态（静止/行驶/特技）
- [ ] 特殊元素（改装/装饰/涂鸦）
