## 自然提示词模板

### 山地景观

```
[山体类型] + [植被状态] + [天气条件] + [光线效果] + [氛围]

示例:
Snow-capped mountain peaks with green valleys, clear sky, golden hour sunlight, majestic and serene atmosphere
```

### 水域景观

```
[水体类型] + [水面状态] + [岸边特征] + [天空反射] + [氛围]

示例:
Calm mountain lake with mirror reflection, pine trees along shore, clear blue sky, peaceful and tranquil mood
```

### 森林景观

```
[森林类型] + [树木特征] + [光照效果] + [地面元素] + [氛围]

示例:
Ancient forest with towering trees, sunbeams filtering through canopy, moss-covered ground, mysterious and ethereal atmosphere
```

### 草原景观

```
[草原类型] + [草地状态] + [天空特征] + [特殊元素] + [氛围]

示例:
Vast golden grassland under dramatic sky, lone tree in distance, wind-swept meadow, expansive and free atmosphere
```

## 自然景观检查清单

分析自然景观时检查：

- [ ] 景观类型（山/水/林/草/沙漠）
- [ ] 地形特征（高度/坡度/形状）
- [ ] 植被状态（种类/密度/颜色）
- [ ] 水体特征（类型/状态/颜色）
- [ ] 天空状况（云量/颜色/光线）
- [ ] 季节判断（春/夏/秋/冬）
- [ ] 时间判断（日出/正午/日落/夜晚）
- [ ] 特殊现象（彩虹/云海/光束等）
