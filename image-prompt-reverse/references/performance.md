## 演出提示词模板

### 舞台表演

```
[表演者] + [表演类型] + [动作姿态] + [舞台] + [灯光] + [氛围]

示例:
Ballet dancer performing on stage, elegant pose, dramatic spotlight, dark theater, graceful and beautiful
```

### 音乐会场景

```
[表演者] + [乐器/声音] + [舞台] + [灯光] + [观众] + [氛围]

示例:
Rock band performing on stage, guitarist soloing, colorful stage lights, excited crowd, energetic atmosphere
```

### 戏剧场景

```
[演员] + [角色] + [场景] + [布景] + [灯光] + [情绪]

示例:
Actor in dramatic scene, classical theater setting, moody lighting, intense emotion, theatrical
```

### 舞蹈表演

```
[舞者] + [舞蹈类型] + [动作] + [服装] + [舞台] + [氛围]

示例:
Contemporary dancers in fluid motion, modern dance, flowing costumes, minimalist stage, emotional performance
```

## 演出分析检查清单

分析演出图片时检查：

- [ ] 表演类型（戏剧/舞蹈/音乐/魔术）
- [ ] 表演者姿态和动作
- [ ] 服装和造型
- [ ] 舞台布景
- [ ] 灯光效果
- [ ] 观众反应（如有）
- [ ] 整体氛围和情绪
