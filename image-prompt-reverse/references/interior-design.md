## 空间布局

### 空间类型

| 空间 | 功能 | 布局特点 | 提示词 |
|------|------|----------|--------|
| 客厅 | 社交，休闲 | 沙发组合，焦点墙 | living room, lounge, sitting area |
| 卧室 | 休息，私密 | 床为中心，对称 | bedroom, sleeping area, master suite |
| 厨房 | 烹饪，储物 | 工作三角，岛台 | kitchen, cooking area, chef's kitchen |
| 餐厅 | 用餐，社交 | 餐桌为中心 | dining room, dining area, eating space |
| 书房 | 工作，学习 | 书桌，书架 | study, home office, library |
| 浴室 | 洗浴，护理 | 干湿分离 | bathroom, washroom, spa-like |

### 布局原则

| 原则 | 说明 | 提示词 |
|------|------|--------|
| 对称 | 平衡，正式 | symmetrical layout, balanced arrangement |
| 不对称 | 动态，自由 | asymmetrical layout, dynamic arrangement |
| 开放式 | 通透，连贯 | open plan, open concept, flowing space |
| 分区 | 功能明确 | zoned layout, distinct areas, functional zones |
| 动线 | 流畅通行 | good circulation, clear pathways, flow |

### 空间感

| 感受 | 特征 | 提示词 |
|------|------|--------|
| 开放 | 大空间，通透 | spacious, open, airy, expansive |
| 温馨 | 小空间，舒适 | cozy, intimate, snug, warm |
| 高挑 | 高天花板 | high ceiling, loft-like, grand height |
| 紧凑 | 空间利用 | compact, efficient, space-saving |

## 室内提示词模板

### 空间整体描述

```
[风格] [空间类型], [色彩基调], [主要材质], [氛围]

示例:
Modern minimalist living room, neutral color palette, wood and metal accents, clean and serene atmosphere
```

### 家具组合描述

```
[主要家具], [材质], [色彩], [布局方式]

示例:
L-shaped gray fabric sofa, walnut coffee table, symmetrical arrangement, centered on fireplace
```

### 软装搭配描述

```
[窗帘类型], [地毯类型], [抱枕], [灯具], [装饰品]

示例:
Floor-length sheer curtains, large area rug, colorful throw pillows, pendant light, indoor plants
```

### 氛围营造描述

```
[光线效果], [色彩情绪], [材质触感], [整体氛围]

示例:
Soft natural light from large windows, warm earth tones, mix of wood and linen textures, cozy and inviting atmosphere
```

## 室内设计检查清单

分析室内图片时检查：

- [ ] 设计风格（现代/传统/特殊）
- [ ] 空间类型（客厅/卧室/厨房等）
- [ ] 空间布局（对称/开放/分区）
- [ ] 主要家具（类型/材质/颜色）
- [ ] 软装搭配（窗帘/地毯/抱枕）
- [ ] 灯具类型（吊灯/落地灯/台灯）
- [ ] 装饰品（画作/花瓶/绿植）
- [ ] 色彩搭配（主色/辅色/点缀色）
- [ ] 材质运用（木/石/金属/织物）
- [ ] 整体氛围（温馨/现代/奢华）
