## 美食摄影基础

### 美食摄影要素

| 要素 | 说明 | 分析重点 |
|------|------|----------|
| 主体 | 食物本身 | 种类、状态、质感 |
| 摆盘 | 食物摆放方式 | 造型、层次、空间 |
| 光线 | 照明效果 | 方向、质感、氛围 |
| 背景 | 环境和道具 | 材质、色彩、风格 |
| 细节 | 食物细节 | 纹理、光泽、热气 |

### 美食摄影风格

| 风格 | 特点 | 适用场景 | 提示词 |
|------|------|----------|--------|
| 商业广告 | 精致、完美 | 菜单、广告 | commercial food photography, advertisement style |
| 生活记录 | 自然、真实 | 博客、社交媒体 | lifestyle food photography, casual dining |
| 复古怀旧 | 暖调、质感 | 复古餐厅、家庭 | vintage food photography, nostalgic |
| 极简现代 | 简洁、留白 | 高端餐厅、杂志 | minimalist food photography, clean |
| 过程记录 | 动态、步骤 | 烹饪教学 | cooking process, step by step |

## 食物特征分析

### 食物状态

| 状态 | 描述 | 提示词 |
|------|------|--------|
| 新鲜 | 刚制作，最佳状态 | fresh, just made, freshly prepared |
| 热气 | 冒着热气 | steaming, hot, steam rising |
| 融化 | 芝士、巧克力融化 | melted, gooey, stretchy |
| 脆皮 | 酥脆表面 | crispy, crunchy, golden crust |
| 多汁 | 内部汁水丰富 | juicy, succulent, moist |
| 酱汁 | 淋有酱汁 | drizzled, sauce, glaze |

### 食物质感

| 质感 | 视觉特征 | 提示词 |
|------|----------|--------|
| 光滑 | 表面光滑有光泽 | glossy, shiny, smooth surface |
| 粗糙 | 表面有纹理 | textured, rough, grainy |
| 酥脆 | 层次分明 | flaky, layered, crispy |
| 绵密 | 质地紧密 | dense, creamy, smooth |
| 蓬松 | 质地松软 | fluffy, airy, light |
| 透明 | 半透明质感 | translucent, clear, see-through |

### 食物色彩

| 色彩类型 | 示例 | 提示词 |
|----------|------|--------|
| 金黄 | 烤面包、炸物 | golden brown, golden crust, toasted |
| 翠绿 | 蔬菜、香草 | vibrant green, fresh herbs, leafy |
| 鲜红 | 番茄、肉类 | bright red, vivid red, ripe |
| 棕色 | 巧克力、咖啡 | rich brown, chocolate, deep brown |
| 乳白 | 奶油、牛奶 | creamy white, milky, ivory |
| 橙黄 | 芝士、芒果 | orange, yellow, bright orange |

## 摆盘与构图

### 摆盘风格

| 风格 | 特点 | 提示词 |
|------|------|--------|
| 随意摆放 | 自然、生活感 | casually placed, rustic arrangement |
| 精心摆盘 | 精致、艺术感 | artfully arranged, meticulous plating |
| 对称摆盘 | 平衡、正式 | symmetrical arrangement, balanced |
| 堆叠摆盘 | 层次、立体 | stacked, layered presentation |
| 散落摆盘 | 动态、自然 | scattered, organic arrangement |

### 摆盘技巧

| 技巧 | 说明 | 提示词 |
|------|------|--------|
| 留白 | 盘子留有空间 | negative space on plate, clean rim |
| 高度 | 堆叠增加高度 | vertical presentation, stacked layers |
| 配色 | 色彩搭配和谐 | color contrast, complementary colors |
| 点缀 | 装饰性元素 | garnish, edible flowers, microgreens |
| 酱汁 | 酱汁装饰 | sauce drizzle, sauce art, swoosh |

### 美食构图

| 构图方式 | 适用场景 | 提示词 |
|----------|----------|--------|
| 俯拍 | 多道菜、摆盘展示 | overhead shot, flat lay, top-down view |
| 45度角 | 单道菜、立体感 | 45-degree angle, classic food angle |
| 平视 | 饮品、层次展示 | straight on, eye level, profile view |
| 特写 | 细节、质感展示 | close-up, macro, detailed texture |
| 环境 | 场景、氛围展示 | environmental shot, table setting |

## 美食分析检查清单

分析美食图片时检查：

- [ ] 食物种类和名称
- [ ] 食物状态（热/冷/新鲜/加工）
- [ ] 食物质感（酥脆/柔软/光滑）
- [ ] 摆盘方式和风格
- [ ] 光线类型和方向
- [ ] 背景材质和色彩
- [ ] 道具和装饰元素
- [ ] 整体氛围和风格
- [ ] 色彩搭配和对比
- [ ] 构图角度和景深
