## 科技提示词模板

### 产品特写

```
[产品类型] + [品牌风格] + [材质] + [颜色] + [角度] + [背景] + [光线]

示例:
Premium smartphone with glass back, silver aluminum frame, front view, clean white background, studio lighting, product photography
```

### 使用场景

```
[产品] + [使用环境] + [用户] + [动作] + [氛围]

示例:
Person using wireless headphones in coffee shop, listening to music, relaxed atmosphere, natural light
```

### 科技氛围

```
[产品] + [科技风格] + [光线效果] + [色彩] + [未来感]

示例:
Futuristic laptop with RGB lighting, cyberpunk style, neon glow, dark background, high-tech atmosphere
```

### 产品组合

```
[主要产品] + [配件] + [布局] + [风格] + [氛围]

示例:
MacBook Pro with Magic Keyboard and Mouse, minimal desk setup, clean aesthetic, professional workspace
```

## 科技产品检查清单

分析科技产品时检查：

- [ ] 产品类型识别
- [ ] 品牌风格判断
- [ ] 材质质感描述
- [ ] 颜色和配色
- [ ] 设计语言（极简/未来/工业/赛博）
- [ ] 使用场景和环境
- [ ] 光线和反射效果
- [ ] 科技感和未来感
