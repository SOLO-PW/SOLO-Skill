## 动物提示词模板

### 宠物肖像

```
[品种] [动物], [毛发/羽毛描述], [表情], [姿态], [光线], [背景]

示例:
Golden retriever dog, shiny golden coat, happy expression with tongue out, sitting in grass, warm sunlight, park background
```

### 动物特写

```
[动物] close-up, [特征细节], [表情], [光线], [景深]

示例:
Cat close-up, detailed green eyes with vertical pupils, curious expression, soft window light, shallow depth of field
```

### 动物动作

```
[动物] [动作], [环境], [光线], [动态效果]

示例:
Dog running through autumn leaves, golden hour sunlight, motion blur on legs, joyful and energetic
```

### 野生动物

```
[动物] in [自然栖息地], [行为], [环境], [光线], [氛围]

示例:
Lion resting on savanna rocks, golden hour, African grassland background, majestic and powerful atmosphere
```

## 动物分析检查清单

分析动物图片时检查：

- [ ] 动物种类（犬/猫/鸟/其他）
- [ ] 品种识别（如可识别）
- [ ] 毛发/羽毛类型和颜色
- [ ] 体型大小
- [ ] 面部表情和情绪
- [ ] 姿态和动作
- [ ] 眼睛颜色和神态
- [ ] 环境背景
- [ ] 光线和氛围
- [ ] 与人类的互动（如有）
