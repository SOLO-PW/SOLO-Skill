## 情绪提示词模板

### 面部情绪描述

```
[情绪类型] + [表情细节] + [眼神描述] + [嘴部表情] + [整体氛围]

示例:
Joyful expression with bright eyes and wide smile, radiating happiness and warmth
```

### 肢体情绪描述

```
[姿态情绪] + [肢体动作] + [身体语言] + [情绪强度]

示例:
Relaxed posture with open body language, conveying comfort and ease, gentle and welcoming
```

### 环境情绪描述

```
[场景氛围] + [色调情绪] + [光线效果] + [整体感觉]

示例:
Warm and cozy atmosphere with golden tones, soft lighting creating intimate and inviting mood
```

### 综合情绪描述

```
[主导情绪] + [面部表情] + [肢体语言] + [环境氛围] + [色彩配合]

示例:
Romantic mood with tender expression, gentle embrace, soft candlelight, warm pink and gold tones
```

## 情绪分析检查清单

分析图片情绪时检查：

- [ ] 面部表情识别（眼睛/眉毛/嘴巴）
- [ ] 肢体语言解读（姿态/手势/动作）
- [ ] 环境氛围判断（光线/色调/元素）
- [ ] 色彩情绪关联（暖色/冷色/中性）
- [ ] 整体情绪基调（正面/负面/中性）
- [ ] 情绪强度判断（柔和/中等/强烈）
- [ ] 叙事性情绪（故事性/戏剧性）
