# 🍲 海龟汤文案创作 Skill

> 一个全面、专业、易用的海龟汤（情境猜谜）创作工具集，帮助用户创作高质量的汤面与汤底。

---

## 📖 简介

**海龟汤**（Turtle Soup / Lateral Thinking Puzzle）是一种通过提问来推理出完整故事的益智游戏，包含：
- **汤面**：谜面描述，呈现看似不合理的情境
- **汤底**：真相解答，揭示出人意料但合情合理的反转

本 Skill 提供从入门到精通的全流程创作指南，包含模板、案例、检查清单等实用工具。

## 🚀 快速开始

### 使用方式

当用户请求创作海龟汤时，本 Skill 会自动触发。标准流程：

1. **询问需求**：主题、难度、类型（本格/变格）、特殊要求
2. **选择模板**：根据需求选择合适的汤面/汤底模板
3. **创作内容**：按规范格式编写完整海龟汤
4. **质量检查**：使用逻辑检查清单验证
5. **输出文件**：保存为 `.md` 文件（命名格式：`海龟汤_[主题]_[难度].md`）

### 默认配置

如果用户未指定，默认创作：**中等难度 / 本格 / 悬疑**

## 🎯 核心功能

### 1. 智能需求收集
自动询问用户关键信息：
- 主题偏好（恐怖/悬疑/温情/搞笑/科幻/日常/爱情/其他）
- 难度等级（简单/中等/困难）
- 类型选择（本格/变格）
- 特殊要求

### 2. 模板化创作
提供 5 个汤面模板 + 5 个汤底模板，支持快速组合：
- 异常行为型、突发反应型、发现异常型、物品线索型、循环累积型
- 身份反转型、认知错位型、视角欺骗型、牺牲奉献型、规则异常型

### 3. 质量保障体系
- **5步快速自检**：汤面朗读→反向推理→汤底完整→逻辑漏洞→游戏体验
- **详细检查清单**：汤面质量、汤底质量、本格/变格特殊检查
- **质量评级标准**：5星制评价体系

### 4. 变格规则支持
支持 5 种变格类型：
- 时间循环、灵魂互换、预知未来、规则怪谈、平行世界

## 📝 输出文件格式示例

**文件名**：`海龟汤_悬疑_中等.md`

**文件内容**：

```markdown
# 🍲 海龟汤原版

**主题**：悬疑 | **难度**：中等 | **类型**：本格

---

## 汤面
一个男人走进一家餐厅，点了一碗海龟汤。喝了一口后，他立刻冲出去自杀了。为什么？

---

## 汤底
<details>
<summary>🔍 点击展开查看真相</summary>

### 故事背景
这个男人曾和同伴在海上遇难，漂流到荒岛。

### 事件经过
同伴说用海龟肉煮了汤给他喝，他活了下来被救。多年后，他在餐厅喝到真正的海龟汤，发现味道完全不同——原来当年同伴是用自己的肉煮汤给他喝，为了让他活下去而牺牲了自己。男人发现真相后无法承受，选择了自杀。

### 关键线索解释
- **海龟汤**：表面是海龟肉，实际是人肉
- **喝一口就自杀**：发现味道不同，瞬间明白真相

</details>

---

## 💡 提示线索
1. **轻度**：关注"海龟汤"这个特定食物的选择
2. **中度**：想想为什么喝一口就能确定，而不是吃完
3. **重度**：如果当年喝的不是真正的海龟汤呢？

## 🎯 推理要点

| 玩家可能提问 | 主持人回答 | 推理作用 |
|-------------|-----------|----------|
| 「他是自杀吗？」 | 是 | 确认方向 |
| 「汤里有毒吗？」 | 否 | 排除误导 |
| 「他以前喝过海龟汤吗？」 | 是 | 接近真相 |

---

## 📝 主持人手册

### 回答规范
| 玩家提问类型 | 主持人回应 | 示例 |
|-------------|-----------|------|
| 直接相关 | 「是」或「否」 | 「他是自杀吗？」→「是」 |
| 部分相关 | 拆分回答 | 「被杀或自杀？」→「是其中之一」 |
| 无关问题 | 「无关」 | 「他穿红色衣服吗？」→「无关」 |
| 开放式 | 引导具体化 | 「发生了什么？」→「请具体提问」 |
| 复合问题 | 要求拆分 | 「被刀杀而且在晚上？」→「请分开问」 |

### 游戏节奏控制
- **预期时长**：15-20 分钟
- **常见误区**：猜测汤里有毒、猜测过敏
- **节奏建议**：
  - 5分钟无进展：给出轻度提示
  - 10分钟无进展：给出中度提示
  - 15分钟无进展：给出重度提示
- **跑偏时**：「这个方向暂时得不到有效信息，试试别的角度」
- **接近真相时**：「你能完整描述一下事情的经过吗？」

### 主持人速查表
| 阶段 | 操作 |
|------|------|
| 开场 | 宣读汤面，说明规则（是/否/无关） |
| 推理 | 回答提问，适时给提示 |
| 揭晓 | 展开汤底，复盘推理过程 |
```

2. 尝试 [协作创作](./references/collaboration-guide.md)
