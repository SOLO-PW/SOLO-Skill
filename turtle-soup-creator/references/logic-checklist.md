# 海龟汤逻辑检查清单

## 快速自检流程（创作完成后必做）

> 每次创作完成后，按以下 5 步快速自检。全部通过即可输出。

### Step 1：汤面朗读测试
大声朗读汤面，检查：
- [ ] 2-5 句话，50-150 字
- [ ] 每句话都有存在的意义（无废话）
- [ ] 存在表面矛盾或异常，能引发好奇
- [ ] 不会产生歧义（玩家理解的方向与设计意图一致）

### Step 2：反向推理测试
假设自己是玩家，只看汤面：
- [ ] 能提出至少 3 个具体问题
- [ ] 通过提问能逐步接近真相（存在推理路径）
- [ ] 不会被某个显而易见的答案直接猜中（除非简单难度）

### Step 3：汤底完整性测试
检查汤底是否包含：
- [ ] 故事背景（时间、地点、人物）
- [ ] 事件经过（起因、发展、结果）
- [ ] 人物动机（为什么这么做）
- [ ] 关键线索解释（汤面中每个异常都有对应）

### Step 4：逻辑漏洞测试
逐项检查四类常见漏洞：
- [ ] **时间逻辑**：时间线连贯，人物有足够时间完成行为
- [ ] **空间逻辑**：场景合理，人物移动路径可行
- [ ] **人物逻辑**：行为符合身份/性格，动机充分，能力匹配
- [ ] **信息逻辑**：汤底没有引入汤面完全没有暗示的信息

### Step 5：游戏体验测试
- [ ] 揭晓真相时有「原来如此」的满足感
- [ ] 不会被「被耍了」的负面感受
- [ ] 主持人能清晰回答玩家的各种提问

---

## 详细检查项（遇到问题时查阅）

### 汤面质量

**信息控制**：
- [ ] 关键线索已隐藏，但汤面中留有痕迹
- [ ] 没有透露过多信息导致过于简单
- [ ] 没有遗漏必要信息导致无法推理
- [ ] 误导信息与真相信息比例适当（建议 1:1 或 2:1）

**语言表达**：
- [ ] 用词准确，避免歧义
- [ ] 关键信息自然融入，不突兀
- [ ] 没有语法错误

---

### 汤底质量

**反转效果**：
- [ ] 真相与表面现象形成反差
- [ ] 反转出人意料但合情合理
- [ ] 没有为了反转而强行扭曲逻辑

**可推理性**：
- [ ] 玩家通过提问可以获得所有关键信息
- [ ] 存在明确的推理路径（不是只有一条死路）
- [ ] 没有依赖「猜中作者心思」的情况

---

### 本格特殊检查

- [ ] 所有现象符合物理/化学/生物规律
- [ ] 没有超自然解释
- [ ] 特殊道具/药物的使用符合现实
- [ ] 真相是唯一合理解释（或最合理的解释）
- [ ] 经得起「奥卡姆剃刀」检验

### 变格特殊检查

- [ ] 超自然规则明确且始终一致
- [ ] 没有「规则随剧情需要而变化」
- [ ] 汤面中暗示了特殊设定的存在
- [ ] 玩家可以通过提问了解规则
- [ ] 没有突然引入新规则来解释剧情

---

## 常见逻辑漏洞速查

| 漏洞类型 | 表现 | 修正方法 |
|---------|------|----------|
| **时间矛盾** | 人物在不可能的时间出现在某地 | 调整时间线或增加合理过渡 |
| **空间矛盾** | 密室无法解释、移动路径不可行 | 补充空间细节或改变场景 |
| **人物矛盾** | 行为与身份/性格不符 | 补充动机或调整行为 |
| **信息矛盾** | 汤底突然引入新设定 | 在汤面中增加暗示 |
| **巧合依赖** | 关键情节依赖小概率事件 | 用因果关系替代巧合 |
| **动机缺失** | 人物行为没有合理动机 | 补充心理或现实动机 |

## 难度验证

| 难度 | 验证标准 |
|------|----------|
| 简单 | 新手能在 10 分钟内通过 3-5 个问题猜出 |
| 中等 | 需要组合 2-3 个线索，10-15 个问题，15-25 分钟 |
| 困难 | 需要突破思维定势，20+ 个问题，30 分钟以上 |

## 质量评级

| 评级 | 标准 |
|------|------|
| ⭐⭐⭐⭐⭐ | 逻辑严密，反转精彩，体验极佳，值得反复玩 |
| ⭐⭐⭐⭐ | 逻辑自洽，体验良好，值得推荐 |
| ⭐⭐⭐ | 无明显漏洞，可以正常游戏（最低合格线） |
| ⭐⭐ | 存在小问题，影响体验，需要修改 |
| ⭐ | 逻辑漏洞严重，不建议使用 |

**目标**：所有创作的海龟汤至少达到 ⭐⭐⭐ 级别。
