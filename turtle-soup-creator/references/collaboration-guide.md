# 多人协作创作指南

> 复杂海龟汤可以由多人协作创作，集思广益，提高质量。本指南介绍协作创作的流程和工具。

---

## 一、协作创作的优势

| 优势 | 说明 |
|------|------|
| **多元视角** | 不同创作者提供不同思路，避免思维定势 |
| **逻辑互查** | 多人检查逻辑漏洞，提高作品质量 |
| **效率提升** | 分工合作，缩短创作周期 |
| **创意碰撞** | 讨论中产生新的创意火花 |

---

## 二、协作角色分工

### 角色1：创意总监（1人）
**职责**：
- 确定创作方向和核心诡计
- 协调团队成员
- 最终决策权

**适合**：有经验的海龟汤创作者

### 角色2：汤面设计师（1-2人）
**职责**：
- 撰写汤面
- 设计线索分布
- 控制信息密度

**技能要求**：文字功底好，擅长悬念设计

### 角色3：汤底构建师（1-2人）
**职责**：
- 构建完整故事
- 设计反转逻辑
- 确保逻辑自洽

**技能要求**：逻辑思维强，擅长故事架构

### 角色4：逻辑检查员（1人）
**职责**：
- 检查逻辑漏洞
- 验证可推理性
- 测试难度平衡

**技能要求**：细心，擅长挑刺

### 角色5：提示设计师（1人）
**职责**：
- 设计3级递进提示
- 预测玩家问题
- 准备主持人备注

**技能要求**：了解玩家心理，擅长引导

## 三、协作创作流程

### Phase 1：创意阶段（30分钟）

**步骤1：头脑风暴（15分钟）**
- 所有成员提出核心诡计创意（不评判）
- 记录所有想法
- 目标：10+个创意

**步骤2：筛选确定（15分钟）**
- 评估每个创意的可行性
- 投票选出最佳创意
- 创意总监确定最终方向

**工具**：白板/在线文档（如腾讯文档、Notion）

---

### Phase 2：设计阶段（60分钟）

**步骤1：汤底构建（30分钟）**
- 汤底构建师撰写故事框架
- 团队成员补充细节
- 确定关键反转点

**步骤2：汤面设计（20分钟）**
- 汤面设计师根据汤底撰写汤面
- 隐藏关键信息，保留线索
- 团队成员提供修改建议

**步骤3：初步整合（10分钟）**
- 将汤面和汤底整合
- 检查基本逻辑
- 确定难度等级

---

### Phase 3：验证阶段（45分钟）

**步骤1：逻辑检查（20分钟）**
- 逻辑检查员逐项检查逻辑清单
- 团队成员提出疑问
- 记录所有潜在漏洞

**步骤2：修订完善（15分钟）**
- 根据检查结果修改
- 汤面设计师调整线索
- 汤底构建师补充解释

**步骤3：试玩测试（10分钟）**
- 一人扮演主持人，其他人扮演玩家
- 模拟推理过程
- 记录问题和改进点

---

### Phase 4：完善阶段（30分钟）

**步骤1：提示设计（15分钟）**
- 提示设计师撰写3级提示
- 预测玩家可能的问题
- 准备主持人备注

**步骤2：最终审核（10分钟）**
- 全员阅读完整作品
- 最后修改建议
- 创意总监确认定稿

**步骤3：文档整理（5分钟）**
- 按标准格式输出
- 存档备份
- 署名创作者

## 五、协作沟通规范

### 会议规则
1. **准时开始**：不等待迟到者
2. **发言限时**：每人每次发言不超过2分钟
3. **先肯定后建议**：批评前先肯定优点
4. **记录决策**：所有决策必须记录在案

### 反馈格式
```
【肯定】这个设计的优点是...
【建议】可以考虑...
【疑问】这里我不太理解...
【修改】建议改为...
```

### 冲突解决
当出现分歧时：
1. 双方陈述理由（各2分钟）
2. 其他成员投票
3. 创意总监做最终决定
4. 记录决策理由

## 七、常见问题与解决

### 问题1：创意分歧
**表现**：团队成员对方向有不同意见
**解决**：
- 分别创作小样，对比选择
- 融合不同创意的优点
- 投票决定，少数服从多数

### 问题2：进度不一致
**表现**：有人进度快，有人进度慢
**解决**：
- 设定明确的里程碑和截止时间
- 每日站会同步进度
- 调整分工，让慢的人做简单任务

### 问题3：质量参差不齐
**表现**：不同部分质量不一致
**解决**：
- 统一审核标准
- 指定一人负责最终润色
- 互相检查，交叉审核

### 问题4：署名争议
**表现**：对贡献度认定有分歧
**解决**：
- 事先约定署名规则
- 按角色分工署名
- 特别贡献单独致谢

## 八、协作创作示例

### 案例：5人团队创作一个困难难度海龟汤

**团队构成**：
- 创意总监：小明
- 汤面设计师：小红
- 汤底构建师：小刚
- 逻辑检查员：小丽
- 提示设计师：小华

**创作过程**：

**Phase 1**：
- 头脑风暴：提出了12个创意
- 选定方向：时间循环+身份替换的双重诡计

**Phase 2**：
- 小刚构建汤底：男人每天醒来都是同一天，但每天"自己"的行为都不同，最后发现每天醒来都在不同的平行世界，每个世界的"自己"都在试图杀死其他世界的自己。
- 小红设计汤面：「他每天醒来都会发现房间里多了一样东西，但某天那样东西不见了，他却松了口气。」

**Phase 3**：
- 小丽发现逻辑漏洞：如果每天在不同世界，为什么能保留记忆？
- 解决方案：增加设定——只有主角因为某个特殊事件保留了跨世界记忆

**Phase 4**：
- 小华设计提示：
  1. 轻度：关注"多了一样东西"的含义
  2. 中度：想想为什么某天不见了反而松了口气
  3. 重度：如果每天醒来的"自己"不是同一个人呢？

**最终作品**：困难难度变格海龟汤，试玩时间45分钟
