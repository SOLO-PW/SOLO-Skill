# 变格规则设计指南

> 变格海龟汤允许超自然元素，但规则必须清晰、一致、可推理。本指南详解常见变格类型的设计方法。

---

## 一、变格设计核心原则

### 1. 规则前置原则
**所有超自然规则必须在汤面中有暗示，不能汤底突然引入。**

**好的示例**：
> 汤面：「他每天醒来都会发现房间里多了一样东西」——暗示时间循环或空间异常

**差的示例**：
> 汤面：「他死了」——汤底突然说「其实他有复活能力」，汤面毫无暗示

### 2. 规则一致性原则
**规则一旦设定，不能随剧情需要而改变。**

**错误示范**：
- 规则：「每天循环，记忆保留」
- 剧情需要：某天突然失忆（违反规则）

### 3. 规则可推理原则
**玩家可以通过提问了解规则边界和限制。**

**设计要求**：
- 规则有明确的边界（能做什么，不能做什么）
- 规则有限制条件（什么情况下失效）
- 规则有代价（使用能力的代价）

## 二、常见变格类型详解

### 类型1：时间循环

**定义**：人物被困在某一段时间（通常是一天）内不断重复。

**经典设定**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 循环范围 | 从哪里开始，到哪里结束 | 每天早上8点醒来，晚上12点重置 |
| 记忆保留 | 是否保留上一轮记忆 | 保留记忆（常见）/不保留（困难） |
| 退出条件 | 如何打破循环 | 完成某个任务/拯救某人/找到真相 |
| 累积效应 | 每轮循环是否留下痕迹 | 可以留下记号/物品 |

**汤面暗示技巧**：
- 「每天醒来都发现...」——暗示循环
- 「同样的场景重复出现」——直接暗示
- 「他记得昨天发生的事，但其他人不记得」——暗示记忆保留

**示例设计**：
```
汤面：一个男人每天早上醒来，都会发现房间里多了一样东西。
第7天，他决定自杀。为什么？

汤底：男人被困在时间循环里，每天醒来都是同一天。
房间里多出的东西是前几次循环的自己留下的记号。
第7天，他发现记号已经满了7个，意识到这个循环最多只有7次机会，
而他每次都失败了，绝望之下选择自杀。
```

---

### 类型2：灵魂互换/身体交换

**定义**：两个或多个人物的灵魂互换身体。

**经典设定**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 交换对象 | 谁和谁交换 | 陌生人/亲人/仇人 |
| 交换触发 | 什么导致交换 | 特定时间/特定动作/意外事件 |
| 交换时长 | 持续多久 | 永久/临时/可控制 |
| 识别方式 | 如何识别真实身份 | 只有当事人知道/特定测试 |

**汤面暗示技巧**：
- 「他照镜子发现不认识自己」——直接暗示
- 「他的行为突然变得很奇怪」——间接暗示
- 「他说了一些只有XX才知道的事」——暗示身份错乱

**示例设计**：
```
汤面：一个男人每天早上都会照镜子。某天早上，他看着镜子里的自己，
突然尖叫一声，晕了过去。为什么？

汤底：男人患有短期记忆丧失症，每天早上醒来都会忘记前一天的事。
他一直以为镜子里的自己是陌生人，每天都和"陌生人"对视。
某天早上，他突然恢复了记忆，意识到镜子里的就是自己，
而他已经和"陌生人"对视了十年，瞬间的精神冲击让他晕了过去。

（注：这是记忆问题，但设计思路类似灵魂互换的认知错位）
```

---

### 类型3：预知未来

**定义**：人物能看到即将发生的未来片段。

**经典设定**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 预知方式 | 如何看到未来 | 梦境/闪回/被动触发 |
| 预知范围 | 能看到多远的未来 | 几秒后/几小时后/几天后 |
| 可改变性 | 未来是否可以改变 | 可改变（困难）/不可改变（悲剧） |
| 副作用 | 使用能力的代价 | 头痛/失忆/寿命减少 |

**汤面暗示技巧**：
- 「他提前避开了那辆车」——暗示预知
- 「他说"不要进去，会出事"」——暗示看到未来
- 「他的梦境总是成真」——直接暗示

**示例设计**：
```
汤面：一个男人每天都会在同一时间同一地点等待。
某天他突然跑开，几分钟后那里发生了事故。
他为什么知道会出事？

汤底：男人有预知能力，能看到几分钟后发生的未来。
他每天在那个时间地点等待，是为了救一个会在那里出现的小女孩。
某天他预知到那里会发生车祸，所以提前跑开避险。
```

---

### 类型4：规则怪谈

**定义**：必须遵守特定规则才能生存，违反规则会受到惩罚。

**经典设定**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 规则数量 | 多少条规则 | 3-5条最佳，太多会混乱 |
| 规则来源 | 谁制定的规则 | 未知存在/诅咒/实验 |
| 违反后果 | 违反会怎样 | 死亡/被困/变成怪物 |
| 隐藏规则 | 是否有未明示的规则 | 需要玩家推理发现 |

**汤面暗示技巧**：
- 「他数到三就必须闭眼」——直接展示规则
- 「房间里贴着一张纸条，上面写着...」——规则文档化
- 「他知道不能这样做，但不知道为什么」——暗示规则存在

**示例设计**：
```
汤面：一个男人被困在一个房间里，墙上贴着一张纸条：
"1. 不要看镜子。2. 听到敲门声不要回答。3. 灯灭时必须闭眼。
违反任何一条，你将永远留在这里。"
男人遵守了所有规则，但还是死了。为什么？

汤底：还有第四条隐藏规则："不要呼吸超过100次。"
男人因为紧张呼吸急促，在灯灭时已经呼吸了100次，
虽然闭上了眼，但还是违反了隐藏规则。
```

---

### 类型5：平行世界/多重现实

**定义**：存在多个相似但不同的世界，人物可能在不同世界间穿梭。

**经典设定**：
| 要素 | 说明 | 示例 |
|------|------|------|
| 世界差异 | 不同世界有什么不同 | 某人活着vs死了/某个决定不同 |
| 穿梭方式 | 如何在世界间移动 | 意外触发/特定地点/特定时间 |
| 识别方法 | 如何知道自己在哪个世界 | 特定标记/人物状态 |
| 穿梭代价 | 穿梭的代价 | 记忆混乱/身体损伤/无法返回 |

**汤面暗示技巧**：
- 「他发现昨天的伤今天消失了」——暗示世界切换
- 「这个人明明昨天死了，今天却活着」——直接暗示
- 「周围的一切都很熟悉，但总觉得哪里不对」——间接暗示

## 三、变格规则设计模板

### 模板：规则设计文档

创作变格海龟汤前，先填写以下文档：

```
【变格类型】：[时间循环/灵魂互换/预知未来/规则怪谈/平行世界/其他]

【核心规则】：
1. [规则1的具体描述]
2. [规则2的具体描述]
3. [规则3的具体描述]

【规则边界】：
- 能做什么：[范围]
- 不能做什么：[限制]
- 特殊情况：[例外]

【汤面暗示】：
- 暗示1：[汤面中的具体描述]
- 暗示2：[汤面中的具体描述]

【玩家可推理的问题】：
- Q1：[玩家可能问的问题] → A1：[主持人的回答]
- Q2：[玩家可能问的问题] → A2：[主持人的回答]

【退出条件/解决方式】：
[如何打破变格状态，或如何适应变格状态]
```

## 四、变格与本格的结合

### 伪变格（推荐）
表面看起来是变格，最后揭示是本格。

**示例**：
```
汤面：他每天醒来都会发现房间里多了一样东西。
汤底：他不是被困在时间循环里，而是有一个双胞胎兄弟
每天潜入他的房间放东西恶作剧。
```

### 变格中的本格推理
即使在变格设定下，推理过程仍应遵循逻辑。

**示例**：
```
设定：时间循环（变格）
推理：谁在循环中保留了记忆？（本格逻辑）
答案：只有主角保留记忆，因为他在循环起点时处于特殊状态
```

## 五、常见错误与避免方法

### 错误1：规则过于复杂
**问题**：规则太多，玩家记不住
**解决**：限制在3条核心规则以内

### 错误2：规则自相矛盾
**问题**：规则A和规则B冲突
**解决**：创作前先写规则文档，检查一致性

### 错误3：汤面无暗示
**问题**：汤底突然引入超自然设定
**解决**：确保汤面中有至少2处规则暗示

### 错误4：规则无法推理
**问题**：玩家无法通过提问了解规则
**解决**：设计3-5个可以回答「是」的规则相关问题

### 错误5：退出条件不公平
**问题**：退出条件过于苛刻或过于简单
**解决**：退出条件应与谜题难度匹配，需要推理而非运气

---

## 六、变格创作检查清单

创作完成后检查：

- [ ] 汤面中有至少2处规则暗示
- [ ] 规则不超过3条核心规则
- [ ] 规则不自相矛盾
- [ ] 玩家可以通过提问了解规则
- [ ] 退出条件合理且可达成
- [ ] 变格设定服务于故事，而非为了变格而变格
