# 海龟汤创作模板库

> 本模板库提供可直接套用的汤面/汤底结构模板。创作时选择合适的模板，填入具体内容即可。

---

## 一、汤面模板

### 模板1：异常行为型
**结构**：人物 + 异常行为 + 表面矛盾

```
[人物]每天都会[正常行为]，但某天[异常变化]，[他人反应]。为什么？
```

**示例填充**：
- 人物：小女孩
- 正常行为：给路边流浪汉一颗糖
- 异常变化：某天没给糖
- 他人反应：流浪汉却哭了

**成品**：小女孩每天放学都会给路边的流浪汉一颗糖。某天她没给糖，流浪汉却哭了。为什么？

---

### 模板2：突发反应型
**结构**：人物 + 正常请求 + 异常反应 + 意外结果

```
[人物]走进[场所]，对[他人]说："[正常请求]。"[他人]突然[异常反应]。[人物][意外结果]。为什么？
```

**示例填充**：
- 人物：一个男人
- 场所：酒吧
- 他人：酒保
- 正常请求：给我一杯水
- 异常反应：掏出一把枪指着他
- 意外结果：愣了一下，说了声"谢谢"就离开了

**成品**：一个男人走进酒吧，对酒保说："给我一杯水。"酒保突然掏出一把枪指着他。男人愣了一下，说了声"谢谢"就离开了。为什么？

---

### 模板3：发现异常型
**结构**：人物 + 日常习惯 + 发现异常 + 极端反应

```
[人物]每天都会[检查/做某事]。某天[检查/做完后]，却立刻[极端反应]。为什么？
```

**示例填充**：
- 人物：独居女子
- 日常习惯：每晚睡前检查床底
- 发现异常：检查完躺下后
- 极端反应：立刻尖叫着逃出房间

**成品**：独居女子每晚睡前都会检查床底，确认没人后才敢睡觉。某天她检查完躺下后，却立刻尖叫着逃出房间。为什么？

---

### 模板4：物品线索型
**结构**：人物 + 特定物品 + 异常状态 + 他人反应

```
[人物][动作][物品]，[物品状态]。看到的人[反应]。为什么？
```

**示例填充**：
- 人物：一个女人
- 动作：在阳台上晾
- 物品：一件男士衬衫
- 物品状态：但她独居，也没有男朋友
- 他人反应：邻居觉得很奇怪

**成品**：一个女人每天都会在阳台上晾一件男士衬衫，但她独居，也没有男朋友。邻居觉得很奇怪，直到有一天女人不再晾衬衫了，邻居却报了警。为什么？

---

### 模板5：循环累积型（适合变格）
**结构**：人物 + 循环事件 + 累积异常 + 最终抉择

```
[人物]每天[循环事件]，都会发现[累积异常]。第[N]天，[人物][极端抉择]。为什么？
```

**示例填充**：
- 人物：一个男人
- 循环事件：早上醒来
- 累积异常：房间里多了一样东西
- N：7
- 极端抉择：他决定自杀

**成品**：一个男人每天早上醒来，都会发现房间里多了一样东西。第7天，他决定自杀。为什么？

## 二、汤底模板

### 模板A：身份反转型
**适用**：温情、悬疑、爱情主题

```
**故事背景**：
[人物A]其实是[人物B的隐藏身份]，因为[原因]而[伪装/隐藏]。

**事件经过**：
[人物B]每天[行为]，[人物A]虽然[表面状态]，但[内心状态]。
某天[触发事件]，[人物A]意识到[真相]，[情感反应]。

**关键线索解释**：
- **[汤面线索1]**：[对应解释]
- **[汤面线索2]**：[对应解释]
```

**示例**（流浪汉父亲）：
```
**故事背景**：
流浪汉其实是女孩失散多年的父亲。他因意外失去记忆，流落街头，
唯一记得的就是女儿喜欢吃糖。

**事件经过**：
女孩每天给他糖时，他虽然不记得她是谁，但会感到莫名的温暖。
那天女孩没给糖，是因为她看到流浪汉在哭，递上了纸巾说"叔叔别难过"。
父亲听到女儿叫自己"叔叔"，意识到女儿已经不记得他了，悲喜交加而落泪。

**关键线索解释**：
- **每天给糖**：父亲记得女儿喜欢吃糖，这是唯一的记忆锚点
- **没给糖却哭了**：女孩叫他"叔叔"，触发了他对失忆的悲伤
```

---

### 模板B：认知错位型
**适用**：搞笑、日常主题

```
**故事背景**：
[人物A]有[某种状态/问题]，需要[某种解决方式]。

**事件经过**：
[人物A][行为]，[人物B]看出[真实问题]，用[非常规方式]帮助解决。
[人物A][反应]，因为[效果达成]。

**关键线索解释**：
- **[汤面线索1]**：[表面看是X，实际是Y]
- **[汤面线索2]**：[非常规行为的合理原因]
```

**示例**（打嗝）：
```
**故事背景**：
男人打嗝不止，想要水止住，但水的效果不够好。

**事件经过**：
男人向酒保要水，酒保看出他在打嗝，掏枪是为了吓他一跳。
受到惊吓后，打嗝果然停了。男人说了声"谢谢"表示感谢。

**关键线索解释**：
- **要水**：表面是口渴，实际是想止嗝
- **掏枪**：表面是威胁，实际是治疗打嗝的方法
- **说谢谢**：因为问题解决了
```

---

### 模板C：视角欺骗型
**适用**：恐怖、悬疑主题

```
**故事背景**：
[场景描述]，存在[隐藏的威胁/异常]。

**事件经过**：
[人物][常规检查]，[表面安全]。
但[实际危险]，因为[隐藏真相]。
[人物发现真相]，[极端反应]。

**关键线索解释**：
- **[汤面线索1]**：[视角盲区的解释]
- **[汤面线索2]**：[时间/空间差导致的误解]
```

**示例**（床底）：
```
**故事背景**：
独居女子的床底藏着一个人，一直在等待时机。

**事件经过**：
女子检查时看到床底没人（因为那人平躺着）。
她躺下后，从床底视角看到了一双眼睛——有人一直躺在床底，
只是之前没抬头看她。女子发现后尖叫逃出。

**关键线索解释**：
- **检查床底没人**：检查时视角只能看到床底地面，看不到平躺的人
- **躺下后看到眼睛**：躺下后视角变成从床底向上看，能看到那人的眼睛
```

---

### 模板D：牺牲奉献型
**适用**：温情、悬疑主题

```
**故事背景**：
[人物A]和[人物B]处于[极端环境/困境]。

**事件经过**：
[人物A]告诉[人物B][善意的谎言]，实际是[牺牲行为]。
[人物B]幸存，多年后[发现真相]。
意识到[人物A的牺牲]，[人物B][情感反应/行为]。

**关键线索解释**：
- **[汤面线索1]**：[谎言的表面]
- **[汤面线索2]**：[真相的残酷]
```

**示例**（海龟汤原版）：
```
**故事背景**：
男人和同伴在海上遇难，漂流到荒岛，食物耗尽。

**事件经过**：
同伴说用海龟肉煮了汤给他喝，他活了下来被救。
多年后，他在餐厅喝到真正的海龟汤，发现味道完全不同。
原来当年同伴是用自己的肉煮汤给他喝，为了让他活下去而牺牲了自己。
男人发现真相后无法承受，选择了自杀。

**关键线索解释**：
- **海龟汤**：表面是海龟肉，实际是人肉
- **立刻自杀**：发现真相后的极度愧疚和无法承受
```

---

### 模板E：规则异常型（变格专用）
**适用**：科幻、规则怪谈主题

```
**世界观设定**：
[特殊规则/设定描述]。

**事件经过**：
[人物]处于[规则影响]中，每天[累积变化]。
[人物]发现[规律/限制]，意识到[绝望的事实]。
[人物][极端抉择]。

**关键线索解释**：
- **[汤面线索1]**：[规则的表现]
- **[汤面线索2]**：[累积的暗示]
```

**示例**（时间循环）：
```
**世界观设定**：
男人被困在时间循环里，每天醒来都是同一天，最多循环7次。

**事件经过**：
房间里多出的东西是前几次循环的自己留下的记号。
第7天，他发现记号已经满了7个，意识到这个循环最多只有7次机会，
而他每次都失败了，绝望之下选择自杀。

**关键线索解释**：
- **每天多一样东西**：前几次循环的自己留下的记号
- **第7天自杀**：发现循环次数上限，绝望放弃
```

## 三、提示设计模板

### 3级递进提示模板

```
### 💡 提示线索

1. **轻度提示**（指向细节）：
   「可以关注一下汤面中提到的 [具体细节]，它可能不是表面看起来的那样。」

2. **中度提示**（建立联系）：
   「想想 [元素A] 和 [元素B] 之间可能有什么联系？它们的出现是巧合吗？」

3. **重度提示**（接近真相）：
   「[关键行为] 这个行为，在什么特殊情况下会成立？试着跳出常规思维。」
```

## 四、快速组合公式

### 公式1：温情向
**汤面**：日常互动 + 某天异常 + 情感反应  
**汤底**：隐藏身份 + 记忆/情感锚点 + 真相揭示

### 公式2：悬疑向
**汤面**：异常场景 + 不合逻辑的细节 + 他人反应  
**汤底**：非常规解释 + 隐藏信息 + 逻辑闭环

### 公式3：搞笑向
**汤面**：紧张场景 + 夸张反应 + 意外结果  
**汤底**：认知错位 + 非常规解决方式 + 反转幽默

### 公式4：恐怖向
**汤面**：安全检查 + 确认安全 + 突发恐惧  
**汤底**：视角盲区 + 隐藏威胁 + 细思极恐

### 公式5：变格向
**汤面**：循环/累积现象 + 规律变化 + 极端抉择  
**汤底**：特殊规则 + 规则限制 + 绝望处境

---

## 五、模板使用建议

1. **初学者**：从「模板1+模板A」组合开始，创作温情向简单难度
2. **进阶者**：尝试「模板3+模板C」组合，创作恐怖/悬疑向中等难度
3. **高手**：使用「模板5+模板E」组合，创作变格困难难度
4. **创新者**：混合不同模板元素，创造独特结构
