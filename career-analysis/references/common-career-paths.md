# 常见职业发展路径示例

## 互联网/科技行业

### 技术类岗位

#### 软件工程师
**典型路径**：
```
初级工程师 (0-2年) → 中级工程师 (2-5年) → 高级工程师 (5-8年)
    ├── 技术专家路线：资深工程师 → 技术专家 → 首席科学家/架构师
    └── 技术管理路线：技术主管 → 技术经理 → 技术总监 → CTO
```

**关键技能要求**：
- 初级：编程基础、数据结构、算法
- 中级：系统设计、项目经验、技术深度
- 高级：架构设计、技术决策、团队协作
- 专家：技术视野、行业影响力、创新思维

**薪资参考**：
| 阶段 | 薪资范围（月） |
|------|---------------|
| 初级 | 8-15K |
| 中级 | 15-30K |
| 高级 | 30-50K |
| 专家 | 50-100K+ |

#### 产品经理
**典型路径**：
```
产品助理 (0-1年) → 产品经理 (1-3年) → 高级产品经理 (3-5年)
    ├── 产品专家路线：资深产品经理 → 产品专家 → 首席产品官
    └── 产品管理路线：产品总监 → 产品VP → CPO
```

**关键技能要求**：
- 助理：需求分析、原型设计、数据分析
- 经理：产品规划、项目管理、跨部门协作
- 高级：产品战略、商业思维、团队管理
- 专家：行业洞察、产品创新、商业决策

## 教育行业

### 教师类岗位

#### 中小学教师
**典型路径**：
```
实习教师 (0-1年) → 初级教师 (1-3年) → 中级教师 (3-8年) → 高级教师 (8-15年)
    ├── 教学专家路线：特级教师 → 教学名师 → 教育专家
    └── 教育管理路线：年级组长 → 教务主任 → 副校长 → 校长
```

**职称体系**：
- 初级职称：二级教师、三级教师
- 中级职称：一级教师
- 高级职称：高级教师、正高级教师

## 医疗行业

### 医生类岗位

#### 临床医生
**典型路径**：
```
医学生 (5-8年) → 住院医师 (1-3年) → 主治医师 (3-5年) → 副主任医师 (5-10年) → 主任医师 (10年+)
    ├── 医学专家路线：科室主任 → 学科带头人 → 医学专家
    └── 医院管理路线：科室副主任 → 医院副院长 → 医院院长
```

**职称晋升要求**：
- 住院医师：医学学位、执业医师资格
- 主治医师：住院医师工作一定年限、通过考试
- 副主任医师：主治医师工作一定年限、科研成果
- 主任医师：副主任医师工作一定年限、学术成就

## 跨行业通用路径

### 管理类岗位通用路径
```
专员/助理 (0-2年) → 主管 (2-5年) → 经理 (5-8年) → 总监 (8-12年) → 副总裁 (12-15年) → CXO/CEO (15年+)
```

### 专家类岗位通用路径
```
初级专业人员 (0-2年) → 中级专业人员 (2-5年) → 高级专业人员 (5-8年) → 资深专业人员 (8-12年) → 专家 (12-15年) → 首席专家/顾问 (15年+)
```

## 职业转型路径示例

### 技术转产品
```
软件工程师 (3-5年) → 技术型产品经理 (转型期1-2年) → 产品经理 (稳定期) → 高级产品经理
```

**转型关键**：
- 补充产品知识
- 参与产品项目
- 建立产品思维

### 传统行业转互联网
```
传统行业从业者 (3-5年) → 互联网行业初级岗位 (转型期1-2年) → 互联网行业中级岗位 → 互联网行业高级岗位
```

**转型关键**：
- 学习互联网知识
- 积累互联网经验
- 建立互联网人脉

### 专业转管理
```
专业技术人员 (5-8年) → 技术管理岗位 (转型期2-3年) → 管理岗位 → 高级管理岗位
```

**转型关键**：
- 培养管理能力
- 学习管理知识
- 积累管理经验

## 职业发展路径选择建议

### 选择标准
1. **兴趣匹配**：是否对工作内容感兴趣
2. **能力匹配**：是否具备相应能力
3. **价值观匹配**：是否符合个人价值观
4. **发展机会**：是否有良好的发展空间
5. **薪资待遇**：是否满足经济需求

### 决策框架
```
评估维度        权重    评分(1-10)    加权得分
─────────────────────────────────────────────
兴趣匹配        25%      ?            ?
能力匹配        25%      ?            ?
价值观匹配      20%      ?            ?
发展机会        20%      ?            ?
薪资待遇        10%      ?            ?
─────────────────────────────────────────────
总分            100%                  ?
```

### 风险评估
- **低风险**：稳定行业、成熟岗位、明确路径
- **中风险**：发展中行业、新兴岗位、探索性路径
- **高风险**：衰退行业、不稳定岗位、激进转型

### 备选方案
- **主路径**：最优选择，优先执行
- **备选路径**：次优选择，主路径受阻时启用
- **应急路径**：保底选择，确保基本发展
