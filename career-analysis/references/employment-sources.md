## 检索策略

### WebSearch优化查询

| 场景 | 查询模板 |
|------|----------|
| 职位搜索 | "[职位名称] 招聘 要求 薪资 [城市] [当前年份]" |
| 行业分析 | "[行业名称] 发展趋势 [当前年份] 市场规模" |
| 薪资查询 | "[职位名称] 平均薪资 [城市] [当前年份]" |
| 政策查询 | "[行业/地区] 就业政策 人才引进" |

> **动态年份说明**：检索时用实际当前年份替换 `[当前年份]` 占位符，避免使用过期年份。

### 信息整合方法

1. **交叉验证**：对比多个数据源的一致性
2. **时效性**：优先使用最新数据
3. **权威性**：官方数据优先于民间数据
4. **代表性**：关注数据样本量和覆盖范围
