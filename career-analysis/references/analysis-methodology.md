# 就业分析方法论

## 信息收集框架

### 用户信息维度

| 维度 | 具体内容 | 收集方法 |
|------|----------|----------|
| **教育背景** | 学历、专业、学校类型、GPA | 直接询问 |
| **技能证书** | 专业技能、职业证书、语言能力 | 直接询问 + 技能测试 |
| **实习经验** | 实习经历、项目经验、竞赛获奖 | 行为面试法 |
| **个人特质** | 性格特点、兴趣爱好、价值观 | 测评工具 + 访谈 |
| **就业意向** | 目标行业、职位、城市、薪资 | 直接询问 |

### 信息收集策略

**渐进式收集**：
1. 核心信息（必需）：教育背景、技能、就业意向
2. 补充信息（推荐）：实习经验、个人特质
3. 深入信息（可选）：职业规划、价值观

**提问技巧**：
- 开放式问题：了解用户想法
- 选择式问题：确认具体信息
- 假设性问题：探索潜在需求

## 市场信息分析

### 行业分析维度

| 维度 | 分析要点 | 数据来源 |
|------|----------|----------|
| **市场规模** | 当前规模、增长趋势 | 行业报告 |
| **竞争格局** | 主要企业、市场份额 | 企业财报 |
| **发展趋势** | 技术趋势、政策趋势 | 研究报告 |
| **人才需求** | 岗位需求量、人才缺口 | 招聘网站 |

### 职位分析维度

| 维度 | 分析要点 | 数据来源 |
|------|----------|----------|
| **岗位职责** | 工作内容、工作要求 | 职位描述 |
| **任职要求** | 学历、技能、经验要求 | 招聘信息 |
| **薪资水平** | 薪资范围、薪资结构 | 薪资报告 |
| **发展前景** | 晋升路径、发展空间 | 职业访谈 |

## 匹配度计算

### 匹配维度权重

| 维度 | 权重 | 说明 |
|------|------|------|
| **教育背景** | 20% | 学历、专业匹配度 |
| **技能匹配** | 30% | 核心技能掌握程度 |
| **经验匹配** | 25% | 相关经验积累 |
| **兴趣匹配** | 15% | 职业兴趣契合度 |
| **价值观匹配** | 10% | 职业价值观一致性 |

### 匹配度计算公式

```
匹配度 = 教育背景×0.2 + 技能匹配×0.3 + 经验匹配×0.25 + 兴趣匹配×0.15 + 价值观匹配×0.1
```

### 匹配等级划分

| 分数区间 | 匹配等级 | 建议 |
|----------|----------|------|
| 90-100 | 高度匹配 | 强烈推荐，优先考虑 |
| 80-89 | 较好匹配 | 推荐，可作为主要选择 |
| 70-79 | 一般匹配 | 可考虑，需要提升相关能力 |
| 60-69 | 勉强匹配 | 谨慎考虑，差距较大 |
| 0-59 | 匹配度低 | 不推荐，建议其他方向 |

## 推荐算法

### 推荐排序规则

1. **高匹配度 + 高发展潜力** → 优先推荐
2. **高匹配度 + 中等发展潜力** → 次优先推荐
3. **中等匹配度 + 高发展潜力** → 可选推荐
4. **高匹配度 + 低发展潜力** → 备选推荐
5. **中等匹配度 + 中等发展潜力** → 备选推荐

### 推荐输出格式

```
## 就业方向推荐

### 推荐1：[职位名称]（匹配度：XX%）
- **岗位要求**：[核心要求]
- **薪资范围**：[薪资区间]
- **发展前景**：[发展评估]
- **匹配优势**：[用户优势]
- **提升建议**：[改进建议]

### 推荐2：[职位名称]（匹配度：XX%）
...
```

## 发展路径规划

### 路径设计原则

1. **可行性**：路径必须切实可行
2. **渐进性**：逐步提升，避免跳跃
3. **多样性**：提供多条路径选择
4. **灵活性**：根据情况调整路径

### 路径规划步骤

1. **现状评估**：分析当前能力和资源
2. **目标设定**：明确短期、中期、长期目标
3. **路径设计**：设计多条可行路径
4. **差距分析**：识别能力差距
5. **行动计划**：制定具体提升计划

### 路径图生成规范

**节点信息**：
- 职位/角色名称
- 预计时长
- 关键要求
- 薪资范围

**边信息**：
- 转型条件
- 所需时间
- 难度评估

## 最佳实践

### 信息收集
- 从核心信息开始，逐步深入
- 使用开放式和选择式问题结合
- 对关键信息进行确认和验证

### 信息检索
- 使用优化的查询关键词
- 交叉验证多个数据源
- 关注数据的时效性和权威性

### 分析推荐
- 综合考虑多个维度
- 平衡匹配度和发展潜力
- 提供多个选择方案

### 路径规划
- 设计多条可行路径
- 标注关键节点和要求
- 提供具体的行动计划
