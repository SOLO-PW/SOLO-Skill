# 互联网废话文学生成器

## 核心工作流

```
用户输入 → 分析语境 → 选择废话模式 → 生成废话 → 输出
              ↓
         WebSearch补充热门素材
```

## 快速判断指南

收到用户请求时，快速检查：

1. **包含情景描述？** → 分析场景选择废话类型
2. **包含情绪词？** → 选择对应情绪的废话
3. **包含特定对象？** → 使用对象相关的废话模板
4. **要求多个选项？** → 生成2-3个不同废话

## 语境分析要点

分析用户输入时，关注：

| 维度 | 关注点 | 示例 |
|------|--------|------|
| 场景类型 | 工作、生活、社交、网络 | 会议发言、朋友聊天 |
| 情绪基调 | 轻松、严肃、调侃、无奈 | 被夸奖、被批评 |
| 对话对象 | 朋友、同事、领导、陌生人 | 领导讲话、朋友调侃 |
| 核心话题 | 根据话题选择相关素材 | 吃饭、天气、外貌 |

## 废话生成技巧

### 同义反复型
用不同词表达相同意思，或重复相同结构：
- "情况就是这么个情况，但具体什么情况，还得看情况"
- "说重要也重要，说不重要也不重要"

### 时间循环型
利用时间流逝特性，说出显而易见的事实：
- "上次这么无语的时候，还是上次"
- "一日不见如隔一日"

### 条件假设型
用如果...那么...句式，说出逻辑正确但无意义的话：
- "但凡你有点本事，也不至于一点本事没有"
- "你要是不丑的话，其实还挺好看的"

### 单位转换型
将时间、距离等单位进行转换：
- "每呼吸六十秒，就过去了一分钟"
- "每过一天，就离昨天更远了一天"

### 众所周知型
说出大家都知道的事实：
- "这个西红柿，有一股番茄味儿"
- "我发现，我胖了之后，体重就变重了"

### 领导讲话型
模仿领导讲话的冗长和重复：
- "既然让我讲两句，那我就来讲两句，具体哪两句呢? 我先随便讲两句"

### 逆转型
先认同再转折：
- "我知道你很急，但是你先别急"
- "给你提个建议，你不要随便给别人提建议"

### 顺接型
熟语接梗，反向接话：
- "俗话说得好：俗话说得好"
- "能力越大，能力就越大"

### 长句式型
用冗长复杂的句式表达简单意思，增加理解难度：
- "关于这个问题，我简单说两句，第一句是我要说两句，第二句是我说完了"
- "这个事情很重要，重要到什么程度呢？重要到很重要"
- "全文内容大概是这么个事啊，我们讲不是说，不是说不办。但是……"

### 前后矛盾型
前后逻辑矛盾，自我否定：
- "我上次这么无语的时候，还是上次，具体什么时候呢？就是上次"
- "这个方案可行不可行呢？可行，但具体怎么行，还得看怎么不行"

### 文学改编型
改编经典文学或名言，赋予废话属性：
- "听君一席话，如听一席话"
- "三人行则必有三人"
- "一日不见如隔一日"

### 美好希望型
表达美好愿望但实际空洞：
- "如果我有男朋友，那么这句话就不用加如果两个字了"
- "如果你愿意多花点时间了解我，你就会发现多花了点时间"

### 冗余信息型
提供冗余信息，看似详细实则无用：
- "每呼吸六十秒，就过去了一分钟"
- "每过一天，就离昨天更远了一天"
- "每吃一顿饭，就少了一顿饭"

## 搜索补充机制

当用户输入特定场景时，可使用WebSearch搜索相关废话文学素材：

```
WebSearch("废话文学 + 场景关键词")
WebSearch("互联网废话 + 话题")
```

## 脚本使用

调用脚本生成废话：

```bash
# 生成1条废话
python scripts/generator.py "用户输入"

# 生成多条废话
python scripts/generator.py "用户输入" --count 3

# JSON格式输出
python scripts/generator.py "用户输入" --json
```

## 输出格式

生成废话时，提供：
1. **直接废话**：直接给出废话回复
2. **多选方案**：提供2-3个废话选项
3. **技巧解析**：说明使用了哪种废话技巧
