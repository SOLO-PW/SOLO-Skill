# 互联网废话文学生成器

根据用户输入的情景对话，分析语境并生成贴合场景但信息量为零的废话文学。

## ✨ 功能特点

- **场景智能匹配**：自动分析对话场景、情绪基调、对话对象
- **15 种废话类型**：同义反复、时间循环、条件假设、单位转换、领导讲话等
- **多场景覆盖**：工作、生活、社交、网络等常见场景
- **脚本支持**：可通过 Python 脚本批量生成

## 🎯 使用场景

| 场景 | 示例输入 | 废话输出 |
|------|----------|----------|
| 被问问题 | "有人问我忙不忙" | 我知道你很忙，但你先别忙 |
| 会议发言 | "领导让我说两句" | 既然让我讲两句，那我就来讲两句，具体哪两句呢? 我先随便讲两句 |
| 尴尬场面 | "不知道说什么" | 情况就是这么个情况，但具体什么情况，还得看情况 |
| 被夸奖 | "被人夸奖怎么回复" | 能力越大，能力就越大 |

## 📝 使用方法

### 方式一：直接对话

```
用户：说点废话
用户：如果有人说我胖，怎么用废话文学回复
用户：面对领导批评，说点废话
```

### 方式二：脚本调用

```bash
# 生成 1 条废话
python scripts/generator.py "有人问我吃饭了吗"

# 生成 3 条废话
python scripts/generator.py "被领导批评" --count 3

# JSON 格式输出
python scripts/generator.py "不知道说什么" --json
```

## 🎭 废话类型速览

| 类型 | 特点 | 示例 |
|------|------|------|
| 同义反复 | 用不同词表达相同意思 | 听君一席话，如听一席话 |
| 时间循环 | 利用时间流逝说废话 | 上次这么无语的时候，还是上次 |
| 条件假设 | 如果...那么...句式 | 但凡你有点本事，也不至于一点本事没有 |
| 单位转换 | 转换时间/距离单位 | 每呼吸六十秒，就过去了一分钟 |
| 众所周知 | 说出显而易见的事实 | 这个西红柿，有一股番茄味儿 |
| 领导讲话 | 模仿冗长重复的讲话 | 既然让我讲两句，那我就来讲两句 |
| 逆转型 | 先认同再转折 | 我知道你很急，但是你先别急 |
| 顺接型 | 熟语接梗，反向接话 | 俗话说得好：俗话说得好 |
| 文学改编 | 改编经典名言 | 三人行则必有三人 |
