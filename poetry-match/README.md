# Poetry Match

根据你描述的心情、场景或感受，智能匹配最契合的真实古诗词。

---

## 简介

**poetry-match** 是一个古诗词智能匹配 Skill。当你想用诗意表达某种心情，或者只记得半句诗想补全全文时，它能帮你找到最匹配的那一首。

**核心特点：**
- ✅ 只推荐真实存在的古诗词（严格真实性验证）
- ✅ 多维度匹配（情感 + 意象 + 主题 + 氛围）
- ✅ 输出完整信息（作者、朝代、体裁、题材、匹配理由、适用场景）
- ✅ 支持现代场景转译（如"加班到深夜"→羁旅诗）

---

## 功能特性

| 特性 | 说明 |
|------|------|
| **智能匹配** | 基于情感、意象、主题、氛围四维评分算法 |
| **真实性保障** | 三级门控验证，存疑诗词绝不输出 |
| **详细输出** | 诗词原文 + 作者信息 + 体裁题材 + 匹配理由 + 适用场景 |
| **现代场景支持** | 自动提取底层情感，跨时空匹配古诗词 |
| **多首推荐** | 支持一次性推荐最多 5 首备选诗词 |

## 使用方法

### 安装

将 `poetry-match` 文件夹放入 SOLO 的 Skill 目录即可。

### 调用

直接用自然语言描述你的心情或场景，例如：

```
"最近感觉很孤独，想找首诗表达一下"

"秋天傍晚，看着夕阳下的柳树，想起远方的朋友"

"加班到深夜，一个人走在回家的路上"

"用古诗怎么说'人生苦短'"

"但愿人长久...后面是什么来着？"
```

### 输出示例

**输入：**
> "加班到深夜，一个人走在回家的路上"

**输出：**

```markdown
## 📜 《天净沙·秋思》

**元代 · 马致远**

> 枯藤老树昏鸦，小桥流水人家，古道西风瘦马。
> 夕阳西下，断肠人在天涯。

### 🏷️ 基本信息
- **体裁**：散曲
- **题材**：羁旅
- **主题标签**：#漂泊 #孤独 #思乡

### 💡 匹配理由

**核心契合点**：深夜独行的漂泊感与"断肠人在天涯"高度共鸣

**详细分析**：
- 情感维度：孤独/疲惫 ↔ 羁旅之苦，深层共鸣
- 意象维度：深夜独行 ↔ 古道西风瘦马，画面感极强
- 主题维度：现代漂泊 ↔ 异乡羁旅，跨越时空的情感连接

**匹配度**：⭐⭐⭐⭐⭐（5星制）

### 📖 背景与赏析

**适用场景**：深夜独处、漂泊在外、思念故乡时引用
```

## 支持的输入类型

| 类型 | 示例 | 匹配策略 |
|------|------|---------|
| 情感直述 | "最近感觉很孤独" | 情感共鸣优先 |
| 场景描述 | "秋天傍晚看夕阳下的柳树" | 意象重合优先 |
| 半句引用 | "但愿人长久..." | 补全全诗 |
| 现代转译 | "加班到深夜一个人回家" | 提取底层情感，跨时空匹配 |
| 主题诉求 | "用古诗说人生苦短" | 主题契合优先 |

## 质量承诺

每首推荐的诗词均经过：

1. **多维度匹配算法**筛选（情感35% + 意象25% + 主题25% + 氛围15%）
2. **严格真实性验证**（作者、朝代、原文、归属四重校验）
3. **质量门控检查**（真实性 → 匹配质量 → 信息质量）
4. **匹配置信度**评估（高/中/低）

---

## 注意事项

- 输入越具体，匹配越精准
- 若对推荐结果不满意，可以补充更多细节（如偏好朝代、风格）重新匹配
- 所有输出诗词均经过真实性验证，但创作背景等信息若不确定会标注"暂缺"
- 如发现推荐不准确的诗词，欢迎反馈优化

---

## 技术说明

本 Skill 不依赖外部 API，通过结构化 prompt 指导 AI 利用自身古诗词知识完成匹配。核心方法论包括：

- 20+ 常见意象与情感映射词典
- 按体裁/题材/情感三维分类的诗词体系
- 量化评分算法与三级质量门控
- 完整的反向质量约束（防退化机制）

详细技术文档见 `references/poetry-guide.md`。
