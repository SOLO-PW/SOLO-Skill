# Poetry Match

根据用户输入的语境和意境，智能匹配最相似的真实古诗词，提供详细的匹配分析和完整的诗词信息。

## 核心约束

### 正向质量要求

1. **真实性第一** — 每首输出的诗词必须是真实存在的，作者、朝代、原文准确无误。绝不可编造、拼接或张冠李戴
2. **主动联网核验** — 输出前默认执行「必做 WebSearch 真实性核验」，将每首入选诗词的作者、朝代、原文与网络权威检索结果比对，杜绝张冠李戴。可通过内置开关关闭（见「联网核验开关」）
3. **核验结果留痕** — 输出中必须标注是否已完成联网核验，以及核验通过所依据的置信度来源，提升可信度
4. **多维度匹配** — 综合情感、意象、主题、氛围多维度判断，输出最契合的诗词
5. **详细输出** — 除诗词原文外，提供体裁、题材、主题标签、匹配理由、适用场景等完整信息
6. **有理有据** — 每首推荐均需给出具体的匹配理由，包含维度分析和匹配度评级

---

### 联网核验开关

| 开关 | 设置位置 | 行为 |
|------|---------|------|
| **开（默认）** | 无显式命令 | 每首候选输出前**必做** WebSearch 真实性与归属校验，校验通过才输出 |
| **关** | 用户显式声明「不需要联网核验 / 离线模式」 | 跳过 WebSearch，仅执行内部记忆自检，并在输出「核验状态」处诚实标注「未联网核验，仅内部自检」 |

### 反向质量约束（质量红线）

以下行为**严格禁止**：

| 红线 | 禁止行为 | 触发处理 |
|------|---------|---------|
| 🚫 **真实性妥协** | 为匹配度而使用存疑诗词 | 立即换候选，无可用的则诚实告知 |
| 🚫 **信息造假** | 编造创作背景、名句赏析 | 删除该部分，仅输出确认真实的信息 |
| 🚫 **牵强附会** | 匹配理由强行关联，缺乏逻辑 | 重新分析，无法建立合理关联则换候选 |
| 🚫 **置信度虚标** | 实际匹配度低却标注高星级 | 重新评估，按实际匹配度标注 |
| 🚫 **空洞填充** | 为填满字段而输出无意义内容 | 标注"暂缺"或直接省略 |
| 🚫 **重复推荐** | 多首推荐实质是同一意境变体 | 去重，确保每首有独立价值 |

### 质量门控

输出前必须通过三级门控：

```
门控1: 真实性检查 → 任一失败则拒绝输出
门控2: 匹配质量检查 → 匹配度<60则降级处理（明确告知）
门控3: 信息质量检查 → 存疑内容删除或标注"暂缺"
```

## 工作流程

### 1. 解析用户输入

从用户输入中提取四个维度（详见 poetry-guide.md）：

- **情感基调**：核心情绪（喜/哀/壮/愁/思/淡/怒/惧）+ 情感强度（1-3级）+ 复杂度（单一/复合）
- **场景意象**：自然意象（月/柳/酒/山/水等）+ 时空背景 + 人物活动
- **人生主题**：离别/思乡/怀古/壮志/爱情/隐逸/时光/友情/贬谪/边塞/田园等
- **语言风格**：豪放/婉约/清新/沉郁/空灵/质朴 + 修辞特征

**输入类型判断**：情感直述型 | 场景描述型 | 主题诉求型 | 现代转译型 | 半句引用型 | 多义模糊型

### 2. 候选检索与评分

**检索策略**：
1. **第一轮精准匹配**：情感、意象、主题至少两个维度高度匹配
2. **第二轮扩展匹配**：至少一个维度高度匹配，增加多样性
3. **第三轮意境匹配**：以整体意境为主要依据（适用于抽象输入）

**评分算法**：
```
匹配度 = 情感共鸣分 × 0.35 + 意象重合分 × 0.25 + 主题契合分 × 0.25 + 氛围相似分 × 0.15
```

### 3. 真实性验证

对选定的诗词执行严格核验（默认联网核验，开关关闭时降级为内部自检）：

**A. 联网核验（开关「开」，默认）— 每首候选必做：**

- 🌐 **WebSearch 检索**：以「作者名 + 诗词标题」为关键词检索权威来源（古籍库、权威诗词网站、出版社文献等）
- ✅ **作者归属**：确认检索结果中诗词归属于标注作者，无张冠李戴
- ✅ **原文一致**：比对检索到的原文，确认无错字、漏字、拼接，标题用标准名称
- ✅ **朝代核实**：作者与朝代匹配准确
- **⚠️ 检索结果与候选冲突、或存在权威存疑时，不输出该诗，换选其他候选**
- 校验通过的诗词记录「联网核验通过 + 来源」用于输出留痕

**B. 内部自检（开关「关」时降级）：**

- ✅ 作者确为历史人物，朝代标注准确
- ✅ 原文与记忆中的权威版本一致，无错字、漏字、拼接
- ✅ 诗词确实为标注作者所作，无张冠李戴
- ✅ 标题使用标准名称
- **⚠️ 若对任何一项有疑虑，不输出该诗，换选其他候选**

### 4. 格式化输出

默认输出 **1 首最佳匹配**。用户明确要求多首时，最多输出 **5 首**，按匹配度降序排列。

**多样性 vs 准确性平衡**：
- 若高匹配候选不足5首，只输出实际有的高质量推荐
- **宁可输出2首高质量，不输出5首凑数**
- 多首推荐需确保每首有独立价值，避免同一意境的重复变体

**标准输出模板**：

```
## 📜 《诗词标题》

**[朝代] · [作者]**（[字/号，若有]）

> 诗词原文（完整呈现，分行排版）

### 🏷️ 基本信息
- **体裁**：[古体诗/律诗/绝句/词/曲] [五言/七言/词牌名]
- **题材**：[边塞/田园/山水/送别/咏史/爱情/哲理/羁旅等]
- **主题标签**：#标签1 #标签2 #标签3

### 💡 匹配理由

**核心契合点**：[1句概括最核心匹配点]

**详细分析**：
- 情感维度：[输入情感] ↔ [诗词情感]，[具体分析]
- 意象维度：[输入意象] ↔ [诗词意象]，[具体分析]  
- 主题维度：[输入主题] ↔ [诗词主题]，[具体分析]

**匹配度**：⭐⭐⭐⭐⭐（5星制）

### 📖 背景与赏析

**创作背景**：[1-2句创作背景，助于理解]

**名句赏析**：[若有精妙之句，简要点评]

**适用场景**：[该诗词适合在什么场景引用或表达]

---

**匹配说明**：本次推荐基于[情感/意象/主题]维度匹配，置信度[高/中/低]。
若需更精准的匹配，可提供更多细节，如：具体场景、情感强度、偏好朝代等。

**核验状态**：[已联网核验 ✔ | 未联网核验，仅内部自检]（作者/朝代/原文已与[来源类型，如权威诗词网站]比对，无张冠李戴）

**信息缺失标注规范**：
- 创作背景不确定 → 标注"创作背景：暂缺"或直接省略
- 名句赏析无特别亮点 → 标注"名句赏析：暂缺"或省略
- 绝不编造内容填充字段
```

### 5. 特殊场景处理

| 场景 | 处理策略 |
|------|---------|
| **情感直述** | 情感共鸣优先，如意象重合更佳 |
| **场景描述** | 意象重合优先，兼顾情感基调 |
| **半句引用** | 补全原诗全文并输出完整信息 |
| **现代场景** | 提取底层情感，跨时空匹配（参考现代场景转译表） |
| **抽象概念** | 主题契合与哲学思考优先 |
| **多义模糊** | 列出可能解读，提供多选项或邀请细化 |
| **无高匹配** | 诚实告知，提供意境最接近的确认真实诗词 |

## 使用示例

### 示例 1：情感直述

**用户输入**："最近感觉很孤独，想找首诗表达一下"

**解析**：
- 情感：孤独/寂寞，强度中等，单一情感
- 意象：无特定意象
- 主题：孤寂/思乡
- 风格：偏婉约

**输出方向**：张继《枫桥夜泊》、柳宗元《江雪》、李白《独坐敬亭山》等

### 示例 2：场景描述

**用户输入**："秋天傍晚，看着夕阳下的柳树，想起远方的朋友"

**解析**：
- 情感：思念/惆怅，强度中等
- 意象：秋、夕阳、柳（离别意象）
- 主题：离别/友情/时光
- 风格：婉约

**输出方向**：柳永《雨霖铃》、王维《送元二使安西》等

### 示例 3：现代转译

**用户输入**："加班到深夜，一个人走在回家的路上"

**解析**：
- 底层情感：孤独/疲惫/漂泊感
- 现代场景 → 古代对应：羁旅/夜行/思乡

**输出方向**：马致远《天净沙·秋思》、张继《枫桥夜泊》等

## 质量承诺

每首推荐的诗词均经过：
1. **多维度匹配算法**筛选
2. **主动联网核验**（默认必做 WebSearch 真实性与归属校验）
3. **核验结果留痕**（输出明确标注核验状态与来源）
4. **质量自检清单**检查
5. **匹配置信度**评估

如推荐不准确，欢迎提供反馈，可根据具体偏差调整匹配维度重新推荐。
