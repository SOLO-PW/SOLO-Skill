# 预览分析

## 概述

预览模式仅输出分析报告，不生成融合 Skill。用于在正式融合前评估可行性和风险，帮助用户做出明智决策。

## 适用场景

- 不确定两个 Skill 是否值得融合
- 想了解融合的复杂度和潜在冲突
- 需要向团队展示融合方案以获取共识
- 评估多种融合组合方案

## 预览分析流程

### 步骤 1：收集验证

同 full 模式步骤 1，验证所有输入 Skill 的完整性。

### 步骤 2：深度解析

同 full 模式步骤 2，为每个 Skill 构建能力画像。

### 步骤 3：关系分析

同 full 模式步骤 3，执行完整的交叉分析。

### 步骤 4：生成分析报告

基于步骤 1-3 的结果，生成结构化分析报告。

## 多 Skill 预览

当预览 3+ 个 Skill 时，报告增加分组建议：

```markdown
## 批量融合分组建议

### 推荐分组策略

[高交叉优先 / 领域聚类 / 流水线顺序]

### 分组方案

| 轮次 | 分组 | 理由 |
|------|------|------|
| 第一轮 | (A + B), (C + D) | [理由] |
| 第二轮 | (AB + CD) | [理由] |

### 预估总轮次

[X] 轮

### 复杂度预警

[如有预警信号，列出]
```

## 预览报告的使用方式

1. **用户自行决策** — 阅读报告后决定是否融合
2. **团队讨论** — 将报告分享给团队获取共识
3. **方案对比** — 对不同 Skill 组合分别生成预览报告，对比选择最优方案
4. **融合准备** — 根据报告中的冲突清单和风险，提前准备解决方案
