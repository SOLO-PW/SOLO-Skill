# Skill Post Writer

帮你一键生成符合 SOLO 技能创作赛官方标准的参赛帖子。

---

## 这是什么？

这是一个专门为 SOLO 技能创作赛设计的 Skill，解决参赛者在写帖子时的痛点：

- ❌ 不知道帖子该写哪些内容
- ❌ 不清楚官方要求的格式
- ❌ 写了删、删了写，效率低下
- ❌ 结构混乱，影响参赛效果

使用这个 Skill，只需要提供基本信息，5 分钟就能生成一篇结构完整、格式规范的参赛帖子。

---

## 适用场景

- 参加 SOLO 技能创作赛，需要提交参赛作品帖
- 想分享自己创建的 Skill 但不知如何组织内容
- 希望帖子符合官方标准，提高获奖概率

---

## 快速开始

### 1. 告诉 Skill 你的需求

```
帮我写一篇 Skill 参赛帖子
```

### 2. 提供基本信息

Skill 会问你几个问题：

| 问题 | 示例回答 |
|------|----------|
| Skill 名称 | skill-post-writer |
| 一句话描述 | 帮你一键生成符合官方标准的 Skill 参赛帖子 |
| 解决什么问题 | 不知道如何组织参赛帖内容、结构不清晰 |
| 目标用户 | 参加 SOLO 技能创作赛的用户 |
| 使用场景 | 需要提交参赛作品帖时 |
| Skill 链接 | GitHub 或本地路径 |

### 3. 获取完整帖子

Skill 会自动生成包含 7 个标准部分的 Markdown 帖子，保存到当前目录。

---

## 生成的帖子结构

```
【Skill 创作】{一句话描述}
├── 1、Skill简介
├── 2、使用场景
├── 3、创作过程
├── 4、使用步骤
├── 5、效果展示
├── 6、Skill链接
└── 7、总结与思考
```

完全符合 [SOLO 技能创作赛投稿指南](https://forum.trae.cn/t/topic/15661) 要求。

---

## 写作风格特点

- ✅ **第一人称**：像真实用户分享经验
- ✅ **口语化表达**：轻松自然，不生硬
- ✅ **真实情感**：承认困难，分享收获
- ✅ **具体细节**：时间、步骤、数据
- ✅ **有互动感**：结尾邀请反馈

## 使用示例

### 示例 1：基础使用

**用户：** 帮我写一篇 Skill 参赛帖子

**Skill：** 好的，请告诉我：
1. 你的 Skill 叫什么名字？
2. 用一句话描述它做什么？
3. 解决了什么问题？
4. 适合谁使用？
5. Skill 链接是什么？

**用户：** （提供信息）

**Skill：** （生成完整帖子并保存）

### 示例 2：详细使用

**用户：** 帮我为我的 "桌面宠物 Skill" 写一篇参赛帖，它能让我在 SOLO 里养一只桌面宠物，适合想要个性化桌面的用户。

**Skill：** 好的，我来为你生成帖子...

## 注意事项

1. **真实为本**：提供真实的信息，不要虚构功能
2. **信息越详细，帖子质量越高**：尽量多提供使用场景、创作过程等细节
3. **截图使用外链**：社区不支持直接上传，请使用图床或网盘
4. **适当调整**：生成的帖子是初稿，建议根据实际情况微调

---

## 优质帖子特征

根据官方指南，好的参赛帖通常有：

- ✅ 标题清楚，一眼就知道做了什么
- ✅ 场景真实，是真问题不是空泛概念
- ✅ 过程完整，能看出不是只放了个结果
- ✅ 展示充分，有截图、有对比、有说明
- ✅ 表达清晰，层次分明读起来不费劲
- ✅ 有个人判断，不是流水账

## 常见问题

**Q: 生成的帖子可以直接投稿吗？**

A: 可以，但建议根据自己的实际情况微调，加入更多个人色彩和真实细节。

**Q: 我不知道某些信息怎么办？**

A: 可以告诉 Skill "我不知道"或"[待补充]"，Skill 会用占位符标注，你可以后续补充。

**Q: 可以生成多篇帖子吗？**

A: 可以，每个 Skill 都可以生成一篇独立的参赛帖。

**Q: 帖子格式是固定的吗？**

A: 7 个部分的结构是固定的（官方要求），但内容会根据你提供的信息个性化生成。
