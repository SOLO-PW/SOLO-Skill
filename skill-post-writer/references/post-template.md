# Skill 推广帖子标准模板

## 帖子结构规范

本模板定义了撰写 Skill 推广帖子的标准结构，共 7 个必要部分。

---

## 1. Skill 简介

**写作要求：**
- 用 1-2 句话说明 Skill 名称
- 清晰描述解决了什么问题
- 明确实现了什么效果
- 指明适合谁使用

**示例：**
> 这是一个帮助内容运营快速完成选题整理、标题生成和平台改写的 Skill，适合需要频繁产出社媒内容的同学使用。

**检查清单：**
- [ ] 包含 Skill 名称
- [ ] 说明解决的问题
- [ ] 描述达到的效果
- [ ] 明确目标用户

---

## 2. 使用场景

**写作要求：**
- 描述具体的工作/生活场景
- 回答三个核心问题：
  1. 你为什么想做它？（动机）
  2. 你之前遇到了什么麻烦？（痛点）
  3. 做出来之后能省掉哪些动作？（价值）

**示例：**
> 我是一名小红书博主，每天需要发布内容。以前写一篇帖子需要 2-3 小时：先选题，再查资料，再写文案，最后还要改写成不同平台的版本。
>
> 用这个 Skill 后，我只需要输入几个关键词，5 分钟就能生成一篇完整的帖子，还能一键改写成抖音、微博等多个平台的版本。效率提升了至少 10 倍！

**检查清单：**
- [ ] 有具体场景描述
- [ ] 说明原始痛点
- [ ] 量化时间节省（如果可能）
- [ ] 描述具体省掉的步骤

---

## 3. 创作过程

**写作要求：**
- 展示使用 SOLO 的创作过程
- 可附上关键提示词
- 可描述工作流配置
- 不用展示所有技术细节
- 至少让人看懂如何做出来的

**示例：**
> 我是这样创建的：
>
> 1. **明确需求**：告诉 SOLO "帮我创建一个 xxx 的 Skill"
> 2. **描述功能**：详细说明这个 Skill 需要做什么
> 3. **迭代优化**：根据生成结果进行调整
>
> 关键提示词示例：
> ```
> 创建一个帮助我 [具体功能] 的 Skill，适合 [目标用户] 使用
> ```

**检查清单：**
- [ ] 有明确的创作步骤
- [ ] 包含可参考的提示词
- [ ] 描述了整体流程
- [ ] 避免过于技术性的细节

---

## 4. 使用步骤

**写作要求：**
- 清晰介绍如何调用 Skill
- 提供详细操作步骤
- 步骤编号清晰
- 每步说明清楚动作

**示例：**
> ### 如何使用这个 Skill
>
> 1. 打开 SOLO，点击 Skill 商店
> 2. 搜索 "xxx Skill"
> 3. 点击安装
> 4. 在对话框输入你的需求
> 5. 等待生成结果

**检查清单：**
- [ ] 步骤编号连续
- [ ] 每步动作明确
- [ ] 不遗漏必要步骤
- [ ] 语言简洁易懂

---

## 5. 效果展示

**写作要求：**
- 提供清晰的截图或效果对比
- 展示使用前后的对比
- 视觉效果清晰
- 说明关键变化点

**写作规范：**
- 图片使用 `![](图片链接)` 格式
- 图片需要真实有效
- 需要至少 2 张对比图
- 标注关键差异点

**检查清单：**
- [ ] 有使用前的效果截图
- [ ] 有使用后的效果截图
- [ ] 标注了关键差异
- [ ] 图片清晰可读

---

## 6. Skill 链接

**写作要求：**
- 附上 Skill 分享链接
- 如果有额外资源一并提供
  - GitHub 仓库
  - 说明文档
  - Demo 演示

**示例：**
> **Skill 下载链接：**
> [Skill Name](https://example.com/skill-link)
>
> **相关资源：**
> - GitHub: [仓库地址](链接)
> - 文档: [说明文档](链接)

**检查清单：**
- [ ] 包含主链接
- [ ] 链接格式正确
- [ ] 可选资源链接完整

---

## 7. 总结与思考

**写作要求：**
- 分享实际收获
- 可包含效率提升数据
- 分享对 AI 工作方式的新感悟

**必须回答：**
1. 这个 Skill 目前最满意的地方是什么？
2. 后续还想怎么优化？
3. 希望别人怎么体验或给你什么建议？

**示例：**
> ### 总结与思考
>
> **效率提升：** 使用后从 2-3 小时缩短到 5 分钟，效率提升约 20 倍。
>
> **最满意的地方：** 自动化的程度很高，基本不需要人工干预。
>
> **后续优化方向：** 计划加入更多模板选项。
>
> **建议：** 建议先从简单场景开始使用，慢慢探索更多功能。

**检查清单：**
- [ ] 有明确的收获描述
- [ ] 回答了三个必答问题
- [ ] 语言真诚不夸大
- [ ] 提供了可落地的建议

---

## 通用写作规范

### 语气与风格
- 轻松但专业
- 使用第一人称"我"
- 真诚不夸大
- 具体不笼统

### 格式要求
- Markdown 格式规范
- 标题层级清晰
- 列表使用有序或无序
- 适当使用加粗强调

### 禁止事项
- 不要虚构不存在的功能
- 不要夸大使用效果
- 不要抄袭他人内容
- 不要堆砌空洞词汇

---

## 快速检查清单

完成帖子后，逐项检查：

- [ ] **1. Skill 简介**：名称、问题、效果、用户都写清楚了吗？
- [ ] **2. 使用场景**：动机、痛点、价值都说清楚了吗？
- [ ] **3. 创作过程**：步骤和提示词可供参考吗？
- [ ] **4. 使用步骤**：操作流程清晰可执行吗？
- [ ] **5. 效果展示**：有前后对比截图吗？
- [ ] **6. Skill 链接**：链接有效吗？
- [ ] **7. 总结与思考**：三个问题都回答了吗？
- [ ] **整体**：语气真诚、结构清晰、内容真实吗？
