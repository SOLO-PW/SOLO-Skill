# Skill Post Writer

## 概述

这是一个帮助用户撰写 SOLO 技能创作赛标准参赛帖子的 Skill。根据官方投稿指南设计，生成的帖子包含 7 个标准部分，格式规范、内容真实、适合参赛。

**适用场景：**
- 参加 SOLO 技能创作赛，需要提交参赛作品帖
- 想分享自己创建的 Skill 但不知如何组织内容
- 需要一篇规范、易读的推广帖子

## 核心能力

1. **格式规范**：严格按照官方要求的 7 部分结构输出
2. **真实可信**：强调真实效果，避免夸大
3. **步骤完整**：创作过程、使用步骤清晰可执行
4. **效果展示**：支持截图、录屏外链格式

## 工作流程

### Step 1: 收集信息

主动询问用户以下信息：

| 信息项 | 说明 | 必填 |
|--------|------|------|
| Skill 名称 | 要推广的 Skill 叫什么 | 是 |
| 一句话描述 | 标题用的简短描述 | 是 |
| 解决什么问题 | Skill 的核心用途 | 是 |
| 目标用户 | 适合谁使用 | 是 |
| 使用场景 | 具体在什么情况下使用 | 建议提供 |
| 创作过程 | 如何用 SOLO 创建的 | 建议提供 |
| Skill 链接 | GitHub 或分享链接 | 是 |
| 效果截图 | 使用效果截图 | 建议提供 |

### Step 2: 生成帖子

按照官方标准格式生成帖子。

### Step 3: 保存文件

将帖子保存为 Markdown 文件：`【Skill 创作】{一句话描述}.md`

### Step 4: 审核优化

1. 检查 7 个部分是否完整
2. 确认数据真实合理
3. 询问是否需要调整

## 写作风格指南

### 语气要求

- ✅ **第一人称**：用"我"而不是"用户"
- ✅ **轻松自然**：像跟朋友聊天一样
- ✅ **真实坦诚**：承认不足和局限性
- ✅ **有个人色彩**：加入自己的思考和感悟
- ❌ **避免机械**：不要用"本 Skill"、"本产品"等生硬表达
- ❌ **避免空洞**：不要堆砌形容词，要有具体例子

### 内容要求

- ✅ **讲故事**：用场景引入，不要直接罗列功能
- ✅ **有细节**：具体的数字、时间、操作步骤
- ✅ **有情感**：表达自己的真实感受
- ✅ **有互动**：结尾邀请读者反馈

### 结构要求

- 每个部分之间用 `---` 分隔
- 标题使用 `## 1、xxx` 格式（顿号，不是点）
- 子标题使用 `###` 或 `**第一步**` 格式
- 代码块、表格适当使用，但不要过多

---

## 什么样的帖子更容易成为优质投稿

根据官方指南，好帖子通常有这些共同点：

- ✅ **标题清楚**：别人一眼就知道你做了什么
- ✅ **场景真实**：不是空泛概念，而是真问题
- ✅ **过程完整**：能看出你不是只放了个结果
- ✅ **展示充分**：有截图、有对比、有说明
- ✅ **表达清晰**：层次分明，读起来不费劲
- ✅ **有个人判断**：不是流水账，而是有自己的思考

---

## 哪些情况可能被判定为无效投稿

- ❌ 只有一句话介绍，没有过程、没有展示
- ❌ 纯粹复制别人的内容或搬运他人作品
- ❌ 标题和正文严重不符
- ❌ 没有实际作品链接
- ❌ 大量空泛表述，没有真实使用信息
- ❌ 只靠 AI 拼接生成、没有真实体验和判断
