# Break Up

## Overview

这个 Skill 帮助用户分析聊天内容，生成分手话术。通过分析对话情感和上下文，生成能够引对方生气或降低好感的自然、不直白的回复，适用于各种性别组合和沟通场景。

**覆盖范围：**
- **沟通场景**：聊天、电话、视频等日常沟通场景；未来规划、家庭问题、金钱问题等特定话题场景；节假日、纪念日、生日等特定时间场景；刚确立关系、热恋期、磨合期等特定关系阶段场景
- **性别组合**：男性对女性、女性对男性、男性对男性、女性对女性、跨性别组合、双性恋组合等
- **分手情景**：过度依赖、情感勒索、冷暴力、争吵不断、第三者等常见分手情景

## Workflow Decision Tree

当用户提供聊天内容时，按以下流程处理：

### Step 1: 输入分析

解析用户提供的聊天内容：

- 识别对话双方（用户和对方）
- 提取关键对话内容和情感表达
- 识别对话的转折点和矛盾焦点
- 分析对话的上下文和背景信息

**输入格式示例：**
```
用户：我最近工作很忙，没时间陪你
对方：你总是这样，根本不在乎我
用户：我不是不在乎，是真的忙
对方：那你到底爱不爱我？
```

### Step 2: 情感分析

分析对话的情感状态和关系动态：

- 识别主要情感（愤怒、失望、焦虑、冷漠等）
- 分析权力关系（谁更强势、谁更依赖）
- 识别矛盾焦点（沟通问题、信任问题、价值观冲突等）
- 评估当前关系的紧张程度

**情感分析要点：**
- 对方的情感诉求是什么？
- 用户的真实意图是什么？
- 关系中存在哪些根本性问题？
- 对方最在意什么？

### Step 3: 话术生成

基于情感分析结果，生成符合情景的分手话术：

**话术原则：**
- 自然流畅，不直白生硬
- 结合具体情景，不虚空捏造
- 引导对方产生负面情绪或降低好感
- 避免明显的人身攻击或恶意伤害
- 考虑性别差异和沟通风格

**话术类型：**

| 类型 | 说明 | 适用场景 | 效果强度 |
|------|------|----------|----------|
| **冷淡回应** | 降低情感温度，让对方感到被忽视 | 对方过度热情、粘人 | ⭐⭐ |
| **转移焦点** | 将问题转移到其他方面，避免正面回应 | 对方追问承诺、未来 | ⭐⭐ |
| **合理化借口** | 用看似合理的理由掩盖真实意图 | 需要减少陪伴、沟通 | ⭐⭐ |
| **情感绑架** | 让对方感到内疚或自责 | 对方质疑你的付出 | ⭐⭐⭐ |
| **模糊承诺** | 给出不确定的承诺，拖延时间 | 对方要求明确答复 | ⭐⭐ |
| **制造矛盾** | 引发争吵，加速关系恶化 | 需要快速降温 | ⭐⭐⭐⭐ |
| **设定边界** | 强调个人空间和独立性 | 对方过度依赖 | ⭐⭐ |
| **价值观冲突** | 强调观念差异，暗示不合适 | 长期关系、家庭问题 | ⭐⭐⭐⭐ |
| **经济压力** | 利用经济问题制造距离 | 对方期待物质付出 | ⭐⭐⭐ |
| **社交疏离** | 减少社交互动和公开关系 | 对方要求更多公开 | ⭐⭐⭐ |

### Step 4: 效果评估

评估生成话术的可能效果：

- 预测对方可能的反应
- 评估话术的有效性
- 识别潜在风险和副作用
- 提供备选方案和调整建议

**效果评估维度：**

| 维度 | 评估标准 |
|------|----------|
| **自然度** | 话术是否听起来自然，不像是刻意为之 |
| **有效性** | 是否能达到降低好感/引发矛盾的目的 |
| **安全性** | 是否会引发对方过激反应（如自残、报复） |
| **可逆性** | 如果反悔，是否有回旋余地 |

## 渐进式分手策略

分手不是一蹴而就的，而是一个渐进的过程。根据关系状态选择合适的策略阶段：

### 阶段一：降温期（1-2 周）

**目标**：降低情感温度，减少亲密互动

**话术策略**：
- 减少回复频率和热情度
- 用工作/学习/家庭作为借口
- 减少主动发起对话

**示例话术**：
```
"最近工作比较忙，可能回复会慢一些。"
"我最近在准备一个项目，没什么时间聊天。"
"我今天有点累，想早点休息。"
```

### 阶段二：疏离期（2-4 周）

**目标**：制造距离感，减少依赖

**话术策略**：
- 强调个人空间和独立性
- 减少见面和约会
- 制造小矛盾，引发争吵

**示例话术**：
```
"我觉得我们需要一些个人空间。"
"我最近想多花点时间在自己身上。"
"你有没有觉得我们最近总是吵架？"
```

### 阶段三：冲突期（1-2 周）

**目标**：制造不可调和的矛盾

**话术策略**：
- 放大性格差异和价值观冲突
- 引发关于未来的争论
- 表达对关系的怀疑

**示例话术**：
```
"我们的性格好像真的不太合适。"
"你有没有想过，我们对未来的规划可能不一样？"
"我开始怀疑我们是不是真的适合在一起。"
```

### 阶段四：分手期

**目标**：正式提出分手

**话术策略**：
- 直接表达分手意愿
- 强调不合适的原因
- 保持坚定，不给虚假希望

**示例话术**：
```
"我想了很久，我觉得我们不太适合继续在一起了。"
"我很珍惜我们在一起的时光，但我觉得我们应该各自去寻找更适合自己的人。"
"这不是一时冲动，我认真想过了。"
```

## 话术组合策略

单一话术往往效果有限，组合使用可以达到更好的效果：

### 组合一：冷淡 + 转移焦点

**适用场景**：对方过度热情，需要降温

**示例**：
```
对方：我想你了，你什么时候来看我？
用户：最近工作比较忙（冷淡），你最近怎么样？（转移焦点）
```

### 组合二：合理化借口 + 设定边界

**适用场景**：对方要求过多陪伴

**示例**：
```
对方：你为什么总是不回我消息？
用户：我最近在准备一个重要的项目（合理化借口），我需要一些专注的时间（设定边界）
```

### 组合三：情感绑架 + 制造矛盾

**适用场景**：需要快速降温，引发争吵

**示例**：
```
对方：你为什么不陪我？
用户：我为了我们的未来在努力工作，你却不理解我（情感绑架），你总是这样要求我（制造矛盾）
```

### 组合四：价值观冲突 + 模糊承诺

**适用场景**：长期关系，需要铺垫分手

**示例**：
```
对方：我们什么时候结婚？
用户：我们的未来规划好像不太一样（价值观冲突），等时机成熟了再说吧（模糊承诺）
```

## 性别差异处理

不同性别的沟通风格和情感需求不同，话术需要相应调整：

### 对女性的话术特点

**女性更在意**：
- 情感回应和关注度
- 安全感和承诺
- 细节和仪式感

**话术调整**：
- 减少情感回应，让她感到被忽视
- 回避承诺和未来规划
- 忽略细节和仪式感

**示例**：
```
"你太敏感了，我只是需要一些空间。"
"我觉得我们现在这样挺好的，没必要想那么远。"
"你太在意这些形式了，我觉得不重要。"
```

### 对男性的话术特点

**男性更在意**：
- 尊重和认可
- 独立性和空间
- 实际问题和解决方案

**话术调整**：
- 质疑他的能力和决定
- 限制他的独立性和空间
- 放大实际问题，制造矛盾

**示例**：
```
"你总是这样，从来不考虑我的感受。"
"你能不能多花点时间陪我？你总是忙自己的事。"
"我们的消费观念好像不太一样，我觉得你太浪费了。"
```

### 对同性的话术特点

**同性关系更在意**：
- 平等和理解
- 共同兴趣和价值观
- 社会认可和压力

**话术调整**：
- 强调性格和价值观差异
- 质疑关系的可持续性
- 利用社会压力和外部因素

**示例**：
```
"我们的性格好像真的不太合适。"
"你有没有想过，我们的未来规划可能不一样？"
"我最近压力很大，我觉得我们的关系让我更累了。"
```

## 特殊场景处理

### 场景 1：对方有自残/自杀倾向

**处理方式：**
- 不要使用激进的话术
- 保持冷静，不要被情绪操控
- 建议对方寻求专业帮助
- 必要时联系对方的家人或朋友

**参考话术：**
```
"我觉得你现在情绪很激动，我们冷静一下再谈好吗？"
"我很担心你，你有没有考虑过和专业人士聊聊？"
"我希望你能照顾好自己，不管我们之间怎么样。"
```

### 场景 2：对方有暴力倾向

**处理方式：**
- 不要激怒对方
- 保持安全距离
- 不要在私密空间单独见面
- 必要时寻求法律帮助

**参考话术：**
```
"我觉得我们现在情绪都不太好，我们改天再谈好吗？"
"我希望我们能冷静地谈这个问题。"
"我需要一些时间，我们之后再联系。"
```

### 场景 3：涉及共同财产

**处理方式：**
- 不要在争吵中处理财产问题
- 保持理性，记录相关证据
- 必要时寻求法律咨询

**参考话术：**
```
"关于财产的问题，我们之后再谈好吗？"
"我希望我们能理性地处理这个问题。"
"我觉得我们可以找一个中立的人来帮忙处理。"
```

## 话术注意事项

### 避免被识破

- 不要过于明显地使用话术，保持自然
- 不要频繁使用同一种话术类型
- 根据对方的反应调整话术策略
- 不要在情绪激动时使用话术

### 应对反问

当对方反问时，保持冷静，不要被情绪操控：

**对方问：你是不是想分手？**
```
"你怎么会这么想？我只是最近压力比较大。"
"我没有这个意思，我只是需要一些时间。"
"你想多了，我只是最近比较忙。"
```

**对方问：你是不是有别人了？**
```
"你怎么会这么想？我只是最近比较忙。"
"我没有这个意思，我只是需要一些时间。"
"你想多了，我只是最近压力比较大。"
```

**对方问：你到底爱不爱我？**
```
"我当然爱你，只是最近压力比较大。"
"我当然爱你，只是需要一些时间。"
"我当然爱你，只是最近比较忙。"
```
