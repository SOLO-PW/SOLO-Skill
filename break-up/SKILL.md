# Break Up

## Overview

这个 Skill 帮助用户分析聊天内容，生成清晰、尊重地结束或调整关系的话术。通过分析对话情感和上下文，输出自然、不直白的回复，适用于各种性别组合和沟通场景。

**覆盖范围：**
- **沟通场景**：聊天、电话、视频等日常沟通场景；未来规划、家庭问题、金钱问题等特定话题场景；节假日、纪念日、生日等特定时间场景；刚确立关系、热恋期、磨合期等特定关系阶段场景
- **性别组合**：男性对女性、女性对男性、男性对男性、女性对女性、跨性别组合、双性恋组合等
- **分手情景**：过度依赖、情感勒索、冷暴力、争吵不断、第三者等常见分手情景

**⚠️ 伦理与安全使用声明**：本 Skill 仅用于开放的、非强迫性的关系沟通。绝不支持通过欺骗、情感操纵或以伤害对方为目的的使用方式。所有生成内容默认遵守下方「伦理安全护栏」。

---

## 伦理安全护栏（必须遵守）

本 Skill 帮助在关系中明确边界或结束关系，但**绝不助长操纵或伤害**。每次输出前必须逐条核对：

1. **不主动鼓励操纵** — 不以「引对方生气 / 降低好感」为唯一目标。先评估输出方式是否健康、尊重，仅把降温话术作为非强迫沟通的辅助手段。
2. **始终提供健康选项** — 生成话术时**必须并列**提供「坦诚沟通 / 健康分手」版本，尊重对方的知情权与自主选择，不下套、不精神控制。
3. **高风险优先** — 一旦检测到自残 / 自杀、暴力、威胁、报复等高风险信号，**立即停止生成激化话术**，切换到「特殊场景处理」的安全流程。
4. **专业求助提示** — 涉及心理健康危机时，主动建议双方寻求专业帮助（心理援助热线 / 心理咨询师 / 身边信任的人），并提供可操作建议。
5. **禁止攻击性内容** — 不输出人身攻击、人格侮辱、威胁、恐吓、PUA 式言语（完整禁止清单见 [references/response-templates.md](references/response-templates.md) 的「话术使用注意事项」）。

## Workflow Decision Tree

当用户提供聊天内容时，按以下流程处理：

### Step 1: 输入分析

解析用户提供的聊天内容：

- 识别对话双方（用户和对方）
- 提取关键对话内容和情感表达
- 识别对话的转折点和矛盾焦点
- 分析对话的上下文和背景信息

**输入格式示例：**
```
用户：我最近工作很忙，没时间陪你
对方：你总是这样，根本不在乎我
用户：我不是不在乎，是真的忙
对方：那你到底爱不爱我？
```

### Step 2: 情感分析

分析对话的情感状态和关系动态：

- 识别主要情感（愤怒、失望、焦虑、冷漠等）
- 分析权力关系（谁更强势、谁更依赖）
- 识别矛盾焦点（沟通问题、信任问题、价值观冲突等）
- 评估当前关系的紧张程度

**先做安全筛查**：若无权确认，优先判断是否存在自残、暴力、威胁等高危信号；命中则跳过话术生成，直接进入「特殊场景处理」。

### Step 3: 话术生成

基于情感分析结果，结合「话术类型表」选取合适类型生成话术。具体例句模板见 [references/response-templates.md](references/response-templates.md)，分场景完整示例见 [references/examples.md](references/examples.md)。

**话术原则：**
- 自然流畅，不直白生硬
- 结合具体情景，不虚空捏造
- 兼顾尊重与边界，铲除攻击性内容
- 每类话术同时给出「坦诚沟通」的健康替代版本

### Step 4: 效果评估

评估生成话术的可能效果：

- 预测对方可能的反应
- 评估话术的有效性
- 识别潜在风险和副作用（尤其安全风险）
- 提供备选方案和调整建议

**效果评估维度：**

| 维度 | 评估标准 |
|------|----------|
| **自然度** | 话术是否听起来自然，不像是刻意为之 |
| **有效性** | 是否能清晰传达意图、推进沟通 |
| **安全性** | 是否会引发对方过激反应（如自残、暴力、报复） |
| **可逆性** | 如果反悔，是否有回旋余地 |
| **尊重度** | 是否尊重对方知情与自主选择 |

## 话术类型表（索引）

以下为常用话术类型索引，对应路径见 [references/response-templates.md](references/response-templates.md)。渐进式分手策略、话术组合策略、性别差异调整、应对反问答辞均维护在 references。

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **冷淡回应** | 降低情感温度，让对方感到被忽视 | 对方过度热情、粘人 |
| **转移焦点** | 将问题转移到其他方面，避免正面回应 | 对方追问承诺、未来 |
| **合理化借口** | 用看似合理的理由掩盖真实意图 | 需要减少陪伴、沟通 |
| **情感绑架** | 让对方感到内疚或自责 | 对方质疑你的付出 |
| **模糊承诺** | 给出不确定的承诺，拖延时间 | 对方要求明确答复 |
| **制造矛盾** | 引发争吵，加速关系恶化 | 需要快速降温 |
| **设定边界** | 强调个人空间和独立性 | 对方过度依赖 |
| **价值观冲突** | 强调观念差异，暗示不合适 | 长期关系、家庭问题 |
| **经济压力** | 利用经济问题制造距离 | 对方期待物质付出 |
| **社交疏离** | 减少社交互动和公开关系 | 对方要求更多公开 |

> **章节一致性**：本表类型口径与 [response-templates.md](references/response-templates.md) 保持一致。新增类型必须先在该 references 中定义话术模板，再回填本索引，避免口径漂移。

## 特殊场景处理

以下场景**优先于话术生成**，命中即执行安全流程：

### 场景 1：对方有自残/自杀倾向

**处理方式：**
- 立即停止使用任何激进或施压话术
- 保持冷静与尊重，不被情绪操控
- 表达关心，引导对方寻求专业帮助
- 必要时联系对方信任的家人或朋友
- **建议求助渠道**：心理援助热线、当地心理咨询服务、急诊

**参考话术：**
```
"我很担心你，你有没有考虑过和专业人士聊聊？"
"你现在情绪很激动，我们冷静一下，我会陪着你。"
"不管我们之间怎么样，我希望你能照顾好自己。"
```

### 场景 2：对方有暴力倾向或存在安全威胁

**处理方式：**
- 不要激怒对方，停止任何挑衅性话术
- 保持安全距离，不在私密空间单独见面
- 处于危险中时及时求助（报警 / 联系可信亲友）
- 必要时寻求法律帮助或安全庇护

**参考话术：**
```
"我觉得我们现在情绪都不太好，我们改天再谈好吗？"
"我需要一些时间，我们之后再联系。"
"我希望我们都能冷静、安全地处理这件事。"
```

### 场景 3：涉及共同财产

**处理方式：**
- 不要在争吵中处理财产问题
- 保持理性，记录相关证据
- 必要时寻求法律咨询

**参考话术：**
```
"关于财产的问题，我们之后再理性地谈好吗？"
"我觉得我们可以找一个中立、专业的人帮忙处理。"
```
