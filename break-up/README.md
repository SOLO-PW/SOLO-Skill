# Break-up 分手话术生成器

> 一个帮助用户分析聊天内容、生成分手话术的 SOLO Skill。

---

## 功能概述

| 功能 | 说明 |
|------|------|
| **情感分析** | 分析聊天记录中的情感状态、矛盾焦点、权力关系 |
| **话术生成** | 根据分析结果生成 10 种类型的分手话术 |
| **效果评估** | 评估话术的自然度、有效性、安全性 |
| **特殊场景** | 处理自残倾向、暴力倾向、共同财产等复杂情况 |

---

## 使用方法

### 触发条件

提供聊天记录并表达以下意图之一：
- "帮我分析这段聊天"
- "我想分手，该怎么说"
- "怎么降低对方好感"
- "这段聊天怎么回复"

### 输入示例

```
对方：你最近怎么总是不回我消息？
我：最近工作比较忙
对方：你根本就不在乎我
我：我不是不在乎，是真的忙
```

### 输出内容

1. **情感分析**：情感状态、矛盾焦点、权力关系、性别组合
2. **话术建议**：3-5 条话术，含类型和预期效果
3. **效果评估**：自然度、有效性、安全性评分

---

## 话术类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 冷淡回应 | 降低情感温度，让对方感到被忽视 | 对方过度热情、粘人 |
| 转移焦点 | 将问题转移到其他方面，避免正面回应 | 对方追问承诺、未来 |
| 合理化借口 | 用看似合理的理由掩盖真实意图 | 需要减少陪伴、沟通 |
| 情感绑架 | 让对方感到内疚或自责 | 对方质疑你的付出 |
| 模糊承诺 | 给出不确定的承诺，拖延时间 | 对方要求明确答复 |
| 制造矛盾 | 引发争吵，加速关系恶化 | 需要快速降温 |
| 设定边界 | 强调个人空间和独立性 | 对方过度依赖 |
| 价值观冲突 | 强调观念差异，暗示不合适 | 长期关系、家庭问题 |
| 经济压力 | 利用经济问题制造距离 | 对方期待物质付出 |
| 社交疏离 | 减少社交互动和公开关系 | 对方要求更多公开 |
