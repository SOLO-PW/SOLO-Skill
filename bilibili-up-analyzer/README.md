# Bilibili UP主专业数据分析

> 一键生成 B 站 UP 主专业数据分析报告,支持多维度画像分析、智能评分和可视化图表

## ✨ 核心功能

### 📊 数据分析
- **多维度数据采集**: 自动获取 UP 主基础信息、视频列表、视频详情
- **智能输入识别**: 支持 UID、用户名、主页链接三种输入方式
- **数据缓存机制**: 24 小时缓存,避免重复请求,提升效率 10 倍

### 📈 报告生成
- **专业 Markdown 报告**: 包含 10 个章节的完整分析
- **可视化图表**: 分区分布饼图、视频类型柱状图、评分雷达图
- **多格式输出**: 支持 Markdown 和 JSON 格式

### 🎯 UP 主画像
- **内容创作画像**: 分析创作风格、更新模式、技术水平
- **受众画像**: 评估受众类型、忠诚度、内容偏好
- **商业价值画像**: 评估变现潜力、品牌适配度
- **成长潜力画像**: 分析发展阶段、增长势头、天花板

### ⭐ 智能评分
- **差异化评分算法**: 根据内容类型采用不同权重
- **多维度雷达图**: 6 个评分维度可视化展示
- **等级评定**: S/A/B/C/D 五级评价体系

## 📋 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `target` | string | 是 | UP 主 UID、用户名或主页链接 |
| `--recent` | int | 否 | 分析最近 N 个视频,默认 10 |
| `--all` | flag | 否 | 分析全部视频 |
| `--cache` | flag | 否 | 启用数据缓存 |
| `--cache-dir` | string | 否 | 缓存目录,默认 `./cache` |
| `--output` | string | 否 | 报告输出目录,默认 `./reports` |
| `--format` | string | 否 | 报告格式: `markdown`/`json`,默认 `markdown` |
| `--filename` | string | 否 | 指定输出文件名 |
| `--no-charts` | flag | 否 | 禁用图表生成 |
| `--clear-cache` | flag | 否 | 清除缓存后运行 |
| `--sessdata` | string | 否 | B 站 SESSDATA 登录凭证，提升获赞/粉丝字段完整度 |
| `--cookie` | string | 否 | 完整 Cookie 字符串（优先推荐 `--sessdata`） |
| `--resume` | flag | 否 | 结合 `--all --cache` 从上次断点继续全量分析 |
| `--no-checkpoint` | flag | 否 | 禁用断点续传，始终从头全量分析 |
| `--verbose` | flag | 否 | 显示详细日志 |

## 📄 报告内容

生成的 Markdown 报告包含以下章节:

1. **分析摘要**: UP 主核心数据和总体评价
2. **UP 主基础信息**: 头像、昵称、等级、粉丝数等
3. **核心数据指标**: 播放量、点赞、投币、收藏等统计
4. **分区分布分析**: 各分区视频数量和占比
5. **视频类型分析**: 教程、评测、解说、vlog 等分类
6. **互动质量分析**: 互动率、弹幕密度等指标
7. **发布趋势分析**: 更新频率、活跃度趋势
8. **热门视频排行**: 热度分最高的 5 个视频
9. **UP 主画像**: 内容、受众、商业、成长四维画像
10. **综合评分**: 雷达图展示和多维度评分
11. **总结建议**: 优势分析和改进建议

## 🔧 核心特性

### WBI 签名算法
- 自动绕过 B 站风控机制
- 支持签名接口、非签名接口、搜索 API 三级策略
- 稳定可靠的数据获取

### 智能评分系统
- 根据内容类型差异化评分
- 使用 IQR 统计方法提高鲁棒性
- 6 个维度全面评估

### UP 主画像分析
- 4 大维度深度分析
- 结合内容、受众、商业、成长四个角度
- 提供全面的画像报告

### 数据缓存
- 24 小时缓存有效期
- 减少重复请求,提升效率 10 倍
- 支持手动清除缓存

## ⚠️ 注意事项

1. **数据准确性**: 评分结果仅供参考,不代表官方评价
2. **风控限制**: 频繁请求可能触发风控,建议启用 `--cache`
3. **未登录状态**: 部分字段(如获赞数)通过视频数据累加补充
4. **网络异常**: 自动重试 3 次,指数退避策略
5. **缓存清理**: 缓存按 TTL 自动过期（up_info 12h、video 24h）；`--clear-cache` 用于强制刷新并清空全部缓存（含断点 checkpoint），避免跨 UP 主脏数据
6. **登录态**: 传入 `--sessdata` 可让 API 直接返回获赞/粉丝等字段，无需累加估算
7. **断点续传**: `--all --cache` 全量分析中断后，再次以 `--all --cache --resume` 运行可跳过已完成的视频
8. **图表依赖**: `matplotlib` 为可选依赖；缺失或 `--no-charts` 时自动降级为纯文本迷你柱状图

## 使用示例

```bash
# 单次分析最近 10 个视频
python scripts/analyze_up.py 159285873

# 登录态全量分析（字段更完整）
python scripts/analyze_up.py 159285873 --all --cache --sessdata "你的SESSDATA"

# 全量分析中断后续传
python scripts/analyze_up.py 159285873 --all --cache --resume

# 无绘图环境/禁用图表
python scripts/analyze_up.py 159285873 --cache --no-charts
```
