## 处理建议

### 1. 优先判断领域
根据对话场景快速锁定可能的含义范围。

### 2. 置信度排序
- 95%+：几乎确定
- 85-94%：很可能
- 70-84%：有可能，需要验证
- <70%：较罕见，建议询问

### 3. 用户引导话术

**高歧义缩写：**
```
"{缩写}" 可能有多种含义：
1. {含义A}（{领域A}）
2. {含义B}（{领域B}）
请问您是在什么场景下看到的？
```

**中歧义缩写：**
```
"{缩写}" 通常指 {主要含义}，
但在 {特定场景} 下也可能指 {次要含义}。
您遇到的是哪种情况？
```

### 4. 交叉验证
当不确定时，可以：
- 查看完整句子
- 询问来源平台（微博/游戏/工作群等）
- 搜索验证
