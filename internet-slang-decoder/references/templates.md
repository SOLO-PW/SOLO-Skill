# 用户交互话术模板库

本文件提供处理各种场景的标准话术模板，确保交互的一致性和专业性。

## 1. 发现未知缩写

### 1.1 通用询问模板

```
我发现了缩写 '{缩写}'，但不在我的知识库中。

为了帮您准确解析，请告诉我：
1. 📍 **场景**：这是什么领域的对话？
   - 游戏/电竞
   - 娱乐/饭圈/明星
   - 科技/编程/工作
   - 生活/日常聊天
   - 其他：_____

2. 💬 **完整句子**：能否提供包含这个缩写的完整句子？

3. 📱 **来源**：在哪里看到的？（微博/弹幕/游戏/微信群等）

有了这些信息，我可以更准确地帮您解析！
```

### 1.2 简短询问模板（快速场景）

```
发现了缩写 '{缩写}' 🤔

请问这是什么领域的？（游戏/娱乐/科技/生活）
```

### 1.3 提供猜测的询问模板

```
发现了缩写 '{缩写}'。

根据上下文，我猜测可能是：
- 猜测1：{猜测1}
- 猜测2：{猜测2}

请问是哪一个？或者都不是？
```

## 2. 多义性歧义处理

### 2.1 高歧义缩写（2+ 含义）

```
'{缩写}' 有多种常见含义：

┌─────────────────────────────────────┐
│ 1️⃣ {含义A}                          │
│    领域：{领域A}                     │
│    例句：{例句A}                     │
├─────────────────────────────────────┤
│ 2️⃣ {含义B}                          │
│    领域：{领域B}                     │
│    例句：{例句B}                     │
├─────────────────────────────────────┤
│ 3️⃣ {含义C}                          │
│    领域：{领域C}                     │
│    例句：{例句C}                     │
└─────────────────────────────────────┘

请问您遇到的是哪一种？
或者告诉我您看到这句话的场景，我帮您判断！
```

### 2.2 双义缩写（2 个含义）

```
'{缩写}' 有两个常见含义：

🅰️ {含义A}（{领域A}）
   例句：{例句A}

🅱️ {含义B}（{领域B}）
   例句：{例句B}

根据您的场景 "{用户上下文}"，我认为更可能是 🅰️/{含义A}。
请问对吗？
```

### 2.3 领域特定歧义

```
在{领域}中，'{缩写}' 可能指：

• {含义A} - {说明A}
• {含义B} - {说明B}

具体含义取决于上下文，您能提供完整句子吗？
```

## 3. 搜索结果呈现

### 3.1 搜索后确认模板

```
根据网络搜索，'{缩写}' 可能有以下含义：

📊 搜索结果汇总：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 来源1：{来源1}
   含义：{含义1}
   可信度：{'⭐' * 可信度1}

🔍 来源2：{来源2}
   含义：{含义2}
   可信度：{'⭐' * 可信度2}

🔍 来源3：{来源3}
   含义：{含义3}
   可信度：{'⭐' * 可信度3}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

请问您指的是哪一个？或者都不是？
```

### 3.2 搜索结果不一致时

```
关于 '{缩写}'，不同来源给出了不同解释：

⚠️ 注意：搜索结果存在分歧

来源A（{平台A}）：{含义A}
来源B（{平台B}）：{含义B}

这可能是因为：
• 该缩写在不同圈子有不同含义
• 新兴缩写，尚未统一
• 特定小圈子内部用语

建议您：
1. 提供更多上下文
2. 确认来源平台/圈子
3. 或者直接问对方是什么意思 😄
```

## 5. 特殊情况处理

### 5.1 可能是拼写错误

```
您输入的是 '{缩写}'，但我没有找到相关记录。

🤔 您是否想输入：
• {建议1} - {含义1}
• {建议2} - {含义2}

或者这是一个新出现的缩写？
```

### 5.2 可能是组合缩写

```
'{缩写}' 看起来像是多个缩写的组合：

可能分解为：
• {部分1} → {含义1}
• {部分2} → {含义2}

组合含义：{组合含义}

请问是这样理解的吗？
```

### 5.3 可能是方言/谐音

```
'{缩写}' 可能是拼音缩写或方言谐音：

🔤 拼音解读：
• {拼音1} → {含义1}
• {拼音2} → {含义2}

🗣️ 方言/谐音：
• {方言1} → {含义1}

请问是哪一种？
```

### 5.4 过时/已不用的缩写

```
'{缩写}' 是一个较早期的网络用语：

📅 流行时期：{时期}
💀 当前状态：已较少使用
📖 原含义：{含义}
🔄 现在更常用的说法：{新说法}

您是在回顾老内容时看到的吗？
```

## 6. 教育/科普场景

### 6.1 介绍缩写文化

```
💡 小知识：关于 '{缩写}'

这个缩写来自 {来源} 圈子，
在 {时间} 开始流行。

最初用于 {原始用途}，
现在扩展为 {当前用途}。

类似表达还有：
• {相关缩写1}
• {相关缩写2}
• {相关缩写3}

想了解更多网络用语文化吗？
```

### 6.2 使用建议

```
⚠️ 使用建议：'{缩写}'

✅ 适合场景：
• {适合场景1}
• {适合场景2}

❌ 避免场景：
• {避免场景1}
• {避免场景2}

💡 小贴士：{使用建议}
```

## 7. 结束语模板

### 7.1 成功解析后

```
✨ 解析完成！

希望这帮您理解了 '{缩写}' 的含义。
网络用语变化很快，我会持续学习更新 📚

还有其他缩写需要解析吗？随时问我！
```

### 7.2 未能解析时

```
😅 抱歉，暂时无法确定 '{缩写}' 的含义。

这可能是因为：
• 太新了，还没被广泛记录
• 特定小圈子内部用语
• 可能是拼写错误

建议您：
1. 直接问发消息的人
2. 在相关社区搜索
3. 过段时间再来问我，我可能已经学会了！

无论如何，感谢您的提问，这让我有机会学习新知识 🙏
```
