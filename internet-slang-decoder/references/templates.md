# 用户交互话术模板库

> 自动生成自 scripts/slang_db.json，领域示例基于实际数据。

## 1. 发现未知缩写

### 1.1 通用询问模板

```
我发现了缩写 '{缩写}'，但不在我的知识库中。

为了帮您准确解析，请告诉我：
1. 场景：这是什么领域的对话？
   - 游戏/电竞
   - 娱乐/饭圈/明星
   - 科技/编程/工作
   - 生活/日常聊天
   - 动漫/二次元
   - 金融/投资
   - 学术/教育
   - 其他：_____

2. 完整句子：能否提供包含这个缩写的完整句子？
3. 来源：在哪里看到的？（微博/弹幕/游戏/微信群等）
```

### 1.2 简短询问模板

```
发现了缩写 '{缩写}'，请问这是什么领域的？
```

## 2. 多义性歧义处理

### 2.1 高歧义缩写

```
'{缩写}' 有多种常见含义：

1. {含义A}（{领域A}）
2. {含义B}（{领域B}）
3. {含义C}（{领域C}）

请问您遇到的是哪一种？
```

### 2.2 上下文推断确认

```
根据您的场景，我认为 '{缩写}' 更可能是 {推断含义}。
请问对吗？
```

## 4. 解析结果呈现

### 4.1 单义缩写

```

```

### 4.2 多义缩写

```
'{缩写}' 有 {数量} 种常见含义：

1. {含义A}（{领域A}，置信度：{置信A}%）
2. {含义B}（{领域B}，置信度：{置信B}%）

告诉我具体场景可以帮您确定最准确的含义。
```

## 5. 搜索无结果时

```
搜索了缩写 '{缩写}'，但没有找到明确的含义。

建议：
1. 在搜索引擎中查询 "{缩写} 是什么意思"
2. 提供更多上下文帮助判断
3. 直接询问对方是什么意思
```
