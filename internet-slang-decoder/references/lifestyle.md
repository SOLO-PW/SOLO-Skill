# 生活/网络用语缩写词典

## 常用英文缩写

| 缩写 | 全称 | 含义 | 例句 |
|------|------|------|------|
| btw | by the way | 顺便说一下 | btw，你吃饭了吗 |
| fyi | for your information | 供你参考/顺便一提 | fyi，会议改时间了 |
| asap | as soon as possible | 尽快 | 请asap回复 |
| imo | in my opinion | 在我看来 | imo，这个更好 |
| imho | in my humble opinion | 依我拙见（更谦虚） | imho，这样不太好 |
| tbh | to be honest | 说实话 | tbh，我不太喜欢 |
| tbf | to be fair | 公平地说 | tbf，他也有道理 |
| idk | I don't know | 我不知道 | idk，你问别人吧 |
| idc | I don't care | 我不在乎 | idc，随你便 |
| ik | I know | 我知道 | ik，不用说了 |
| ikr | I know right | 我知道对吧（表认同） | ikr！我也这么觉得 |
| nvm | never mind | 没关系/算了 | nvm，没事了 |
| np | no problem | 没问题 | np，小事 |
| ty | thank you | 谢谢 | ty帮忙 |
| thx | thanks | 谢谢（更随意） | thx！ |
| pls | please | 请 | pls帮我 |
| sry | sorry | 对不起 | sry迟到了 |

| hf | have fun | 玩得开心 | hf！ |

| wbu | what about you | 你呢（同上） | wbu |

## 使用场景

### 微信/QQ聊天
- 常用：btw, fyi, asap, lmk, omw, rn
- 特点：简洁高效，节省时间

### 微博/小红书
- 常用：tbh, imo, irl, smh
- 特点：表达态度，引发共鸣

### 工作沟通
- 常用：fyi, asap, eta, eod, tbd
- 特点：专业简洁，提高效率

### 游戏社交
- 常用：gg, wp, glhf, brb, afk
- 特点：国际通用，快速交流
